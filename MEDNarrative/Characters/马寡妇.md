# 马寡妇

**Role:** 常驻NPC｜**Voice:** 见 frontmatter

## 1. 基础档案（数据）

| 项 | 内容 |
|---|---|
| 正式名称 | 马寡妇（马家杂货铺女掌柜） |
| 年龄 | 40 上下（1942） |
| 明面身份 | 杂货铺女掌柜（前店后坊：前店售卖、后屋母子相依＋仓库） |
| 暗地身份 | 柜台白天小黑市（管控货小宗中转） |
| 主场地块 | 马家杂货铺（SE-01，R9C8——南大道东段、药房正北、警署隔街望见） |

## 2. 身世（数据）

- **丈夫**：马老二出生后不久病死——遗摊（半个杂货铺）她撑大；男人没了、铺子在。
- **早年出身（隐匿不说）**：曾在大户人家（养成的眼力、善于交际与泼辣的性格）——这段来历她从不提；这些本事使她成为维持家庭生活的重要支柱（暗渠渠道由此而来）。

## 3. 外貌锚点（→ 美术描述指标为准）

- 浓眉、颧骨高、嗓门大；粗手大脚（搬货/劈柴的实手）。
- **脂粉撑面**：涂脂抹粉＝丈夫没了也要体面；玉簪＋金耳环＝压箱底的值钱物（**真的，只是旧**——与王裕昌的赝品成对照）。
- 靛蓝洗白的蓝布褂子＋围裙。

## 4. 主场与职能

- 前店后坊：前店针头线脑油盐酱醋（穷人日常）；后屋母子相依＋仓库（马老大死后很多活计没人干）。
- **柜台白天小黑市（小宗）**：管控货（煤油/药品/火柴）小宗中转——**具体运作难以在故事中展开，作地点卡索引钩子（H61）**；与摊主王"上游下游"对接（夜里黑市大宗她不吃）。
- **喂熟巡警保甲**：破财消灾（002 巡警盯梢＝例行收租，不是盯黑市）；嘴上骂"黑狗子"心里算得清。

## 5. 行动逻辑（可执行要点）

- 泼辣＝早年练出来的护身符（也是晓梅学的对象）；对官面赔笑、对街坊开嗓、对程家热络。
- 标志性动作：叉腰开骂、往围裙上擦手、从柜台下摸东西给熟客。
- 说话风格："你这小逼崽子！""光知道喊！"式打骂一体；对程靖霖"程子来啦，辛苦你了"。
- 能力边界：过日子全能（算账/识货/会周旋）；不识字（账靠心记？——候选，未定）。

## 6. 社会关系

1. **[[马老大]]**——长子：**不知去了哪里、不知生死**——只有一封从哈尔滨的来信和几件旧衣物；对外口径"你大哥在哈尔滨混得可好了"，对小儿子也这么说，**甚至有时候连自己都骗过了**；心里不敢想"如果儿子还活着，自己会是什么样子"。
2. **[[马老二]]**——幼子：嘴硬心软（骂"败家玩意儿"骂得凶、护得也凶）；哈尔滨梦＝她口径的代价，她心里清楚但没法说破。
3. **[[程晓梅]]**——**半个亲女儿**（她家里只有儿子没有女儿）：多一层温柔慈爱（不过度亲昵）；看得出晓梅对靖霖的心思；晓梅的泼辣是看她学的；两人之间有一些"女人的对话"。
4. **[[程时一]]**——长年惯例：程时一给马家看病从不收钱，她回煤块/杂货不找零——两边都有数；她对程时一的军医身份不知，但对药房"不干净"心里门儿清。
5. **[[程靖霖]]**——邻家后辈（"程子"）；002 送药/煤块抵药钱。
6. **[[摊主王]]**——柜台上下游对接（她吃小宗、他吃大宗）。

## 7. 秘密与叙事钩子（数据）

- **药房知情度**：知道"不干净"（夜里有人进出/送伤者）、**不知是抗联交通站**——装不知道装到"连自己都骗过了"（她自己的黑市与药房暗面互不打听，同行规矩）。
- **H45 落定（2026-08-24）**：**会打听但不会递话**——她打听药房动向，但不主动递话（D13 后无递话支线）。
- **D16/D21**：搜家夜/抄家时**在门口看着，想要开口，但不知从何说起——没有说额外的话**（沉默是她最大的表达）。
- **结局＝留白（H62）**：D29 去留（跟程家走/留下看铺）写作时定。
- 柜台小黑市运作＝H61（地点卡索引钩子，不展开）。
