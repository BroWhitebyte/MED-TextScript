# 角色属性说明

> 角色卡（`Characters/*.md`）frontmatter 属性规范 v1.0
> 依据：叙事工具链（Narrative Tool 读取 `id/name/role/voice`）+ MEDSystem 系统文档（势力/身份/声望/特殊状态）
> 适用：本目录下全部角色档案的建立与维护

---

## 一、字段总览（22 项，分四组）

### 组 1 · 核心字段（插件实际读取，必填）

| 字段      | 类型   | 必填  | 说明                                           |
| ------- | ---- | --- | -------------------------------------------- |
| `id`    | text | ✅   | **唯一键，不可变**。中文显示名；改名会断开对话 cast 引用、本地化映射与历史记录 |
| `name`  | text | ✅   | 显示名，通常与 id 一致                                |
| `role`  | enum | ✅   | 地位分级（见 §二），**不是职业**                          |
| `voice` | text | ✅   | 语音风格提示（先听后答、句子长短、对谁收着等）                      |

### 组 2 · 系统映射字段（对齐 MEDSystem，必填）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `faction` | enum | ✅ | **表势力**：`官面` / `街面` / `江湖` / `城外`（四分类法） |
| `identity` | enum | ✅ | **表身份**：势力内子类 + 具体职务，如 `诊所·药房伙计`（见 §三枚举表） |
| `secret_faction` | enum / 空 | ✅ | **里势力**（设计真值）；无则 `""`；`表里势力互不影响` |
| `secret_identity` | enum / 空 | ✅ | **里身份**（设计真值）；无则 `""` |
| `initial_reputation` | int | ✅ | 对玩家的**初始NPC声望**，-10~10，默认 `0` |
| `initial_states` | list / 空 | ✅ | 初始特殊状态，如 `[风寒]`；无则 `[]` |

### 组 3 · 编剧与管理字段（必填/建议）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `aliases` | list | ✅ | 对话内称呼全集：`[霖子, 程子, 程哥, …]`；兼作台词-角色匹配兜底 |
| `appearance_scenes` | list | 建议 | 出场场景（对话文件名），插件模板字段 |
| `first_appearance` | text | 建议 | 首次出场：时间或事件，如 `1931-09-22（沈阳城外收养）` |
| `relations` | list | 建议 | 静态关系（wikilink + 关系说明）：`"[[程时一]] 养父·师父"` |
| `death_status` | enum | ✅ | `存活` / `已故` / `未知` |
| `status` | enum | ✅ | 档案生命周期：`活跃` / `草稿` / `待定` / `弃用` |
| `source` | text | 建议 | 设定来源：`角色卡设定：程靖霖.docx` / `事件003C` |
| `tags` | list | ✅ | 检索标签：至少 `[character]`；可加 `主角`、`工具NPC` 等 |

### 组 4 · 可选/预留字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `class_level` | enum | 可选 | 社会阶层：`穷人` / `小市民` / `富户` / `官面` |
| `portrait` | text | 预留 | 立绘文件名（分支对话系统要求立绘，暂空 `""`） |
| `id_slug` | text | 预留 | 英文键（5 语言本地化映射预留），如 `cheng_jinglin` |
| `notes` | text | 建议 | 一句话核心设定摘要（身份/身世/信物要点） |

## 二、`role` 地位分级（五档，2026-08-24 新增核心档）

| 档位 | 定义 | 判定参考 | 当前角色 |
|------|----------|----------|----------|
| `主角` | 玩家控制角色；**镜像主角＝主角的镜像（非操控），按主角卡格式建档** | 唯一（操控）；镜像主角同格 | 程靖霖（操控）、黑川慎介（**镜像主角**，2026-08-24 升格） |
| `核心NPC` | **贯穿全剧的枢轴角色**——驱动主干线（主线/身世/双胞胎/731 等），常驻至终局 | 有系统级影响且贯穿多周弧 | 程时一、王裕昌、中野三郎、老黑川、老朴 |
| `重要NPC` | **驱动支线关键转折** | 有剧情支点或系统级影响（支线级） | 赵掌柜、佟三爷、程晓梅、马老大（待定）、盟军飞行员（待定） |
| `常驻NPC` | 有固定主场、反复出场、承担支线/对话 | 有台词且与主线流程绑定 | 马寡妇、马老二、王吉来、王小、佟立春、李大个子、张老大、老孙、李加夫 |
| `工具NPC` | 功能性角色/布景人物 | 台词少或无、不参与关系系统 | 受刑者、警士、警察A、警察B、风寒车把式、更夫老白、曹二泥、摊主王 |

> 工具NPC 同时约定 `status: 待定`，待其承担剧情后再升级。
> 钩子卡（未激活角色）用 `role: 重要NPC（待定）` 占位＋`status: 待定`——激活后再定档。

## 四、边界原则（什么不进卡片）

以下为**运行时数据**，由游戏存档/状态系统管理，**禁止写入 frontmatter**：

- NPC 声望当前值（卡片只存 `initial_reputation` 初始值）
- 势力声望当前值（选择导致的 ± 变化）
- 关系数值变化（对话选择后增减）
- 秘密/里势力/里身份的**发现状态**（"玩家已知/未知"属存档，卡片只存设计真值）
- 特殊状态当前等级（发冷1→寒冷2→冻僵3→失温4 的实时等级）
- 任务关联与任务进度（待 `Quests/` 目录建立后另行设计）

> 原则：**卡片 = 设计真值；存档 = 运行时状态。** 二者一旦混淆，Obsidian 里就会存满会过期的数据。

## 五、建档与维护约定

1. **新建角色**：`Ctrl+P` → 创建角色（生成 `id/name/role/voice` 基础模板），再按下表补齐组 2/3/4 字段。
2. **id 不可变**：一旦进入对话（cast 引用）即锁定；如需改名，先改全部 `.ncanvas` 引用与导出再改档案。
3. **称呼进 aliases**：新增台词称呼（如新的称谓）时同步补进 `aliases`，便于审计脚本兜底匹配。
4. **身份与职业分离**：`role` 只放地位分级；职业信息放 `identity` 或正文，二者不得混用（旧版"role: 警尉/车把式"的写法已废弃）。
5. **状态流转**：`status` 从 `草稿` → `活跃`；工具NPC 起手 `待定`，承担剧情后升 `活跃` 并同步调整 `role`。
6. **来源可溯**：设定来自 docx / 事件 / 口头拍板的，写进 `source` 与 `notes`，避免"不知道这个设定从哪来"。
7. **新角色补势力**：任何 NPC 都必须有 `faction` + `identity`（系统要求"每位NPC都有所属势力"）；无法确定的先用 `待定` 标注并记录。
