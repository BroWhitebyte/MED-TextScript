# 通用角色卡格式（v1.0）

> **用途**：全项目角色卡统一格式——以主角程靖霖压缩卡为范本导出；后续 27 张角色卡（常驻/重要/工具 NPC）按本格式落盘。
> **字段规范依据**：《角色属性说明.md》（frontmatter 22 字段四组，v1.0）。
> **压缩纪律**：**卡 = 设计真值与可执行锚点；文学白描 = 事件文本/美术规范**。描述性内容不入卡（外貌细描→美术描述指标；成长/氛围→事件文件）。
> **禁区**：运行时数据（声望当前值/发现状态/状态等级/任务进度）禁止写入 frontmatter——卡片=设计真值，存档=运行时状态。
> **命名**：`Characters/<id>.md`；`id` 唯一不可变（narrative-tool 读取，改名先改全部 .ncanvas 引用与导出）。

## 一、frontmatter 模板（复制后按注释填写）

```yaml
---
id: ＿＿＿                    # 唯一键，不可变；中文显示名，与文件名一致
name: ＿＿＿                  # 显示名，通常与 id 一致
role: 常驻NPC                 # 主角 / 核心NPC / 重要NPC / 常驻NPC / 工具NPC（地位分级，非职业；钩子卡用"重要NPC（待定）"占位）
voice: ＿＿＿                 # 语音风格提示（短）：先听后答/先记后说、句子长短、对谁收着
faction: 街面                 # 表势力：官面 / 街面 / 江湖 / 城外
identity: ＿＿＿              # 表身份：势力内子类·具体职务（如 商户·当铺掌柜）
secret_faction: ""           # 里势力（设计真值）；无则 ""
secret_identity: ""          # 里身份（设计真值）；无则 ""
initial_reputation: 0        # 初始玩家声望，-10~10，默认 0
initial_states: []           # 初始特殊状态，如 [风寒]；无则 []
aliases:                     # 对话内称呼全集（台词匹配兜底）
  - ＿＿＿
  - ＿＿＿
appearance_scenes:           # 出场场景（对话文件名）
  - ＿＿＿
first_appearance: ＿＿＿     # 首次出场：时间或事件，如 1931-09-22（沈阳城外收养）
relations:                   # 静态关系（wikilink + 关系说明）
  - "[[＿＿＿]] 关系说明"
death_status: 存活            # 存活 / 已故 / 未知
status: 活跃                  # 活跃 / 草稿 / 待定 / 弃用（工具NPC 起手 待定）
class_level: 小市民            # 社会阶层：穷人 / 小市民 / 富户 / 官面
portrait: ""                 # 立绘文件名（预留）
id_slug: ＿＿＿               # 英文键（5 语言本地化预留）
source: ＿＿＿                # 设定来源：裁定表第X批 / 事件00X / 角色卡设定：XXX.docx
tags:
  - character
  - ＿＿＿                     # 检索标签：双胞胎线 / 抗联线 / 工具NPC 等
notes: ＿＿＿                 # 一句话核心设定摘要（身份/身世/信物要点，勿文学化）
---
```

**必填**：`id / name / role / voice / faction / identity / secret_faction / secret_identity / initial_reputation / initial_states / aliases / death_status / status / tags`（组 1+组 2 全必填）。
**建议**：`appearance_scenes / first_appearance / relations / source / notes`。
**预留**：`portrait / id_slug`（可空）；`class_level` 可选。

## 二、正文模板（九节骨架，按程靖霖压缩卡结构）

### `# <id>` ＋ Role/Voice 行

```markdown
# ＿＿＿

**Role:** 常驻NPC｜**Voice:** 见 frontmatter
```

### 1. 基础档案（数据）

| 项 | 内容 |
|---|---|
| 正式名称 | ＿＿＿ |
| 旧名/别名 | ＿＿＿（无则"无"） |
| 生日 | ＿＿＿（可省） |
| 年龄 | ＿＿＿（1942 年 1 月口径；虚岁） |
| 明面身份 | ＿＿＿ |
| 暗地身份 | ＿＿＿（无则"无"） |
| 主场地块 | ＿＿＿（地图网格定位表 R行C列） |

### 2. 身世与信物（数据）

- 关键履历节点（捡子/收养/投靠/变节等，按裁定表落档）
- 信物/关键道具（名称、来路、剧情链：埋设日→回收日）
- 时间线裁定（如行踪、生死日期）直接写，注明来源批次

> 文学白描（成长段/氛围段）不写此处——移入事件文本或美术规范，卡内留一行"移出说明"即可。

### 3. 外貌锚点（→ 美术描述指标为准）

- 2-3 行可执行锚点（发型/脸色/身形；穿着清单一句；视觉锚点如"灯下的人"）
- 指向：《美术描述指标_角色卡硬性规范.md》对应角色 ①-⑭

### 4. 主场与职能

- 固定站位（该角色在主场的位置）
- 白天职能 / 夜晚职能（明暗两面各一行要点）
- 街面/系统位置（一句话：这角色在系统里是"什么"）

### 5. 四方称呼（数据）

| 群体 | 称呼 |
|---|---|
| 穷人 | ＿＿＿ |
| 富人/铺面 | ＿＿＿ |
| 伪满 | ＿＿＿ |
| 日军 | ＿＿＿ |

实况：谁喊他什么（按人物关系一行）。

### 6. 行动逻辑（可执行要点）

- 标志性动作（2-3 个，写作可用）
- 看人方式（若进辨别表，注明"辨别表依据"）
- 能力边界 / 不会什么（各一行）
- 说话逻辑（对穷人/富户/伪满/日军各收一句，含可藏暗话的词类）

### 7. 社会关系

1. **[[＿＿＿]]**——关系说明一句（关系本质，如"墙"这类比喻保留半句）。
2. …（按 relations 字段展开，正文与 frontmatter 对应）

### 8. 明面规则／潜规则（要点）

- 明面：2-4 条短句（他/它所在场所的规矩）
- 潜规则：2-4 条短句（高压线；写作时不许越）

### 9. 秘密与叙事钩子（数据）

- 隐藏秘密（数据点列表，勿文学化）
- 关键伏笔（埋设日/回收日，如"000 王裕昌'真像……'已埋 → D17 引爆"）
- 道具链（契诃夫之枪式：埋设→互证→处置）

### 10. Speaker Scenes

- 出场场景列表（时间·地点·事件一句话，与 frontmatter `appearance_scenes` 对应）

## 三、填写指引速查

| 场景 | 做法 |
|---|---|
| 新裁定/审计结论落卡 | 按《讨论结果落档速查》§二 字段对应表：结论→字段，`source` 记批次 |
| 描述性内容 | 不入卡——外貌→美术规范；氛围/成长→事件文本 |
| 称呼新增 | 同步补 `aliases`（台词匹配兜底） |
| 身份/职业 | `role` 只放地位分级；职业进 `identity`，二者不得混用 |
| 状态流转 | 工具NPC 承担剧情后：`status: 待定→活跃`，`role` 升档 |
| 里势力 | 只记设计真值；"玩家已知/未知"属存档，禁止入卡 |
| 改 id | 先改全部 `.ncanvas` 引用与 `Exports/*.dialogue` 再改档案 |
