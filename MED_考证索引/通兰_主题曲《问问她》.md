# 通兰·主题曲《问问她》

> **性质**：项目主题曲（**元层内容**——在画布之外、正文之外，**不进任何事件件**｜依据：评价系统「在场断裂·元层断裂」＋《视觉小说文本规则》§二"①②③层信息一律不得进入④正文"）
> **缘起**：以「甲號街的夜曲」的**形式**为蓝本（问句起兴／四问一节／副歌反复／我今夜怎么如此悲伤／窗外→世界）重新创作。**不是填词、不是翻译**——词面几乎全部换掉，换成通兰世界里**能摸到的东西**。
> **"她"＝程晓梅**（程时一之女，时一堂大药房）（2026-10-10 作者裁定）
> **世界观锚点**：通兰县城｜1942 年 2 月｜伪满洲国滨江省｜官面／街面／江湖／城外四势力｜百姓口径与官面口径分层
> **体例**：口语小调。**零比喻、零形容词堆叠、零内心判词**；情感靠物证、账目、路程、时辰自证（`tonglan-narrative-style` 铁律 2、3）

## 二 为什么改成"程晓梅"更好

**原曲的核心动作是"问问她"——一个说话的人，和一个被问的人。**

- 写成**已故的师父**：问的是**问不着的人**。孤独够，但结尾"进来吧"没有着落——对着空气说话。
- 写成**程晓梅**：她**就在屋里**。于是全曲的时间线自己立起来了：

```
程时一被中野的车拉去官舍区（204 末）
        ↓  他一个人走
   车上、雪地里，问的都是家里那点事
        ↓  第二段把镜头转回药铺
   程晓梅在屋里：米在锅里、灯芯在跳、门帘在响
        ↓  掌灯了
   他推门进来：「吃没吃饭／进来吧」
```

**"我今夜一个人走"因此有了对照面**——他一个人走，**她一个人在家**。这不是修辞，是 204 那一夜的实际形状。

**另一处收获**：开头四问从"什么叫罪／什么叫爱"这类大题目，收成"**药熬得咋样／门插没插上**"。一个大男人在车上想的就这两件事——**题目小了，分量重了**。

## 三 这么写，落在哪条纪律上

| 原曲的行 | 通兰的写法 | 依的纪律 |
|---|---|---|
| 什么是罪，什么是爱 | **药熬得咋样** | 去抽象；一个姑娘在药铺能回答的问题 |
| 什么是悲，什么是爱 | **门插没插上** | 秩序代替情绪——"插门"是动作，也是那年月夜里必做的事 |
| 批判现实丑陋的人性 | **柜台上那杆戥子** | 动作/器物优先于形容：戥子（抓药称量）是药铺的良心秤 |
| 批判现实卑微的无奈 | **架子底下那本账** | 账能被玩家接住，"卑微的无奈"不能 |
| 独来独往 | **一个人走＋街上没人／落了雪** | 孤独由"街上没人"自证 |
| 我唱著夜曲 | **哼个曲** | 规避"夜曲"的年代用语风险（见 §五） |
| 表达我内心的感受／世界 | **说说我心里的动静／日子** | 保留"我"的口语，不升格为"灵魂""内心世界" |
| 窗外的**雨**声 | **外头有人扫雪**（＋副歌改**窗上的霜**） | 1942 年 2 月，东北——**是雪不是雨**；扫雪是那年月凌晨必有的声音 |
| 窗外的**枫**林 | **窗上的霜** | 枫在关东小调里不合地；霜是窗上真有的东西 |
| 怎么如此**悲伤** | **咋这么冷** | "悲伤"是判词，"冷"是体感；并用东北口语"咋" |
| 和我的心一样 | **街上没人，跟我心里一样** | 类比保留，但落在"没人"这个事实 |
| 来到这里 | **走到这儿** | 口语 |
| （原曲无） | **掌灯了／吃没吃饭／进来吧** | 收在**动作与短对白**（结尾模板）：从"一个人走"回来，**她就在屋里** |

**没有一句形容词**："悲伤""卑微""丑陋""无奈"**全部不出现**；全曲**零比喻**（无仿佛／像是／如同）。
**"我就会这么一样"**是全曲的钉子：一个药铺掌柜只会一件事——**把药送到人手上**。

## 四 编曲建议（照项目质感，不照流行歌）

| 项 | 建议 |
|---|---|
| 体裁 | **关东小调**（五声音阶，宫调式）；不要流行编曲、不要弦乐铺底 |
| 主奏 | 一双筷子敲碗沿／口琴／二胡（单件，不加层） |
| 速度 | 慢，口语速度；每句尾音**不上扬**（不煽） |
| 人声 | 中年男声，半说半唱；**允许气短、允许破**——不修音 |
| 环境声 | 底噪里要有：**炉子响、门帘响、外头梆子、扫雪声**（都不是配乐，是那时屋里本来就有的声音） |
| 长度 | 两段循环；尾段（掌灯了…进来吧）只在片尾出现一次 |

**落点用法（三处，都不进画布）**
1. **主菜单／片头**：第一段＋副歌
2. **第二天夜里（登门之后）**：第二段（与 205 夜归同段落，元层播放，不进正文）
3. **片尾**：全曲，收在"进来吧"——**与她同处一室，曲子合上**

## 五 自检

| 项 | 结果 |
|---|---|
| 时代用语 | 药铺／戥子／配给本／门帘／掌灯／扫雪——均为 1942 东北口径；**无"夜曲"以外的现代词** |
| 比喻套语 | **0**（无仿佛／像是／如同／一般） |
| 抒情与总结 | **0**；结尾收在"进来吧"（短对白） |
| 内心判词 | **0**（无觉得／感到／心里发涩；"跟我心里一样"是类比，不是判词） |
| 独白上限 | 无双段超 150 字 |
| 修饰密度 | 极低（全曲几乎无"的"）｜副词仅"咋""这么" |
| 指代一致 | "她"全曲 4 处（问答起兴 2 处／副歌 2 处）＋尾 1 处，**均指程晓梅** |

## 六 一处提请你裁定

**「夜曲」这个词留不留？**
我改成了"**哼个曲**"。理由：库里"夜曲"作**音乐体裁**偏后起（民国常见"小夜曲"多指西乐），小调类更常叫"调""曲""牌子"。
若你认为主题曲是**元层**、不必受 1942 口径约束，**改回"我今夜唱著夜曲"我也照办**——纯口径选择，无对错。
