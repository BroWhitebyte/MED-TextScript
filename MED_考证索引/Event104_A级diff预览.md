### 改动 1：`n15.turns[1].line`（第二句）

```
− 这板子上的事儿，大部分都不麻烦，一个时辰就能回来。可是也会有一些，得多跑几次。

＋ 这板子上的事儿，大部分都不麻烦，一个时辰就能回来；也有得多跑几趟的，今儿跑不完，

> 说明：把"可延到次日天黑前"这条规则**放进人物嘴里**；保留"一个时辰"（民间口语，库中有据：`满洲山怪` p29「煮一个时辰」）。

### 改动 2：`n15.turns[4].line`（第五句）——与 B1 天光口径合并处理

```
− 这功夫，你要么在店里待着，等吃饭；要么趁天黑透之前，出去办一件。天快黑了。自己拿主意吧。

＋ 这功夫，你要么在店里待着，等吃饭；要么趁还看得见道，出去办一件。天说黑就黑，别在外头耗着。

## A3 牌局入口互斥（改 `n15.turns[0]` ＋ 分写 `n26`/`n27`）

**问题**：选送药路线时，`n15` 承诺"回来吃饭"，`n34` 又演"饭菜上桌、正要动筷子"＝**吃两顿**；且 `n27`「把板子上办好的事擦去」在"哪里也不去"分支不成立。

**采用的解法**（审查意见 §二 A3 的方案 1）：**「哪里也不去」＝进牌局的路径**；送药路线在 `n26` 后收束，牌局留给 105 由"没出门"前置条件触发。

### 改动 1：`n15.turns[0].line`（第一句）——去掉"回来吃饭"的承诺

```
− 天色还早，霖子，挑一个去吧。回来吃饭。

＋ 天色还早，霖子，挑一个去吧。
```

### 改动 2：`n26` 按分支分写（新增 1 张卡）

**现状**：`n26`「天色沉沉，程靖霖回到了药房。」——这是三条送药分支的汇合点（`l7`/`l8`/`l9`/`l10` 四条入边：`n22`、`n23`、`n24`、`n25`）。

**问题**：`n21`→`n22`（哪里也不去）也汇进 `n26`，于是"回到药房"对没出门的人也成立得别扭。

```
− n26.body: 天色沉沉，程靖霖回到了药房。

＋ n26.body: 灯点上了。（"哪里也不去"分支）
＋ 或
＋ n26.body: 天色沉沉，程靖霖回到了药房。（送药分支）
```

**建议改法**（不新增节点、不动连线，只按入边分化文本）：
- 保持 `n26` 为汇合卡，文本改成**两种情形都成立**的中性句：
  ```
  ＋ 屋里点上了灯。
  ```
- 另在 `n27` 里用一句把"有没有出门"区分开（见下）。

### 改动 3：`n27` 的"擦板"按分支处理

```
− 他把板子上办好的事擦去，回身看向程时一。程时一没有细问。他站在柜台边，看了看年轻的伙计：

＋ 他抹了抹板子上的粉笔灰，回身看向程时一。程时一没有细问。他站在柜台边，看了看年轻的伙计：
```

> 说明：改成中性动作后，**两条分支都成立**；若想保留"擦"的成就感，则需按分支分写（要新增节点，成本更高，**不建议**）。

### 改动 4（连带）：`n29` 的"贴新事"改口

`n29.turns[1].line` 现状「板上的事，办一件，少一件。明儿还会有新的事**贴上来**」——"贴上来"是系统口吻。若 105 改由"没出门"触发牌局，此处宜同步弱化机制语：

```
− 板上的事，办一件，少一件。明儿还会有新的事贴上来。

＋ 板上的事，办一件，少一件。
```

> 若要保留"明天还有新事"的信息，建议移到【看板说明】卡（`n10`），不进人物台词。
