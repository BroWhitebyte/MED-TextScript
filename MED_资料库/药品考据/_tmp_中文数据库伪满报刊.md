> **核查日期**：2026-09-10（系统时间）
> **核查方式**：全部条目均由本次会话**实际发起 HTTP 请求**核实（`web_fetch` + `curl.exe` + `Invoke-WebRequest`），非凭记忆。
> **目标**：为设定在**伪满洲国 1942 年初、东北某县城**的历史叙事游戏，查清哪些中文报刊数据库能拿到 1942 年前后东北报刊的「白浊／花柳（性病）药品广告」影像或全文。
> **证据纪律**：凡广告原文均给「报刊名＋日期＋版次＋数据库名」。1930 年代材料一律标注年代，不当 1942 年证据用。访问失败如实记录 HTTP 码。

## 0. 一句话结论（TL;DR）

1. ⭐⭐⭐ **本次已实测找到并完整抄录出一条 1942 年伪满洲国的「白濁（淋病）」药品广告**——《盛京时报》**1942-03-01（康德九年三月一日）** 末页（页号 95899）「**五淋白濁　靈藥　特靈伯爾**」，制造商为「**滿洲第一製藥株式會社　奉天市大和區平和街**」。全文与价格见 **§2.1 A5**。
2. **唯一能免费、立刻拿到 1942 年东北报刊原报影像的渠道是「抗日战争与近代中日关系文献数据平台」（modernhistory.org.cn）**。免费、无需登录、无需机构 IP，且其**后端 API 与 IIIF 影像服务均可匿名调用**（实测打通）。
3. **但该平台的报纸是「纯影像、无 OCR」**：`白浊`／`花柳`／`淋病`／`梅毒` 在报纸库（`docType=bz`）检索命中数均为 **0**。**找广告只能按日期逐版翻**，不能关键词直达。
4. **爱如生确实收录《盛京时报》到 1944 年**（1906.10.18–1944.9.14），**1942 年在范围内**；且**只有它提供「影像＋录文」的全文检索**。但单报子库标注「2024 启动、预定 2026 出版」，定价未公布、机构授权（详见 §1.1）。
5. **《全国报刊索引》（cnbksy.com）全线 HTTP 412，被「瑞数」JS 反爬挡住**，本次**一个字节的页面内容都没取到**。
6. **孔夫子条目 84226679 抄不到**：HTTP 200 但返回「抱歉，请登录以后再进行访问。」——需登录，本次无法读取正文。**未编造任何内容**。
7. **学术界的空白恰好被本次一手发现填上**：并行文献检索（§2.3）确认，**没有任何学术论文引用过《盛京时报》1942 年的性病广告**——现有《盛京时报》医药广告研究的实例年代下限是 1940 年（孙秀蕙 2020 的 20 条实例中仅 2 条属 1940 年代：1940.5.4、1940.6.24）。**§2.1.1 A5 那条广告是本次新发掘的一手材料。**
8. ⭐ **免费平台上 1942 年在库的伪满报纸共四种**（均经独立复核）：《**盛京时报**》（沈阳，1942 全年）、《**大同报**》（新京／长春，伪满机关报，**1942-01-01 至 1942-10-31**）、《**泰东日报**》（大连，1942 全年）、《**滨江日报**》（哈尔滨，1942 全年）。**它们的末页都是整版医药广告版**（§2.1.2 已实测《大同报》1942-09-01 末页）。
9. 🔴 **年代错位警告（对 1942 设定致命）**：任务书点名的《**康德新闻**》**1943-07-01 才创刊**；《**满洲报**》1937-07-31 停刊；《**滨江时报**》《**国际协报**》均 **1937-10-31 停刊**。**这四种在 1942 年都不存在，剧本中不可出现。** 详见 §4.5。
