# 日本侧「白濁／淋疾／梅毒」性病卖药广告 可核查出处调查报告

**调查目的**：为设定在**伪满洲国 1942 年初**的历史叙事游戏，收集日本侧性病卖药（売薬）广告的可核查影像与文本出处。
**重点年代**：昭和前期（1926—1945），尤重 1935—1943。
**调查日期**：本次会话实测（NDL 数字馆藏 API / IIIF 实际取图验证）。
**调查者**：资料搜寻子代理（DeepSeek Harness）

---

## 0. 方法论与「实测」声明（请先读这一节）

本次全部结论均来自**实际 HTTP 访问**，未依赖记忆。使用的通道与验证手段：

| 通道 | 端点 | 实测结果 |
|---|---|---|
| NDL 搜索 API（书目） | `https://ndlsearch.ndl.go.jp/api/opensearch?any=<KW>&cnt=200` | ✅ 可用，返回 RSS/XML，含 PID、年代、出版者、体裁 |
| NDL IIIF Manifest | `https://dl.ndl.go.jp/api/iiif/<PID>/manifest.json` | ✅ 可用；**这是判定访问等级的关键** |
| NDL IIIF 取图 | `https://dl.ndl.go.jp/api/iiif/<PID>/R0000001/full/1400,/0/default.jpg` | ✅ 可用（仅限公开件） |
| NDL 逐页全文检索 | `POST https://dl.ndl.go.jp/api/fulltext/search` | ✅ **可用**（需正确 `bids`），返回**页序号 + 关键词前后文** |
| NDL 件元数据 | `https://dl.ndl.go.jp/api/item/search/info:ndljp/pid/<PID>` | ✅ 可用，含 `contentsBundles` → 取得 `bids` |
| NDL 全文 JSON 直取 | `https://dl.ndl.go.jp/contents/<PID>/<bid>/extra/fulltext.json` | ❌ **HTTP 403 Forbidden** |
| NDL 前端搜索页 | `https://dl.ndl.go.jp/search?keyword=白濁` | ⚠️ Vue SPA，`web_fetch` 返回空壳，**需 JS** |

**访问等级的实测判定法（重要，可复现）**：
`manifest.json` 返回 **HTTP 404** ⇒ 该件**非互联网公开**（属于「図書館・個人送信限定」或「国立国会図書館内限定」）。
`manifest.json` 返回 **HTTP 200** 且 metadata 中 `"Access Restrictions"` = **`PDM`** ⇒ **互联网公开，可直接取图**。

实测命中率极低：**共探测约 130 个候选 PID，仅 25 个为互联网公开（PDM）；其中与性病／广告直接相关的仅 18 个**。
绝大多数昭和前期医薬品广告载体（業界誌・新聞縮刷版・貼込帳・商品目録）均为送信限定或馆内限定。**其中「医海時報」全部抽样件、以及《薬業往来》1942-01 等最贴近 1942 年的件，实测全部 404（非公开）**——这是本次调查最大的结构性障碍。

**本报告最重要的成果**：找到并**下载验证**了一份 1936 年官方调查原件，其中含**「花柳病ニ關スル賣藥調」**统计表——即当时日本官方对性病卖药的全国性统计。详情见 §2。

### 1.3 【C 级】白濁／淋疾 命中但**非性病语境**（必须排除，勿误用）

实测全文检索结果，**「白濁」在昭和前期文献中大量出现但与性病无关**。这是重要的证据纪律提醒：

| # | 資料名 | 年代 | 页码 | 原文片段 | 判定 |
|---|---|---|---|---|---|

| C2 | **最新小児病手当法**（至誠堂書店） | 1914（大正3） | 第5・28・29コマ | 「小兒ノ[[白濁]]尿ニ就テの心得」 | ❌ **小儿乳糜尿/浑浊尿，与性病无关** |
| C3 | **古方日用簡易診療篇**（岸原鴻太郎） | 1936（昭和11） | 第5・20・26・28・54コマ | 「赤[[白濁]]」「小便滑數、遺精[[白濁]]」 | ⚠️ **汉方古典术语（赤白浊＝淋浊/遗精），与近代性病卖药概念部分重叠但非同一体系** |

> **给考据的结论**：在中文/日文史料里检索「白濁」，必须逐条排除①蒸馏浑浊物②小儿浑浊尿③汉方「赤白浊」。**1930—1940 年代日本官方与医学文献更常用「淋病」「黴毒」「軟性下疳」而非「白濁」**（见 §2 实测数据）。

### 3.2 可由官方统计反推的「卖药商品结构」

1936 年 A1 第六表按都道府县统计「賣藥ノ種類及方數」，其表头**只有三类**：

1. **毒淋病**（＝淋病）
2. **黴毒**（＝梅毒）
3. **軟性下疳**

且表旁注明确「**從來藥局ニテハ醫師ノ處方箋ヲ要セズシテ賣藥セルコトアルモ**」——即**无需医师处方即可在药局买到**。这直接证明：**1942 年前后，日本本土存在针对淋病/黴毒/软性下疳的、非处方、全国流通的卖药商品类目**，且政府做过全国性普查。

**给美术/叙事的可用事实**：广告主打的三大适应症就是这三个词，且三者常并列出现（表头即并列）。年龄/性别细分统计见第24・30～33コマ（「娼妓花柳病患者數調」「密賣淫者檢擧人員及健康診斷成績」）。

### 5.3 美术/叙事的事实护栏
- 1942 年日本性病卖药广告的**三大适应症词**是「**淋病**」「**黴毒**」「**軟性下疳**」（可并列），官方文书用**旧字体「黴毒」**。
- 「**白濁**」在昭和前期**不是**性病的标准官方用语；如游戏要用，应设定为**民间/俗称**层级，并注意其在蒸馏、儿科、汉方语境中的歧义。
- 卖药广告在当时已可做到「**全紙二頁**」的巨型规模，且文案基调被同时代人批评为「**强制的**」。
- **不要凭空画「宮内省御用達」「勲章」「人体解剖図」**——本次未获任何实证。若要用，请先取得 D1/D5 核实。
