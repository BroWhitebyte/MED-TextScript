# 〇、给游戏设定的直接结论（先说答案）

1. **消治龙确实存在，1942年已上市**，是**磺胺噻唑（sulfathiazole）**制剂，上海信谊药厂出品，有针剂、片剂、药膏三种剂型，1938年10月已在平津《大公报》上公开登广告。→ **人物知道这个名字、听说过这个药，是完全成立的。**
2. **在伪满洲国的县级城镇，一个中国平民「能弄到」磺胺，但不能在普通药铺随手买到。** 伪满自1940年6月20日起施行《物价及物资统制法》，对医疗物资的**生产、输入、配给、价格**实行全面统制；1941年7月25日又颁「物价停止令」，一切物资纳入配给。药品走的是**配给+黑市**双轨，中国商人配额既少又差。→ 合理路径是：黑市、走私、日本/朝鲜人药商、军队或满铁医院流出的货、以及「托关系」。
3. **价格查不到1941–42年磺胺的直接报价（明确「查不到直接证据」）。** 但可以给出可用的锚点（见第六节），其中最有用的是：**1942年1月延安1石小米＝法币630元**、**1941年12月重庆金价黑市2400元/两**、**1941/1942年河南小学教员月薪18元 / 28–30元**。照此推算，一支磺胺针剂在1942年初大致相当于**数元至数十元法币**量级属于合理想象区间——但**这是我给出的推算区间，不是史料数字，必须明确标注为推算**。
4. **最贴合本作设定的两个细节**（都有一手来源）：
   - 1942年（正是游戏时段）天津日伪当局查抄了为根据地供药的**上池馆大药房**（第一次查抄1938年，第二次1942年，第三次1944年）。→ 说明「药房供药」在当时是会被查抄的**真实风险**。
   - 伪满「在各县均设置了由日本人负责的参事官」。→ 你的县城里有一个日本参事官，是史实。

# 一、消治龙（上海信谊药厂）

## 1.1 成分 ＝ 磺胺噻唑（sulfathiazole）★已核实，一手回忆录

**决定性来源：李靖《土法自制"洋药"》**，上海市新四军历史研究会供稿，上海热线 2022-03-03
URL：https://news.online.sh.cn/news/gb/content/2022-03/03/content_9891816.htm
分类：**回忆录**（作者李靖，1927年生，上海南汇人，1945年参加革命；时任华中军区第一后方医院一大队药房材料干事）

原文逐字引用（三处互相印证）：

> 「先少量试制，用4.5公分（克）的**纯磺胺噻唑（"消治龙"）**结晶，溶解于4%的氢氧化钠溶液中……」

> 「只能用酚酞指示剂比色方法来对比自制的"消治龙"注射液与**从敌占区买来的"消治龙"注射液**的碱性反应，观察二者所显示的颜色是否相同？」

> 「药房共发出：外购的**磺胺噻唑**注射液132支（合660毫升），自制的磺胺噻唑注射液860毫升；外购的**磺胺嘧啶**注射液50支（合250毫升），自制的磺胺嘧啶注射液3330毫升」

**推论（重要）**：作者把「消治龙」与「磺胺噻唑」直接画等号，同时把「磺胺嘧啶」作为**另一个并列品种**列出。故：
- **消治龙 ＝ 磺胺噻唑**，不是磺胺嘧啶，也不是氨苯磺胺。
- 该回忆录时段为**1947年（解放战争）**，不能直接证明1942年的成分，但**是同一品牌同一药厂**，是现存最直接的成分证据。

## 1.2 旁证一：地方志把消治龙列为「磺胺类抑菌药」

**《栖霞县志·第四节 医疗用药》**（山东烟台栖霞县）
URL：https://shandong-chorography.org/database/c63/section/2/article/590/
分类：**地方志**（山东地方志资料归档镜像；原链接 lib.sdsqw.cn 已失效）

原文逐字引用：

> 「1937年（民国26年）后，**磺胺类抑菌药**开始在县内各诊所应用，如**消治龙、大健皇、旁浊甫清、阿克知皂儿、知示知尔**等；抗螺旋体类如"606"注射液、"914"注射液、砒素制剂等；抗疟类如奎宁片剂、针剂等。1941年（民国30年），呋喃西林、呋喃唑酮、海群生、**消发灭丁**、斯锑镁散、斯锑波霜、斯锑保民等西药相继在县内应用。」

要点：
- 官方县志把**消治龙明确归入「磺胺类抑菌药」**——与1.1互相印证。
- **「大健皇」**：这正是任务中「大健磺」的音近形态！见 §2.4。
- 名单后半段（旁浊甫清、阿克知皂儿、知示知尔）疑为外文商品名的转写或OCR讹误，**不作考据依据**。
- 「消发灭丁」（1941年）应为磺胺类药物的音译商品名（疑为 Sulfamidine 系），**未能确证对应哪个具体化合物**。

## 1.3 旁证二：企业史标准文本 —— 抗战初期投产，用**进口原料**

同一段文字至少三处独立出现（互为印证）：

- 「上海信谊药业有限公司」词条（2008年创建，我的钢铁百科转录）：https://baike.mysteel.com/doc/view/27668.html
- 快懂百科「上海信谊嘉华药业有限公司」：https://www.baike.com/wikiid/3205423013017803539

分类：**企业史／二手**

原文逐字引用：

> 「1916年，德国药学博士霞飞在上海开设了信谊大药房，随后在1924年，霞飞博士和我国药剂师何子康合资创建了信谊药厂……1937年，德国股东霞飞退股回国，信谊药厂扩股成为真正的中国民族企业。**抗战初期，信谊药厂率先利用进口原料，制成"消治龙"针、片剂**，产品畅销国内及东南亚一带，被誉为"云中之龙，药中之王"，当时，信谊药厂堪称远东第一大药厂。」

快懂百科版补充（**宣传口径，与上条有张力**）：

> 「信谊"消治龙"是中国人最早自主研发的抗菌注射液，打破了当时抗菌素完全依赖进口的局面。」

**⚠️ 口径冲突，必须标注**：
- 「**利用进口原料**」＝ 进口磺胺原料粉，在国内分装/制剂。（与磺胺噻唑1939–40年才在西方上市的时间线，以及中国当时不具备磺胺原料合成能力的事实相符。）
- 「**自主研发**」＝ 企业宣传语的拔高。若游戏要严谨，应采信「**进口原料、国内制剂**」。

| **晚** | 「**上个世纪40年代**，畅销全国和东南亚地区的"消治龙"针剂和片剂首次摆脱国人依靠进口原料生产消炎类制剂的局面」 | 中新网 2016-12-29 http://www.chinanews.com.cn/cj/2016/12-29/8108738.shtml （**原站GB2312乱码**，网易转载可读：https://m.163.com/dy/article/GDNSO7F00525CR59.html ） |

**广告实证把上市时间钉在1938年**（见§7）：1938年10月10日《大公报》第10版广告已含「**消治龙药膏**」。故**1942年1月，消治龙已上市约4年**。

→ **查不到直接证据**能厘清1938–1940年间消治龙成分的演变。若游戏设定在1942年，采用「消治龙＝磺胺噻唑」是有1947年一手回忆录支撑的；但若要写1938年，需谨慎。

## 2.3 关于「消治龙＝磺胺噻唑」的证据强度说明（重要）

本核查中，一条子代理的检索结论曾记为「消治龙=磺胺噻唑**查不到直接证据**」。**该结论已被推翻**——本报告 §1.1 找到了**直接的一手回忆录**（李靖《土法自制"洋药"》，上海市新四军历史研究会供稿），其中**逐字把「消治龙」与「磺胺噻唑」画等号**，并把「磺胺嘧啶」列为并列的另一品种。
→ 因此本报告采信：**消治龙 ＝ 磺胺噻唑**（证据等级：★★★，一手回忆录）。
→ 需要保留的限定：该回忆录叙述的是**1947年**的事；**1938–1940年间消治龙是否已是磺胺噻唑，仍查不到直接证据**（见§1.4存疑点）。

## 2.6 ★「大健磺」—— 关键澄清

**任务中提到的「大健磺」，本次核查的结论是：**

- **「大健磺」三字本身：多个引擎、多种异体写法（大健黄／大健凰／大建磺）检索全部无结果。查不到直接证据。**
- **但找到高度相关的「大健皇」**：《栖霞县志》把它与「消治龙」并列，明确归入「**磺胺类抑菌药**」。（见§1.2，https://shandong-chorography.org/database/c63/section/2/article/590/ ）
- **判断**：「大健磺」极可能是「**大健皇**」的异写或口传讹变（磺／皇 音近），而「大健皇」是**真实存在、且在山东县城被实际使用的磺胺类药商品名**。

# 十、一页结论（给游戏主创）

| 问题 | 答案 | 证据等级 |
|---|---|---|
| 消治龙是什么？ | **磺胺噻唑**（sulfathiazole），上海信谊药厂，针/片/药膏 | ★★★ 一手回忆录 + 地方志 |
| 1942年1月它存在吗？ | **存在**，已上市约4年（1938年10月已有《大公报》广告） | ★★★ |
| 中国平民在伪满县城能买到吗？ | **能，但正规渠道极难**。伪满1940.6.20《物价及物资统制法》对医疗物资生产/输入/**配给**/价格全面统制；1941.7.25「物价停止令」纳入一切物资；中国商人配额「少而差」 | ★★★（制度）／★★（执行细节为通俗综述） |
| 别的中国人知道这个药吗？ | 知道。消治龙与香烟、鞋、牙膏、奶粉同版广告，是**大众消费品** | ★★★ |
| 有多贵？ | **查不到1941–42年直接报价。** 可用锚点：1942年1月延安1石小米＝法币630元；1941年12月重庆金价黑市2400元/两；1941/42年河南小学教员月薪18元/28–30元 | ★★（锚点）／✗（药品直接价） |
| 药从哪来？ | 日占区城市（天津、北平、上海）→ 地下交通线 → 根据地。**信谊药厂自己的副经理陈铭珊1942年就在为新四军采购消炎药** | ★★★ |
| 风险？ | 极高。1942年天津上池馆大药房因供药被日伪搜查（1944年第三次被抄，159种药品装7卡车，少东家29岁死于日军监狱） | ★★★ 档案 |
| 「磺胺比黄金还贵」能写吗？ | **不要当史实写。** 该说法目前只能追到2026年一篇学生诵读稿；可信的替代表述是徐锋华（上海社科院）：「消炎用的磺胺药片十分珍贵，往往只有重伤员才能用」 | ★★★（替代表述） |
