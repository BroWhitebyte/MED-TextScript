## 0. TL;DR —— 三句话结论

1. **最硬的一手材料已经拿到**：1942 年伪满《盛京时报》上的**「五淋白濁」藥品廣告全文可读影像**，来源免费、免登录、可 IIIF 直接取图。✅【本人实测·亲眼读图】

# 第二部分 · 自行扩查的来源

## 2.1 ★★★ 最大收获：《近代城市小報資料庫》的免登录元数据 API

✅【本人实测·完整逆向并跑通】

用户原有的 `mhdb` 入口是**检索表单页**；真正的数据接口是 AJAX。我把整条链路挖通了：

### （a）检索接口（免登录、免注册）

```
POST https://mhdb.mh.sinica.edu.tw/newsp/searchResult.php
Content-Type: application/x-www-form-urlencoded; charset=UTF-8
Referer: https://mhdb.mh.sinica.edu.tw/newsp/newspaper.php

para=<base64( UTF-8 JSON )>[&page=<页码>][&filter=<base64(JSON)>]
```

`para` 解码后的 JSON 形如：

```json
{"searchStr":"白濁","year":"1942","month":"","day":"",
 "searchStrForAuthor":"","searchLimit":"1","advance":"no"}
```

- 每页返回 **100 条**；`page` 从 1 起。
- 首元素是汇总：`{"total":376,"target":"…","now":1,"uuid":"…"}`。
- `filter` 支持 `newsNameLimit`（限报刊）与 `yearLimit`（限年份）。

### （b）返回字段（**这就是做引用所需的全部信息**）

```json
{"no":1,
 "title":"感謝採芝堂大藥房靈藥治愈白濁梅毒",
 "kind":"江蘇日報",          ← 報名
 "author":"本報訊",           ← 廣告主 / 刊登者
 "cate":"中西藥業",           ← 分類
 "brand":"新樂的能",          ← 品牌
 "papernum":"3",              ← 版次  ★
 "date":"1942-01-01",         ← 日期  ★
 "listno":816179}             ← 系統代碼 ★（＝TELDAP 目錄的「系統代碼」）
```

### （c）原书影像接口（**需登录**）

```
GET https://mhdb.mh.sinica.edu.tw/newsp/image.php?kind=<報名>&listNo=<系統代碼>
```
→ 未登录时返回**登录页**（`/login/check.php`、`/login/newuser.php`、`/databaseLogin.php`）。
官网说明该库「**已于 2015 年底开放外界申请使用**」——即**可申请账号**，但**需人工申请/审批**。

### （d）TELDAP 联合目录的等价检索（另一条备用入口）

✅【本人实测】台湾「数位典藏与数位学习联合目录」完整镜像了该库的元数据，**且可按年/月/日逐级浏览**：

```
检索：https://catalog.digitalarchives.tw/Search/Search.jsp?QS=<Big5编码关键词>&log=CIDLog&CID=<类别ID>
分类：近代城市小報 = 69136 ／ 江蘇日報 = 86859 ／ 該報 1942 年 = 86946
     1942 年各月：01月=86947 … 10月=87228 … 12月=87291
```

> **⚠️ 两个必须知道的坑**
> 1. **该站是 Big5 站**。`QS` 参数必须用 **Big5** 编码（如「白濁」→ `%A5%D5%BF%42`）。用 UTF-8 会得到**完全无关的结果**（实测把「白濁」变成匹配「賣」字的 5 万条噪声）。✅【本人实测】
> 2. 目录页的正文含 **HTML 数字实体**（如 `橫痃` 的「痃」在源里写作 `&#30147;`），解析时必须反转义，否则会读成 `?`。✅【本人实测】

**该库按年统计（✅本人实测，TELDAP 分类页）**——《江蘇日報》1942 年全年共约 **46,000 笔**，逐月：1月 4,173／2月 3,555／3月 2,893／4月 4,615／5月 2,861／6月 3,847／7月 3,902／8月 3,827／9月 3,498／10月 4,422／11月 4,137／12月 4,458。（**可逐日浏览**，每日约 120–150 笔。）

## 2.2 ⚠️ 检索范围的决定性限制：**只索引标题，不索引正文**

✅【本人实测·关键结论】

| 检索词 | 1942 年命中 | 判读 |
|---|---|---|
| 白濁 | **376** | 全部命中项标题含「白濁」 |
| 淋病 | 249 | 标题含「淋病」 |
| 下疳 | 88 | 标题含「下疳」 |
| 淋漓 | **1** | 该唯一命中项标题为「平門內東蔡家橋河旁　昨發現無名男屍　血汚淋漓騐明刀傷五處」——**新闻标题，非广告** |
| 刺痛 | **0** | — |
| 魚口 | **0** | — |
| 便毒 | **0** | — |

**结论：凡不出现在标题里的症状词，一律搜不到。**
→ **「小便刺痛」「溺时如刀割火灼」「窍端秽物淋漓不断」这类只写在广告内文里的句子，无法通过关键词获得，必须逐张打开影像（需登录）人工阅读。**

**这直接决定了项目的可行路径**：关键词层能拿到「**哪些广告存在、何时、第几版、誰登的**」；但「**广告里怎么描述症状**」只能靠**看影像**。

◻【子代理实测】**内容属实，但卷次与用字须修正**：

1. **1908 年博医会标准词典**（Cousland, *An English-Chinese Lexicon of Medical Terms*，哈佛藏本，◻子代理逐页读图）：
