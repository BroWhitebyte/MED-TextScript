# 写手速查卡 · 1942年伪满县域药品（1页版）

> 用途：写戏时随手查。**只留能直接用的**，证据与文献URL见三份完整报告。
> 全部结论均经档案/原始文献核验；标注【虚】者须在文案中视为合理虚构。

---

## 一、根本判断（先记这三条）

1. **青霉素在1942年初的东北＝不存在。** 准确说法：只以极微量实验性形式存在于牛津与少数几个美国站点，**不构成任何可获得的治疗手段**。（1941-02牛津首例；1942-03美国首例Anne Miller）
2. **医生"听过青霉素这个名字"是可以的**（1940—41《柳叶刀》已有报道）——**可写"听过名字，但知道那东西弄不到"**。这比"没听说过"好用。
3. **1942年的救命药是磺胺**，但它**救得了肺炎、救不了枪伤**——这是本作医学世界的铁律。

---

## 二、药效铁律（决定剧情走向）

**磺胺有效的**：链球菌病——丹毒、肺炎、产褥热、流行性脑脊髓膜炎。
**磺胺失效的**：
- **脓／创伤／脓肿**——脓液含抑制物，且**组织自溶后抑制物大幅增加**；PABA拮抗（**0.02—0.1 µg PABA 即可逆转 570 µg 磺胺**）
- **气性坏疽**——*Cl. welchii* 需 **50—200 mg%** 才被抑制（其他梭菌仅需 1—3 mg%）；小鼠三天存活率**磺胺噻唑7% vs 青霉素99%**

→ **抗联伤员、老孙D4—D9的伤、D27盟军飞行员，全都落在磺胺无效的那一侧。**

**"看着好了、停药就死"是真的**（原始文献逐字）：感染III型肺炎球菌的小鼠"在给药期间保持健康，但**一旦停药，大多数就死了**"。临床对应：**10%复发率，几乎全部与过早停药相关**。

**同一种药，救得活谁取决于入院时有多重**：

| 病人类型 | 病死率 |
|---|---|
| 磺胺嘧啶时代总体 | 约 **7.2%** |
| 血培养阳性 | **21.5%—27%** |
| 肺炎球菌菌量 >100菌落/cc | **44%** |

## 三、四张道具卡

### 卡1 · 磺胺（スルファミン）★核心道具

| 项 | 内容 |
|---|---|
| 外观 | **白色**结晶粉末或片剂。**红色＝德国百浪多息，日军档案零命中，禁用** |
| 服用 | 片剂常在**研钵中捣碎**混入**牛奶或可可** |
| 针剂 | 钠盐溶液**强碱性 pH 10.5—10.8**、**绝不能煮沸**、**外推约15分钟**、**外渗会组织腐脱** |
| 剂量 | 初始 **4.0 g**，随后**每4小时1.0 g 昼夜不间断**；肺炎热退后再用 **72小时**；脑膜炎热退后再用 **7天**；肺炎**强制入液 3,500 cc／日**（**美军TM 8-210标准；日军方案查不到，若写日本军医照此执行须标【虚】**） |
| 可见效果 | **丹毒最上镜**：第1天结束前皮损停止蔓延 **96.9%**（紫外线组59%）；48小时无发热 **75.2%**（对照组47.3%） |
| 副作用 | **发绀**（58%高铁血红蛋白血症；停药24—72h可逆，硫化血红蛋白**永久不可逆**）；**粒细胞缺乏0.1—0.3%，第17—25天最多见**——⚠️**危险期在病人"看起来已经好了"之后** |
| 肾 | **结晶尿约1/4病例**；**11 g／4天可致双侧输尿管完全阻塞**；血药浓度不是肾脏安全指标 |
| 稀缺机制 | **不是单价贵**（1942美军一个肺炎疗程<1美元）——是**配给权限**＋**总量**（肺炎33—62片、脑膜炎约144片＝**1/7瓶**） |
| 珍贵度铁证 | USSBS："sulfaguanadine was **so small that it was used only by the Army**"（讲的是磺胺胍治痢疾；页码未核）<br>李靖回忆录："一个月领到的磺胺类针剂，**只够伤病员2至3天的需用量**" |
| **⭐军工需占比（USSBS第159/160表）** | 日本磺胺类总产量 **1943年229.5吨 → 1944年78.4吨 → 1945年11.5吨**；**军用占比：1942年25.2% → 1943年30.7% → 1944年34.4% → 1945年39.7%**<br>→ **1942年是"药还有，但已经开始紧"的那一年；真正枯竭在1944—45年** |
| **日本从无拜耳授权，也不需要** | 1909年《专利法》修正建立「**工程特许**」（**工艺专利**）——"改变工艺即可合法生产销售外国新药"（国立科学博物館调查原文）。日本药企走的是**合法逆向工程** |

### ⭐⭐ 卡1补 · 两张"真药也可能是毒药"的硬档案（本卡最强道具）

| 道具 | 内容 |
|---|---|
| **劣药** | **1941年市售磺胺57%不符合日本药局方标准**（厚生省抽检7种商品）；官方报告抱怨劣质品**盗用药局方名义**销售。→ **买到的"磺胺"可能是假药或劣药，且这在1941年是多数情况。** |
| **毒针** | **テラポール注射液含二甘醇／乙二醇作溶剂**——1942年官方报告点名，称其为「**米國に於て多數の人命を奪ひたる恐るべき毒物**」，要求在日本同样禁用（美国1937年磺胺酏剂事件**死105人**）。→ **注射剂本身可能致死，且当时刚被发现。** |

**→ 合起来＝"买到的药可能无效，打进去的针可能致死"。给"程时一要不要用这支药"的戏，这是现成的两难。**
（来源：厚生省東京衛生試験所彙報第59號，1942，寺田论文——**一份"当时日本市场实际在售商品名"的官方表**）

**可引用的原话（给"自己也在吃药的人"）**：
> "那些自己吃过这药的内科医生，都向同事说得清清楚楚：**问题在于到底是治疗更糟，还是疾病更糟。**"（*Edinb Med J* 1948;55(12):715）

### 卡2 · 酒精／甘油／水银 —— 最"不像药"的禁运品
- 档案里与药品并列运输的战略物资；天津上池馆案明载
- **伪装手法（档案级）**：水银**灌入自行车车胎**；药品**改装成滋补药品**；蒲包装药码在渔船里、**上铺防水油布、放上水再撂点活鱼**
- **用途**：药房里"本来就该有"，却是禁运品——**天然隐蔽道具**

### 卡3 · 破伤风血清 —— 最"重"的一样
- 1942年日军军医**随身囊标配**（塩川優一《軍医のビルマ日記》）
- **需冷藏、效期短** → 县城维持不了冷链
- ⚠️ **同一份清单里没有磺胺** → **血清＝个人级；磺胺＝上级审批级**（用规定外药品须**师团／军军医部长批准**）

### 卡4 · 麻醉与成瘾品
- **モヒ液（盐酸吗啡）**、**阿片錠**、**ヴェロナール（巴比妥）**：军医随身囊标配
- **氯仿、乙醚**：任何手术单位必需，县城西医诊所几乎不可能有
- 伪满有鸦片专卖—瘾者登记—配给体系；日文档案载"日本药房贩吗啡成风"

## 五、禁忌清单（凡写即错）

**药理/史实穿越**：
1. 红色百浪多息出现在日军手中（德国药，JACAR零命中；日军制式用语是「**スルファミン**」，**白色**）
2. 1940年代铜绿假单胞菌耐药的生化机制（**当时该机制尚不存在**）
3. 任何"一战vs二战气性坏疽病死率对比"（**一战数据查不到**）
4. 1942年常规配碳酸氢钠（**TM 8-210已明文取消**；可写"老医生坚持旧法"但须点明已过时）
5. 1942年青霉素可得
6. 1942年"黄金存款／储蓄券"（**1944年9月才开始**）
7. "磺胺比黄金还贵"（**查不到可靠出处**，属文学化）→ 改用徐锋华："消炎用的磺胺药片十分珍贵，**往往只有重伤员才能用**"
8. 「大健磺」→ 应写「**大健皇**」

**商品名／厂商／品种（新）**：
9. **磺胺嘧啶（スルファダイアジン）出现在1942年**——USSBS第159表所列1943—45年日本品种**只有 Sulfanilamide、Sulfapyridine、Sulfathiazol、Sulfamethylthiazol 四种**，全文检索 `diazine` **命中0次**；日本首次上市＝**1948年**（第一製薬テラジアシン）
10. **给武田／三共／星製薬／持田／日本新薬安磺胺商品名**——这几家**全部查不到磺胺品牌**（持田社史1935—1951年无任何产品＝**正面否定**）。可用的：**テラポール＝第一製薬**（1937.7）｜**ゲリゾン、アルバジル＝山之内**（战时产日本磺胺30%以上）｜**アクチゾール、ウリノーゲン、アヂプロン＝塩野義**
11. **「アルブシッド」＝「アルバジル」**——**完全不同**：Albucid 活性成分是 **sulfacetamide（磺胺醋酰）**，日本名 **ネオポレオン／レギオン**；アルバジル 是 **Uleron型二基磺胺**（「アルバジール（邦製ウリロン）」）
12. **「ネオプロントジル」**——不是日本商品名；当时作「**水溶性プロントジル**」

**不得编造的数字**：淋病治愈率百分比 · 磺胺嘧啶专属MIC · 1942年耐药率百分比 · 创伤感染对照试验数据 · 民用/英国零售价 · 磺胺醋酰眼药水 · 再生障碍性贫血发生率 · "1937年磺胺酏剂107人死亡"（博物馆级证据，非一手）· 1940—42年分品项产量 · 满洲磺胺产量

## 六、精神内核（一句话）

> **这些药在县城之所以珍贵，不是因为稀有，而是因为它们的来源只有占领者体系。**
> **一个中国药房柜台上出现日文标签的白色药片——它本身就是破绽。**

药越珍贵，账越致命。（咬合：账本＝代价账本／D16除夕搜家／"接错轻则坏事重则死人"）
