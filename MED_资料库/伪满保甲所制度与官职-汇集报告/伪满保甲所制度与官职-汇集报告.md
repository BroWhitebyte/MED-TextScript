## 〇、结论速览

1. **法律依据**：《暂行保甲法》（1933-12-22）＋《暂行保甲法实施细则》（1934-01-17）；编制"**保—甲—牌**"：10户1牌→10牌1甲→10甲1保【档案】。
2. **主管**：省警务厅司法科主管；**各县配专职"保甲指导官"（日系）**【档案】。
3. **职能五块**：户籍连坐（核心）／治安警戒／经济统制执行（出荷·配给·经济犯）／劳务征派／宣抚监视。
4. **1942年时点**：街村制（1937—1939）后行政经济职能渐归街村公所，**保甲保留并强化治安职能**；三江、东安、北安等抗联活动区盘查最严——MED时间线正处"赵尚志事件后盘查升级"期【研究·档案】。

## 一、制度骨架

- **编制**：10户1牌（牌长）→10牌1甲（甲长）→10甲1保（保长），一保约千户【档案】。
- **主管机关**：伪警务司及省警务厅设**司法科**主管保甲事务；各县配备专职**保甲指导官**（日系）【档案】。
- **配套**：保甲＋连坐＋伪自卫团三者强制结合；编印"保甲歌""保甲五训""保甲十训"，设"保甲日"灌输【档案】。
- **1942年时点**：1937—1939年街村制（县城＝街公所、农村＝村公所）推行后，行政经济职能（出荷、配给、劳务）渐由街村公所承担，**保甲保留并强化治安职能**——尤其在三江、东安、北安等抗联活动区【研究·档案】。

## 二、保甲所（保公所）的职能覆盖范围

**保甲所＝保长办公处**，是保甲制在村/屯/城区的实体办公点，职能分五块：

### 1. 户籍与连坐（核心）
- 户口编查、门牌管理（十家连坐门牌）、人口异动登记；牌内居民**来客留宿、出入必报告**；"每隔几天就要查户口、查夜"【档案】。
- 连坐：牌之住民犯**内乱罪、外患罪、公共危害罪、《暂行惩治叛徒法》之罪**，牌内各户**连坐金**惩罚；"通匪"株连左邻右舍【档案】。
- 牌长、甲长**定期汇报居民动态**【档案】。

### 2. 治安警戒（军警的"末梢"）
- 协助警察搜查、戒严、查夜；冬季夜巡（MED的1—2月正值最严期）。
- 组织**保甲自卫团**（壮丁，农闲训练，警戒防御，作军警补充）；1935年底黑龙江地区自卫团超百万人【档案】。
- 集团部落内：部落中央设伪军警派出所＋村公所＋拘留所＋自卫团＋协和会＋特务，出入搜身查证明【档案】。

### 3. 经济统制执行（1940年代后逐步加码）
- **出荷催缴**（出荷督励的基层执行面；与屯长、兴农合作社协作）；**搜荷**（入户搜粮、没收种子粮）【档案·MED库民生政策】。
- **配给发放**（1941年《生活必需物资配给要纲》后，配给票/配给粮发放点常设于街村公所与保甲所；集团部落内"只能靠配给的苞米面、橡子面、谷糠过活"）【档案】。
- **"经济犯"检举**（私藏粮谷、食米、棉布——保甲长是眼皮底下的检举人）【档案·回忆】。

### 4. 劳务与征派
- 劳工征发、勤劳奉公征派的名单编造与催征；修筑工事、道路的夫役摊派【研究】。

### 5. 宣抚与监视
- 保甲日训话、"保甲五训"灌输；检举"反满抗日"思想、监视可疑往来（抗联侦察员多在此层暴露——杨靖宇1940年即因**濛江县保安村伪牌长赵廷喜**告密牺牲【档案】）。

## 三、官职称谓（三层系统）

| 系统 | 称谓 | 说明 |
|---|---|---|
| **保甲系统** | 保长 | 一保之首，办公于保甲所（保公所）；多由当地士绅/富户充任，靠摊派与津贴；见警察点头哈腰，对牌甲长则摆谱 |
| | 甲长 | 管约百户（十牌）；出荷催缴、户口异动报告的直接经办人 |
| | 牌长（十家长） | 管十户；连坐的责任节点；来客报告、门牌管理 |
| | 保公所书记/雇员 | 办文书、造册、算账（出荷/配给名单） |
| | 保甲自卫团团长／副团长／团丁 | 壮丁武装；常备团与散在团（农闲集合） |
| **警察主管系统** | 警察署长（日系） | 城内保甲所的直辖上司 |
| | 警尉／警尉补（管区） | 分管一片保甲的日本或日系警官 |
| | 警长、警士 | 查户口、查夜、抓人的实际执行者 |
| | 县警务科（警务局） | 统筹；省警务厅司法科主管保甲事务 |
| | **保甲指导官（日系·县配专职）** | 专司督导保甲运作的日本警官——县城里"管保甲所的人"【档案】 |
| **街村并行系统** | 街长（县城）、村长（农村）、屯长 | 行政与经济（出荷/配给/劳务）名义主体；屯长与甲长职能高度重叠 |
| | 街村公所事务员 | 配给票、劳工册经办 |
| **其他** | 协和会分会（分会长） | 宣抚、储蓄、献金，与保甲并行 |
| | 集团部落内特务 | 监视居民（三江省等治安区） |

## 四、1942年县城保甲所的实际样态（MED落点）

- **位置与形态**：城内一保的保公所，通常挨着警察署或设在保长自家铺面/院落——一间屋、一张桌、户口册与出荷台账、门牌戳记；冬天炉子烧不旺，保长呵着白气按手印【推断·据制度样态】。
- **1942年1—2月最忙的三件事**：①出荷收官催缴＋"搜荷"（防止粮谷搬出县境）；②冬春治安盘查（赵尚志事件后2月中旬起升级）；③春节前后配给发放与"正月特配"【档案·MED库民生政策】。
- **对白/剧情钩子**：保长上门＝查"来客报告"（谁家夜里留了人——直接勾连时一堂药房夜线）；牌长检举私藏大米＝"经济犯"现成把柄；保甲所账本＝配给名单与出荷尾欠（可作黑材料）。
- **细节提示**：保甲长无正式俸给，靠摊派与灰色收入（"人家吃肉他喝汤"的棒子队民谣同款生态）；保长见日系保甲指导官要立正鞠躬【推断·据档案生态】。
