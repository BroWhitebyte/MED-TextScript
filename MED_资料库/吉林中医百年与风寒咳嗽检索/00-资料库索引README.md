### 4.2 风寒与咳嗽的用方（原文）

- **冬季外感**：`先师多以麻黄汤加大剂量双花、连翘收效甚好`（p224）
- **辛温解表**：郝志远 1918 年时疫，`取《五叶饮》一方，不拘格局，随证化裁`（p108）
- **通络导滞**：陈佐宾 1918 年时疫，`误投辛温则死，治以峻寒亦皆罔效`，改`加味凉膈散`（p102）
- **儿科自拟方**：金玺`清解散`『清苓散』『化滞散』『双解散』**『清肺止咳散』**（p106）
- **药性对句**：`麻黄宣肺祛痰，百合肃肺镇咳`（p199）
- **随证用方**：`恶寒汗出用桂枝`……`有是证，用是方`（p273）
- **风寒 vs 感冒的现场鉴别**：陈佐宾四岁男儿案——`此儿虽标为风寒外感，乃真为绝证！感冒发热，面色当红而光泽……风寒外感脉息应浮`（p122）
- **处方书写格式**（《吉林官医院章程》1908）：`先书病人男女、年岁、住址。次病状、次脉象。次主治、次方药`；挂号**绿签＝急病、红签＝寻常病**；官医出诊不收医金，贫者免车费（p27）

### 4.3 药铺内部（时一堂大药房的现成参照）

- 《长春文史资料 第60辑 长春老字号》「世一堂」篇：**前屋柜台、后屋大炕、院子里收购制作药材**（p19）；**坐堂先生**定义（p13）；学徒需保人引见、拜祖师发誓（p13）；柜头管抓药付药包药（p16）；抓药不用称（p19）；**撞笼「摆药阵」**（p27）；**尝药师不喝茶酒不吃糖抽烟**（p28）。
- 《吉林中医百年》p68：**坐堂先生按处方三七分成，医生得三、药店得七**；一剂汤药核价一人一样、差价不过 10%；「压单」药＝川贝、广砂仁、藏红花；以平贝充川贝；声誉受损叫「**臭腕子**」。
- 开业成本（p255）：借六十块钱租一间临街瓦房，向《志诚利》**赊销常用药材**，开业前多次花钱托人情跑警察厅呈请营业执照。
