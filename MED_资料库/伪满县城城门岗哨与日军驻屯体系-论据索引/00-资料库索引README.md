## 三、使用注意

1. **结论**：可能，但分状态——日常城门归伪满警察；戒严/驻屯态由关东军独立守备队（或师团警备部队）军曹带班；边境县为国境守备队/宪兵。
2. 军曹是岗哨负责人（分队长级），不是普通站岗兵；"关东军军曹"≠宪兵（帽徽/兵科不同）。
3. 写作落点：城门检查重点可挂钩1942年冬春"搜荷督励"（私运粮谷），与MED粮店/当铺场景勾连。
