## 〇、结论速览

1. 伪满县城医疗以**中药铺＋坐堂汉医**为主体（1935年调查：东北汉医10317人 vs 西医2497人，汉医占绝对多数）。
2. 汉医地位经历"1934改称汉医—1936《汉医法》—1937首考（302人仅6人合格）—1941《汉医考试令》＋满洲中央汉医会—1942《医林》创刊"的**打压—改造—有限承认**轨迹；名称更迭为"中医→汉医→中医"（详见1.1a/1.1b专节）。
3. 医疗能力边界：望闻问切为主、西药奇缺、外科极弱、传染病靠隔离封锁、地方病（克山病等）无策。
4. 常见病：鼠疫（1940农安）、霍乱（1932哈尔滨）、伤寒痢疾、天花麻疹＋克山病（快当病）大骨节病＋冻伤煤烟中毒＋痨病沙眼疥疮＋营养不良（1942年配给后加剧）。
5. 验方：獾油（冻伤烧烫）、桦树皮/稠李子（痢泻）、五味子/满山红（咳嗽）、硫磺膏（疥疮）、马勃粉（止血）、接骨木热敷（风湿）等——【民间】级叙事素材。

## 一、医馆与医疗设施记录（县城层级）

### 1.1 制度框架：汉医的"改名—取缔—改造"轨迹

|---|---|---|---|
| 1934年 | 伪满政府下令中医改称"汉医" | "去中国化"策略；除原持证者暂行医外，不再批准新中医开业，欲使中医自生自灭 | 【馆藏】北中医博物馆 |
| 1935年 | 日伪调查 | 东北西医2497人、汉医10317人；哈尔滨霍乱流行时日本人病死率高于中国人，日伪归因于中国人用中草药 | 【馆藏】 |

### 1.1a 名称更迭：中医 → 汉医 → 中医

| 时期 | 称谓 | 说明 |
|---|---|---|
| 民国时期（1912—1931） | 中医／国医（民间：大夫、郎中、先生） | 1929年"废止中医案"风波后"中医"称谓确立；1931年中央国医馆称"国医"；东北民间通行"大夫""药房先生"【研究】 |
| 伪满初期（1932—1934） | 沿用"中医"，官方调查口径转"汉医" | 1935年日伪调查"东北西医2497人、汉医10317人"——报告已用"汉医"【馆藏】 |
| 1934年 | **下令中医改称"汉医"** | 伪满"去中国化"策略之一：与日本"汉方医/汉医"话语接轨（明治后日本称"汉方医"，日治台湾亦称"汉医"）【馆藏】 |
| 1936—1945 | **"汉医"为唯一正式称谓** | 《汉医法》（1936）、《汉医认许证》（1937）、《汉医考试令》（1941）、满洲中央汉医会（1941）、《医林》（1942）——官方文书全用"汉医"【馆藏·研究】 |
| 1945光复后 | **恢复"中医"** | 东北解放区/国统区卫生建设中"中医"称谓回归（登记政策【待补】）【推断】 |

- **平行的名字游戏**：日本明治后"汉方医"贬为"草根木皮"【研究·张蒙】；朝鲜日治用"汉医"（光复后演为"韩医"）——"汉医"是日本殖民圈通用语，**改名的本质是把中国医学从"国族医学"降格为"殖民地的民间医学"**【研究·推断】；华北沦陷区（伪北大中药研究所）走"研究改造"另一路——伪满的"改称＋考试"最为系统【研究·张蒙】。

### 1.1b 职业资格：从"自生自灭"到"考试准入"

| 时间 | 制度 | 资格要件 |
|---|---|---|
| 1932—1934 | 过渡期 | 原民国执照/祖传师承从业者照旧行医，无统一登记【馆藏】 |
| 1934年 | 封堵新入 | "除原持中医资格证者暂行医外，不再批准新的中医开业"——欲使中医自生自灭【馆藏】 |
| 1936-11-26 | 《汉医法》（康德三年敕令） | 三要件：①实地学习汉医术5年以上 ②汉医考试及格 ③受主管部门大臣认可——方准行医【馆藏】 |
| 1937（康德四年） | 首次汉医考试 | 《吉林省志·卫生志》：302名应试者仅6名合格；合格者获"满洲帝国《汉医认许证》"（北中医博物馆藏实物）【馆藏】 |
| 1938—1940 | 考试续行、通过率低 | 无证行医取缔；汉医讲习活动渐起【推断·据制度逻辑】 |
| 1941年 | 《汉医考试令》《汉医考试令实行细则》 | 考试制度化——分两部：第一部理论（汉医学〔诊疗学·内外妇儿为主＋汉药学〕＋洋医学〔解剖、生理、防疫〕）；第二部临床＋中药鉴定；备考"汉医讲习会"半年制，教材《医宗金鉴》《本草备要》《温病条辨》＋《简明解剖学》《法定传染病提要》【馆藏】 |
| 1941—1944 | **共举行四次汉医考试** | 从科目/内容/结果看：加强管理控制、改造利用、加速中医学术"西化"【研究·李磊《伪满中医考试制度及实施研究》】 |
| 1941年 | 满洲中央汉医会成立（民生部批准） | 职业团体组织化；各地汉医会（如哈尔滨汉医学研究会，办《哈尔滨汉医学研究会月刊》）【研究·龙江医派】 |
| 1942年 | 《医林》双月刊创刊 | 中央汉医会机关刊；汉医数量变化数据（康德二年末→康德七年）【研究·数字待核】 |
| 1945后 | 恢复"中医" | 重新登记与团结中医政策【待补】 |

**资格制度的三个实质**：①**考试即筛选＋改造**——洋医学（解剖/生理/防疫）占理论考试相当比重，旧式师徒医被淘汰，考过的被"西化"（李磊结论）；②**执业双轨**——汉医限用"汉法"（草药、针灸），西药、注射、手术归"医师"（西医），汉医固定为"民间医学"地位【推断·据双轨制逻辑】；③**团体化即管控**——中央汉医会＋讲习会＋刊物，既是职业组织也是统制管道。

### 1.2 县城的医馆/医疗设施形态（七类）

1. **中药铺（"药局/药房/堂"）**——县城医疗主体：前柜抓药、后坊炮制，多带**坐堂医**；膏丹丸散、汤剂、膏药、药酒；赊账成例。小说《伪满洲国》恒升药房（售砒霜等杂药）、德裕药房（汤药）即此形态【文学】；MED时一堂同型。
2. **西医诊所/西药房**——少数日系或洋医开业，多集中县城主街；阿司匹林、奎宁、碘酒、磺胺类（40年代初渐入）奇缺价昂【研究】。
3. **县立医院/县立病院**——部分县设有，简陋，日系医官主导；药品器械靠伪满卫生行政配给【研究】。
4. **公医制度**——伪满后期（约1937年后）推行"公医"配置，向县以下派驻公医以补缺（[孙彤蔚《东北沦陷时期日伪公医制度研究》](https://wap.cnki.net/touch/web/Dissertation/List/1018142065.nh.html)；赵晓红《日本在伪满公营医疗制度的实施及其回流》）【研究】。
5. **保健所/防疫班**——伪满卫生行政末梢：种痘、霍乱注射、鼠疫隔离检疫【研究】；MED库《民生统治管理政策.md》§11（鼠疫/霍乱/天花强制预防注射与隔离）。
6. **满铁医院**——铁路沿线城镇（满铁系统，不服务普通民众）【研究】。
7. **日军/开拓团医疗**——自成体系，与民间不通；其"防疫"常以封锁、烧屋、隔离名义施行【研究】。

## 二、医疗能力边界

1. **诊断**靠望闻问切＋问病：无X光、无化验；老中医"先看手、再看脸、再听咳"（文学细节与史料互证）【研究/文学】。
2. **药源**以草药为主：本地采药＋药市山货（外路人送药——MED设定吻合）；**西药奇缺**：战时配给管制，盘尼西林等极珍贵（根据地药品70—80%靠到日占区秘密购买【线索·知乎046】）。
3. **外科极弱**：化脓性腹膜炎即"开刀吉凶不保"；枪伤、骨折多靠草药外敷与正骨，感染死亡率高（抗联伤员即此类）。
4. **传染病无特效**：鼠疫、霍乱靠隔离封锁，治愈靠命；伪满防疫手段＝强制注射、隔离、烧屋封村。
5. **地方病无策**：克山病1935年才在克山县"发现"，1942年时病因不明、无疗法，民间只能"吊命"——MED"吊命铺子"称呼的史实底色。
6. **鸦片与毒化**：伪满鸦片专卖—瘾者登记—配给体系（战犯古海忠之供述）【档案】；药房涉毒是灰色地带。

## 三、常见病（分五类）

- **传染病**：鼠疫（[1940年农安大流行](https://zh.wikipedia.org/wiki/1940%E5%B9%B4%E5%86%9C%E5%AE%89%E9%BC%A0%E7%96%AB)，研究证实与731细菌战相关——[《医学与哲学》2023](https://yizhe.dmu.edu.cn/en/article/doi/10.12014/j.issn.1002-0772.2023.23.14)；伪满时期东北鼠疫防治见郭文论文）、霍乱（1932年哈尔滨大流行）、伤寒、痢疾（夏季）、天花（靠种痘）、麻疹（冬春儿童）、白喉、猩红热、流感。
- **地方病**：克山病（俗称"**快当病""吐黄水病""攻心翻"**——心肌病、冬季急死；[1935年克山县首次发现并命名](https://zh.wikipedia.org/wiki/克山病)）、大骨节病、甲状腺肿【研究】。
- **冬季特有**：冻伤、感冒肺炎、**煤烟中毒**（火炕煤炉一氧化碳——东北冬季高发）、克山病冬季高发。
- **慢性/常见**：肺结核（"痨病"，无特效药）、风湿腰腿痛（寒地高发）、沙眼、蛔虫、疥疮、性病（妓院线）、鸦片瘾（专卖体系毒化）。
- **营养缺乏**：浮肿、夜盲、贫血——1942年配给制后加剧【研究】。

## 五、与MED项目（时一堂大药房）的对齐点

1. **程时一的资质**：1942年应持"汉医认许证"；老资格坐堂医更可能是1937年前"原持证者暂行医"一类，或1941年《汉医考试令》后新考。1941年满洲中央汉医会成立后汉医地位微妙回升，药房受伪满卫生行政监管（种痘、防疫配合）【馆藏】。
2. **药斗与暗语**：百子药斗＋坐堂＋赊账＋前店后坊与史料形态吻合；"药名暗语"可挂靠汉医讲习会教材行话（《医宗金鉴》《本草备要》）【研究】。
3. **疫病封禁废屋（D5瓷瓶碎片·731线）**：1940年农安鼠疫（731细菌战）后，东北民间对"疫病封禁"有真实恐惧——废屋"因病封禁不可入"氛围有史实支撑【研究】。
4. **冬季常见病素材**：煤烟中毒、冻伤（獾油）、克山病"快当病"（冬季急死、无策）——可作29天事件/对话的细节钩子【研究/民间】。
5. **药房日常对话素材**：验方名称、汉医考试轶事（302取6）、"一剂痛减二剂痛止三剂痊愈"式行话、种痘/防疫配合差事——均可入对白【馆藏/民间】。
