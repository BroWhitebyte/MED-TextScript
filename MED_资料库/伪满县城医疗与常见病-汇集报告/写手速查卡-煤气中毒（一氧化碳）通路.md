# 写手速查卡 · 煤气中毒（一氧化碳）通路

> 用途：MED 冬季炉火场景（0106 午夜·梦境、0201 清晨、0207 后院、夜归/守夜类段落）的物理底与写法口径。
> 证据分级：**【通识】**＝教科书级常识；**【民俗】**＝当时民间经验说法（可入人物口）；**【待考】**＝未核到一手档，写作时避免断言。
> 关联件：`MED_Demo Event 0106`（午夜·梦境）／`0201`（清晨·领口粮，开场"炉子里的炭火已经灭了，灰还是温的"）／`0207`（午夜响动）。

---

## 一 一句话结论

**同一个炉子，三种结局由"煤量 × 供氧"决定**：煤少火灭（冷，无毒）；煤量适中且留风门（暖，安全）；**煤多又把风门关死（供氧断绝 → 燃烧不充分 → 一氧化碳 → 睡中不醒）**。

## 二 化学与生理（**通识**）

| 项 | 事实 | 写作含义 |
|---|---|---|
| 致命物 | **一氧化碳 CO**——不是二氧化碳 CO₂。CO₂ 是**充分**燃烧的产物，本身不主导这起死亡 | 旁白与人物都不该说"二氧化碳致死"；这是本项目必须守准的一处 |
| 来源 | 含碳燃料（煤、炭、木）在**供氧不足**时不完全燃烧产生 CO | "压火＋封死风门"正是教科书式的不完全燃烧条件 |
| 感官 | CO **无色、无味**；"煤气味儿"来自煤烟里别的成分 | **闻不到才是它可怕的地方**——睡梦中无声奏效；不宜写"闻到煤气味才醒" |
| 毒理 | CO 与血红蛋白结合力约为氧的 **200–300 倍**，生成碳氧血红蛋白，使血液失去携氧能力 | "血不中用了"——当时人不懂机制，但"闷着了""中了煤气"是通的 |
| 症状 | 头痛、眩晕、乏力、恶心呕吐、意识模糊、判断力下降，重者昏迷死亡 | **早期症状＝可写的身体信号**：头沉、嘴里发苦、耳鸣、干呕 |
| 睡中特点 | 睡眠中可在**不觉醒**的情况下死亡（区别于"被呛醒"） | 这是"死在梦里"的现实依据——梦境层因此不是花活，而是症状 |
| 体征 | 部分案例皮肤/尸斑呈**樱桃红**（经典法医体征，非全部案例）；面色**不青反红** | **最好的物证反转**：清晨推门看见"脸色红润、睡得很沉" |
| 尸检语境（**待考**） | 1942 年县域无现代法医条件；判断依赖经验与现场（炉盖、风门、烟囱） | 不要写"验尸断定一氧化碳中毒"；写**现场物证＋掌柜的经验判断** |

## 三 炉子的通路（现实层可写的每一格）

```
燃料量 ──┐
         ├─→ 供氧是否充足 ──→ 燃烧是否完全 ──→ 产物 ──→ 人体
供氧 ────┘        ↑
            风门／炉盖／烟囱抽力（夜间变弱、倒烟）
```

| 环节 | 现实细节 | 正文可落的物证 |
|---|---|---|
| 燃料 | 碎煤坯、煤核、煤面拌土；**压火**＝用煤压住火炭过夜（北方冬季常规） | "填了几块碎煤坯，压住炉膛里的火炭" |
| 供氧 | **风门**（炉门上的进风片）留缝＝安全；推到底＋**压上炉盖**＝断氧 | "风门留着一条缝" ／ "把风门推到底，又压上了炉盖" |
| 抽力 | 烟囱热时抽力足；**夜里火压小、烟囱变凉、风一停或倒风**，烟就往屋里回 | "外头风停了"／"烟囱根儿是凉的"（**民俗**："倒烟"） |
| 信号 | 炉口/炉盖缝里**细蓝火苗**＝CO 正在燃烧的可见信号（**民俗**："火发蓝，有煤气"） | **细蓝的火苗**——全件最好的一笔，宜在死亡支重复出现 |
| 残留 | 火灭后**灰还是温的**；炉壁凉而未凉透 | 次晨的开场（0201 已用） |
| 规矩 | 长辈口传的睡前规矩（**民俗**） | 掌柜的临睡一句："压火就压火，别把炉子闷上。" |

## 四 1942 年用语（**人物口**）

- 可入人物口：**煤气**、**煤烟**、**闷着了**、**中了煤气**、**火发蓝**、**倒烟**、**压火**、**风门**、**炉盖**。
- **不宜入人物口**：「一氧化碳」「碳氧血红蛋白」「缺氧」等科学词——1942 年县城药房掌柜/伙计不会这样说。
- 旁白同理：白描纪律下，机制**不说给读者**，只给物证；要讲机制，**借人物的嘴**（掌柜的阅历／更夫／老把式）。
- 药房阶层可能从医书、报纸见过"煤气"一词，但日常仍说"煤气""煤烟"。

## 五 写法红线（本项目已定案）

1. **现实层**守白描与 1942 口径；机制靠**物证链**（蓝火苗 → 头沉 → 干呕 → 樱桃红），不靠解释。
2. **梦境/元层**（如 0106「遗忘」对话）是**抽离到现实之外的元层**，**不受时代口径约束**——现代语、论说体、元游戏出口皆属有意，勿"修正"。
3. **因果不能互换**：生死由**炉子状态**决定，不由梦里的表态决定；梦里只能决定"睁不睁眼"。梦若只能由"多加煤"一支进入，则死亡已被现实因果闸住。
4. **教训说给人**：把规矩放在**前段人物的交代**里（"别把炉子闷上"），死亡才是"没听话"，而不是随机惩罚。
5. **别写"闻到煤气味"**（**通识**：CO 无味）；要写**看不见的**：火色、发闷、头沉。
6. **樱桃红是反转**，且**不是每个案例都有**（**通识**）——可作掌柜的误读，不可写成法医定论。
