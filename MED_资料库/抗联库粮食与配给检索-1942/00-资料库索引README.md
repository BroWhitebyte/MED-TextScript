## 三、使用注意

1. **页码范围**：正文里的「第X页」是 OCR 成果的 **PDF 顺序页**，与原书印刷页码常差 10–14 页；引用到写作笔记时建议写成「pdf页（书页）」，避免错页。见 `MED_考证索引/MED_新序章_索引.md` 的体例说明。
2. **复跑前必须改路径**：脚本内 `OUT` 仍指向旧工作区 `C:\Users\white\Downloads\DS workspace\data\`（该目录已不再使用）。复跑时把 `OUT` 改到本目录或临时目录。`DB` 路径（`I:\抗联整理_OCR成果\_index\library.db`）保持不变。
3. **本条目只作原句出处**，不做史实裁断；与已有《伪满粮谷出荷与1942年民众食物-汇集报告》冲突时，**制度与时间线以该报告为准**（它已做证据分级），本条目用来补原句。
4. **年代陷阱（已在首轮检索中标注）**：`双鸭山文史资料 第8辑` 全库「粮库」密度第一，但内容**全是1949年后**（岭东粮库1949年9月建库、三年困难时期橡子烧酒），**不可用于 1942**。
5. **制度类比需标注地域**：`满铁农村调查·惯行类` 调查的是**华北**（山东恩县后夏寨、河北滦县宋谢庄、冷水沟庄），只能作制度类比，不能当作东北 1942 实况。
6. 引用方式（Obsidian 双链）：
   `[[MED_资料库/抗联库粮食与配给检索-1942/粮与配给_1942精确抽取]]`
