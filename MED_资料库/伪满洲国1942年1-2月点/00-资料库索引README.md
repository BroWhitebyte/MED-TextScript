## 三、关键史实速查（写作用）

- **1942年2月12日**：赵尚志于汤原县梧桐河吕家菜园子遭特务暗算牺牲（年34岁）；同日库楚河战斗。
- **1942年2月13日**：抗联三支队余部十几人自旺哈达越境入苏。
- **1942年2月15日**：春节（壬午年正月初一）；日伪报刊宣传"击毙赵尚志"并筹备"建国十周年"（3月1日）。
- **1942年2月中旬**：王效明部40人活动于东安省饶河一带。
- **民生底色**：粮谷出荷催缴、"搜荷督励"（1942年起）、配给制、黑市与"经济犯"、劳工征发、保甲连坐——与MED_Demo Event中的粮店配给、警察署、当铺、药房等场景直接对应。
- **存疑项**（写作时避免坐实）：赵尚志牺牲时刻（7时/9时许两说）、库楚战斗日期（12日/13日两说）——已在文档中并列标注。
