## 四、使用方式

1. 查某条资料 → 找到其来源索引文件 → 按条目编号进入对应子目录同名编号md文件。
2. 每个子目录内有 `00-本目录索引README.md`（编号｜条目｜链接｜抓取状态）作为本目录映射表。
3. 抓取全程日志：`抓取总日志.txt`（根目录）。
4. 原始未转换HTML备份：`../伪满洲国1942年1-2月点-核查材料/`。
