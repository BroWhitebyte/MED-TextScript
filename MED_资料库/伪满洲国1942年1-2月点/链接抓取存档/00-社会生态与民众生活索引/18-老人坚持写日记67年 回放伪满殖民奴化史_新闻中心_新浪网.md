老人坚持写日记67年 回放伪满殖民奴化史
| 
http://www.sina.com.cn 2005年08月23日00:36 辽沈晚报 | 
| 
铁岭市银州区82岁高龄的李连举老人已坚持记日记67年。与《拉贝日记》、《东史郎日记》、《魏特琳日记》、《程瑞芳日记》所不同的是，李连举的日记中并没有记载日本侵略者的种种暴行，他以一个亲历者的身份，记录了1938年底至1945年日本无条件投降这段时间里，日本帝国主义在东北如何实行殖民地奴化教育及战争带给人民生活的变化。
辽宁教育史志学会会长齐红深在其刚刚出版的大型系列丛书《见证日本侵华殖民地 
| 
| 
| 
|

|

教育》中，大量收录了李连举日记中的内容。不可否认，这是日本侵略中国的又一铁证。
殖民地奴化教育
李连举1924年出生在吉林省舒兰县杨桥村。李连举7岁那年，爆发了“九·一八”事变。
“康德元年”（1934年），村里的学校恢复了，但名字改了，叫“国民学舍”。10岁的李连举开始接受教育，但还是读《三字经》、《百家姓》等。1938年，李连举进入舒兰县国民学校读书。
当时的课程主要有日语、满语（即汉语）和“国民道德”，其中“国民道德”中主要的内容就是要拥护皇帝（溥仪）、要日满亲善等等。也就是在那一年的冬休（寒假），级任（班主任）宫世盛开始要求学生记日记。1938年12月28日，李连举写下了第一篇日记。
日本人要改造中国青少年，实行奴化教育，从李连举的日记中随处可见。
“1938年12月30日，金曜日（周五。日本人规定：月、火、水、木、金、土、日代表周一至周日），早起温习日语。日语是我们小学生的必修课。衡量一个学生的学习成绩，主要以日语为主，所以，在假期也得天天自学。”
“1939年2月25日，全班学生赴舒兰县协和会听讲演。由协和会长讲‘（伪）满洲国是王道乐土’。听协和会讲演是当时学生的必修课，让学生听了感谢日本亲邦，接受日本的帮助，将来学以成才报答日本的恩情。”
“1939年3月15日，本日为协和日，照例到县协和会广场听讲演。”伪满洲国期间，每月15日定为国家协和日，在该日，对国民进行一次政治教育，学校尤为突出，不论哪年级学生必须参加。
“1939年9月18日，月曜日。上午全校列队参加‘九·一八’纪念日仪式，又到忠魂碑参拜。县长训话，讲了大日本帝国驻东北关东军于1931年发动的‘九·一八’事变，是为了拯救东北民众，建立（伪）满洲国的种种功绩之一，让东北民众永远不忘友邦日本帝国的恩情。”
从李连举1938年至1940年就读“国斜期间的日记中不难看出，除了学校的课程外，学生每年都必须要参加难以想象的大量的节庆活动，像协和日、兴亚奉公日、日本天长节、（伪）满洲国建国纪念日、日本国陆军纪念日、（伪）满洲国皇帝颁发“回銮训民昭书”纪念日、勤劳俸士日、建设东亚协同体日华事变纪念日、拜忠魂碑、祭日本神武天皇、日本靖国神社大祭日等等。这些活动有的每年搞一次，有的每月搞一次，多达数十个，无疑是为了向青少年灌输“爱国（伪满洲国）”、“亲日”思想。
战争带给生活的变化
日本帝国主义大肆侵略需要大量的物资供应保证，东北的物资被其掠夺送往前线与本土，当时东北人民生活水平急剧下降，物资严重短缺，这在李连举老人的日记中也有所记载。
“1941年1月26日，今天是旧历年除夕。……今年吃上了精米饭，可是全家人提心吊胆。按国家规定，稻米是不准老百姓吃的，农民种的稻谷一律要给国家，供给日本人和皇军吃，满洲人吃稻米按经济犯罪论。我家从乡村托人买了几斤精米，在除夕这天早晨偷偷吃的。为了防止被日本人和警察发现，剩点饭根藏了起来，母亲为这顿饭费了很多心血，总算安全度过了除夕。”
“1945年2月3日，今年春节，物资紧缺，十分昂贵，就是花高价也买不到东西。据说物资都给前方军队送去了，只好过一个素节。”
除了人民的生活水平下降外，百姓的人身自由也受到了极大限制。李连举老人在1941年4月30日的日记中写道：“五常县东部山区实行归户拼屯地区。四河川一带方圆几十里的散户居民，在几年前就集中到四河川屯居祝为了断绝当地居民跟抗联的联系，把几百户人家围在一个村里，周围修筑围墙，墙外挖很深的护城壕，全村只留一个门出行，由军警把守。居民发‘良民证’出入验证。发现可疑人，严加拷问或逮捕法办，老百姓完全失去了自由。”
日本无条件投降
1944年，李连举国高毕业，被分配到舒兰县公署当了一名雇员。在县公署，他结识了许多日本雇员，亲身感受到了日本平民的悲观和厌战情绪。他在1944年10月3日的日记中写道：“日本大东亚战争急需人力，在县公署工作的日本在乡军人陆续应召入伍。县里要求欢送这些人入伍，我股的日本人金泽这次入伍，欢送时他哭的很伤心，说了不少告别话，最后他说，我可能回不来了。”
尽管日本人在统治东北期间实行了奴化教育，但从李连举老人日记中的描述中证实：一个民族是不可能被外来侵略者同化的。关于“8·15”前后所发生的一切。李连举从一个平民的角度，鲜活地记录了那一刻。
“1945年8月6日，美军在日本国投下了原子弹，听到这个消息使人十分震惊。大家猜想，大东亚战争可能快到头了。”
“8月9日，听说苏联军队也向日本宣战，进入了中国东北。听说好像（伪）满洲国新京政府最近也从新京逃跑了，（伪）满洲国垮台了？”
“8月16日，一个特大消息从电匣子里播出，日本天皇宣布无条件投降，东北光复，（伪）满洲国垮台了。这天，全城人一齐拥上街头，狂欢庆祝东北光复。”
“9月2日，听说，日本天皇和政府以及日本大本营的代表在投降书签字了。又是一番大庆祝……”
特派铁岭记者赵天乙实习生 宫佳奇
