## 五、1941—1942年社会生态要点速览（政策—民生对照）

| 时间 | 政策/事件 | 对民众生活与治理的影响 |
|---|---|---|
| 1941年3月 | 《苏日中立条约》签订前后，日伪强化"治安肃正" | 归屯并户、经济封锁加剧；抗联与民众联系被割断 |
| 1941年7月 | 关东军"特别大演习"后东北日军增至16个师团、约90万人 | 军事高压常态化，城乡保甲、协和会控制加强 |
| 1941年9—10月 | 《劳务新体制要纲》（9月10日）、《劳动统制法》修改（10月22日） | 劳动力征集与配置纳入国家统制，劳工征发扩大 |
| 1941年12月8日 | 太平洋战争爆发，伪满进入"战时体制" | 粮谷出荷指标逐年提高（1940—1944年预定收买数自630万吨增至820万吨）；配给制收严 |
| 1942年2月 | 伪满总务厅制定《战时紧急经济方案要纲》 | 战时经济统制加码：粮谷、物资、金融全面统制 |
| 1942年起 | "搜荷督励"制度（各省县设搜荷督励本部、督励班） | 入户搜粮、没收种子粮；经济犯每月每县平均200余人被拘；商人因私售被重罚、粮栈倒闭 |
| 1942年3月1日 | 伪满"建国十周年"庆典（新京大同广场） | 宣传造势与强化控制并行，报刊连篇累牍渲染"王道乐土" |
| 1942年11月 | 《国民勤劳奉公局官制》《国民勤劳奉公队编成令》公布 | "勤劳奉公"制度化，青年无偿劳役成常态（次年编成奉公队） |
| 1941—1942年 | 奴化教育深化（"新学制"、日语强化、协和青少年团） | 学校生活全面殖民化；城市配给、黑市与"经济犯"并存，商民两困 |
