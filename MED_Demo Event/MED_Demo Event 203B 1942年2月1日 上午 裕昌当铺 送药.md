# MED 文档 1942年2月1日 上午 · 裕昌当铺（第二个送药任务·当铺线）

时间：1942年2月1日 上午

地点：裕昌当铺

人物：程靖霖/王吉来/王小

以下为文学性描述：

---

从药房的正门出去，拐上南大街，程靖霖回到了昨天的老路上。他将手揣在怀里，想起夜色降临前见到的王裕昌。穷人的活路越走越窄，富人似乎也并没有好多少。这康德九年的艰难日子，莫非跟穷富没什么关系？

小广场上的绞架依旧在寒风中矗立，那具尸体在寒风中轻轻摇晃着。街道上依旧没什么人，偶尔有一两个行人经过，看到那具尸体，便不由自主地加快脚步。

程靖霖慢慢地穿过小广场，目光在那具尸体上稍微停留了一下。死人不需要保暖，枯瘦的尸体上除了一条破裤子外便一无所有，冻结住的眼白漫无目的地望着脚下。寒风吹过，木架发出干涩的声响，绳索慢慢转动着，尸体的眼睛便这样轮流扫过四条大道。

程靖霖把手揣得更深了一些，从小广场旁走过，面前就是裕昌当铺。这间当铺在县城里开了快二十年——民国初年就有，等到九一八之后，一批铺子倒掉，一批铺子转手，这裕昌当铺却是没有任何变化，前几年还红火过一阵子。

当铺的两扇黑漆大门已经显得有些陈旧，但仍颇为气派。里面是青砖底脚、木梁、厚门板和高柜台的老式铺面，牌匾旧，边角起皮，门槛高，冬天门鼻和锁鼻都冻得粘手。

程靖霖走到侧门前，握住门环，叩打了三下门面。

里面有人应道：“来了！”一阵急促的脚步声，一个面相白净的男子打开了门，他头戴瓜皮帽，身穿长棉袍，是这裕昌当铺的二柜王吉来。他是王裕昌的堂弟，也是整个当铺里有门面的人。平时王裕昌不在，他便料理这当铺上下的买卖，盘点营生，代押小押，与人来往。有时候，富家也有过桥的时候，他便上门去给人家处理事情。

王吉来看到门口站着的程靖霖，脸上稍微抽动了一下，但又立刻挂起了笑容：

“哎哟，小程先生来了！快进来暖和暖和——**昨儿公子等药等了一宿，小程先生今儿才来？还以为您不来了呢。**”

程靖霖施了一礼：“先生，昨儿铺子里事多，药是今早才抓好的。”

“来了就好，来了就好。”王吉来引他往里走。

程靖霖向王吉来施礼，钻进了当铺正房。他环顾四周，看到锃亮的柜台与前屋的洋铁皮炉子，以及弥漫在空气里若有若无的一丝萧条气味。他对王吉来寒暄道：“先生，最近生意怎样？”

王吉来叹道：“大掌柜这两天跑上跑下的，我们也不知道在办什么事，但今年呐，多半是不如往年。”他看着程靖霖从怀里取出药包，接着说道：“若是以往，王小得了病，大掌柜哪会把宝贝儿子扔在家里，出门去应酬！你看看，今天这上上下下，就只能我来料理。”

“先生，这是给公子的风寒药。药包里有煎药的法子，老样子，您给灶下就得。”程靖霖将药包双手交给王吉来，犹疑了一下，“公子怎么就偶染风寒了？这几天也没见他出来溜达。”

“那谁知道呢？”王吉来打着哈哈，接过药包，拿出老头票纸钞，递给程靖霖。他掂量着药包，却并未立即送客。半晌，他才对程靖霖说：“老先生不能出诊，小先生帮忙看看也行啊。小程先生，您要是不急的话，看看公子的病情如何？大掌柜爱子如命，我也怕他心神不宁呐。”

程靖霖尚在犹豫，王吉来已经走在前面，引他进入内室。王小的房间在后院里，屋子里烧着个炭火盆，少年蒙着大被躺在炕上。王吉来敲门叫道：“少爷！我请小程先生来给您瞧瞧。”

程靖霖走到炕边，一低头，便和王小活泼灵动的眼神对上了。他心里便有了定数，说道：“公子，我来给你把把脉。”王小没有吭声，只是从被窝里伸出胳膊和焐热的手。王吉来一见小程子有模有样，便远远站在门口观看。

程靖霖把手指头搭在脉门上，感觉到有力的脉搏不像病体，便低声问道：“王小，为啥装病？”

王小的眼神垂了下去。半晌，他才嗫嚅着道：“程哥，我……不想上学。日本督学天天骂人，打人。日语我也学不懂……上学就跟进监狱差不多……”

程靖霖没有作声，只是换了个手势继续搭脉。王小的眼睛重新又抬了起来，他轻轻地说：“程哥，我……”

王小没能把话说完。程靖霖的手指离开了他的脉门，把他的胳膊塞回到大被底下。十七岁的药房伙计站起身来，对站在门边的王吉来说道：“先生，公子偶染风寒，问题不大，按照药方服药，几天就能痊愈。冬天冷得利害，孩子体弱，让他在家多养养，这几天就别去上学了。”

王吉来听罢，眉开眼笑：“不愧是小先生，这本事也跟老程先生差不多了！”他笑嘻嘻地走上前，手里又多了几张老头票，塞在程靖霖手里。“这一趟也不白来，改天公子病好了，我再跟大掌柜说说，登门拜谢。”

程靖霖回头看了一眼安静的王小，谢了王吉来，跨出门去。当铺的侧门在他背后关上，王吉来那句“替我向老程先生带好”还回荡在空气中。

日头才过晌午。程靖霖吸入冰冷的空气，当铺里带出来的热气很快被寒风吞掉。他顺着大道走回到药房前脸，没有迟疑便推开了屋门。黑色的棉门帘子撩起又放下，这一天便也如同这沉重的门帘一样，落到了地上。

路并不远，但日头已经快到正中了。程靖霖推开药房的门，门帘掀起又落下，带进一股寒气。

屋里炉火压着小火，暖意不多。程时一坐在柜台后头，看见他进来，把账本合上：“回来了。洗手，吃饭。”

“是，掌柜的。”

程晓梅在灶间探出头，看见他，笑了一下，转身去端饭。两只粗瓷碗，一碗稠一点的，一碗稀一点的。稠的放程靖霖面前，稀的她自己端了。

程时一慢吞吞地起身，走到桌边坐下。

程靖霖把一卷老头票放在柜台上：“当铺的药送到了，这是药钱。王吉来说，改天登门拜谢。”

程时一点了点头，说：“坐下，先吃饭。”

三个人围着桌子坐定。碗里是稀溜溜的协和面糊糊，桌上一碗熬酸菜。程靖霖看到掌柜的端起碗，便也跟着拿起筷子。

就在此时，门外响起急促的敲门声。咚咚咚。

还没等人应，又响了两下更大的声音，砰砰。

屋里端着饭碗的三个人互相看了一眼。

门外传来生硬的协和语，不耐烦地叫道：

“开门！太君来了！”

程靖霖站起来。他看一眼程时一，掌柜的扶着桌沿，慢慢站起。他便走向门口，拉开门板，日头照进来，门口站着三个人。

前头那个穿着警尉的制服，程靖霖认出这是刚见过面的中野警尉。他身后是一个翻译，一个警察。

程时一站在门口，微微低了低头：“太君，屋里请。”
