# 1942年1月31日 黄昏 大车店支线

时间：1942年1月31日 黄昏 

地点：老佟家大车店

人物：程靖霖/车马店伙计 李大个子/车马店掌柜 佟立春/抽烟车把式（张老大）/风寒的车把式



文学性写作描述：



通兰县城东南区域的平房群落里，多得是七弯八绕的小巷子。老佟家车马店从大道上走也能到，但是从平房后面走显然更快。

程靖霖从药房出来，拐进小胡同里，走过一片他从小就记得没人住的破烂房子，再向东拐个弯，在寒风里很快就望见了老佟家车马店的后身。

大伙儿都叫惯了它大车店，这里是南来北往的把式们歇脚打尖，以及交换消息的地方。把式们都有着自己的一身本领，走南闯北——人人都有明面上的买卖，人人都有暗地里的生意。老佟家的老掌柜佟三爷原本也是走江湖的人，后来在东大道旁边安了家，开了这爿车马店。老头年纪大了之后，把生意交给儿子佟立春打理，其实很多关系还是维系在老头子身上——三教九流，各色人等，有时候也只有阅历足够的老头子才能应付。

程靖霖把手揣在怀里，顺着小道急走，忽然间眼前被一个铁塔也似的黑影笼罩。那个庞大的身躯堵住了窄小的道路，居高临下地在寒风里问道：“你是谁？”

程靖霖耸然抬头，认出这是老佟家的看院子伙计，李大个子。他一直在院里，劈柴、喂马、收拾杂务，偶尔也替掌柜佟立春跑跑外边。南来北往的把式们，多半是来到门口吆喝一声，看到李大个子便仿佛见到了故人。程靖霖赶紧回答道：“老李大哥，我是药店小程子。掌柜的说大车店有人染了风寒，我来送药了。”

李大个子面无表情，他看了看程靖霖，侧了侧身，让出空间，对他说：“快去。”

程靖霖低头从他身边走过，车马店后门的小门已经打开，他闪身进去，走过院子，敲响屋门。

门从里面被打开了，一股热气从屋子里冲出，不到四十岁的掌柜佟立春站在门口，身穿皮袍，戴着一顶小帽，是一个有些狡猾和市侩气的生意人。他看看程靖霖：“程先生让你来的？快进来。”

程靖霖赶紧闪身进屋关上门，留住屋里的暖和劲。他打量着大车店里，往日喧哗热闹的堂屋，今天看起来有些冷清，大炕上躺着一个把式，似乎睡着了——另一个把式正坐在他的旁边，满脸担忧。

佟立春站在程靖霖的身后，嘴里嘀咕着：“今年啊，真是邪了门了。赶到年前，也没几个把式出来跑，往年这时候店里都住满人了。”

躺着的车把式呻吟起来，坐着的那个点着了烟袋，回应着佟立春的话：“佟掌柜，您也不看看今年是什么德行！前年就算管得严，多少还有点山货可以倒腾。现在呢？这也军用，那也军用，什么都不给老百姓。我们这帮赶大车的，还能干什么呢？人吃马喂的，哪样不是钱？再说了，光有钱有什么用？”

程靖霖听着他们的抱怨，没应声，走到躺倒的把式跟前，伸手摸了摸他的额头，有些烫手。他从怀里掏出药包，看向抽烟的把式和佟立春：“这药……”

佟立春走到程靖霖面前，伸手拿过药包说：“给我吧，我让灶下给煎一下。”他向抽烟的把式努努嘴：“药钱找张老大结。”说着便走出了堂屋。

程靖霖回头看了看愁眉不展地抽着小烟袋的张老大。把式的脸上深深的皱纹仿佛沟壑纵横，他抬起头盯着小伙计说：“小老弟，钱不凑手，我明儿还得送这兄弟回去。这样，我给你拿点东西，你跟程先生说一声，说张老大张把式下回带现钱来，赎这玩意儿，这就算个小押。”

张老大叼着烟袋，一只手伸进黑棉袄深处，掏出一只小布袋，将袋子小心地在炕面上铺平，又掏出一根系了红绳的人参，放在布袋上。他望了望程靖霖说：“五两多，顶这个药钱，绰绰有余。这年头，能保命的东西不多啦。”他又掏出几张皱巴巴的“老头钱”（中银券），也扔在炕上，对程靖霖说：“现钱，就这点，勉强顶药钱。你拿钱走，我也得把这根参抵给佟掌柜的，我揣了它一年多，今天到底是要离开我啦。”

程靖霖沉默了一会儿，上前拿起了人参：“那我就拿这个了，张老大，您多担待。”

程靖霖沉默了一会儿，上前拿起了钱：“那我就拿这个了，张老大，您多担待。”

张老大重新端起烟袋，烟锅里的火星忽明忽暗。他重又低下头去，吧嗒吧嗒地抽着烟，挥挥手说：“老弟，回去吧。回去跟程先生带个好。”

程靖霖应了一声，重又从后门出来。他望见前院里的爬犁和几匹瘦马，还有院子里寡淡的货品。佟立春背着手站在门前，看了看他，咳嗽一声，给他打开屋门。

天色将晚，大车店的院门在身后关上。程靖霖吸入冰冷的空气，在小巷子中歪歪扭扭地走回到药房。大车店里逮出来的热气很快被黑夜吞噬。他走回到药房前脸，没有迟疑便推开了屋门。黑色的棉门帘子撩起又放下，这一天便也如同这沉重的门帘一样，落到了地上。
