# MED 文档 1月31日 上午（训练日开始）

时间：1942年1月31日 上午

地点：时一堂大药房

人物：程靖霖/程时一/程晓梅



以下为文学性描述：



铁皮炉子里的火焰缓慢地闪动着。

程靖霖望着赤红色的火炭出神。他慢慢地用火勾拨动了几下火，把炉圈盖好，拿起放在一旁的水壶，坐在炉子上。

这是时一堂大药房的堂屋，也就是他日常生活和劳作的地方。他还记得当年掌柜程时一盘下这间平房的样子，时至今日，似乎并没有改变多少。青砖、木梁、板门、木柜、台面，来往的客人经常倚靠的地方被磨得光亮。

门口黑底白字的匾额“时一堂”是康德二年挂上的，到了现在，在通兰县城里也还是一面硬气的招牌。两扇木板门与厚重的门帘将寒冷隔绝在外，只有在堂屋里还保留着一点温暖。

程靖霖慢慢走到柜台后，他的背后是高过顶的百子药斗，手边是黄铜戥子、药剪、药纸、小刀、麻绳。他抓药和看病的本事，都是掌柜程时一手把手教出来的。这许多年过去，屋子里当归、黄芪、甘草、陈皮，混着煤炭、木柴，加上一点点潮气，构成了他嗅觉的一部分。

炉子里的炭火毕毕剥剥地响起来。程靖霖听见有沉稳的脚步声从后堂过来，一个中年男子挑开柜台后的门帘进了药房。程靖霖转过身来，看到程时一那张略显苍老却并不衰颓的脸。

“掌柜的，早。”程靖霖微微施了个礼。

程时一点了点头，慢慢走到火炉旁。他伸出双手，枯瘦、修长、指节分明的手在炉火旁来回翻转。



“掌柜的，早上我生火的时候，看了一下。”程靖霖在他背后小心地说，“煤快没有了。灶上还熬着药，我算了一下，大概还够三天。”

> **【口径注（E-18 调和）】**：000（1/30 夜）程靖霖答王裕昌"煤够烧的"＝客套/未细算；001（1/31 晨）生火细算只够三天——一夜口径差异为"客套 vs 细算"之别（000 冻结不改，001 为准）。

程时一没有回头。他继续烤着手，盯着水壶，眼中忽明忽暗。

炉火并不是很旺。东北的冬天，那里散发的温度是让人感到安全的最大理由。

良久，老医生才低声说：“快过年了。这煤，和粮食一样。越来越少了，也越来越贵啦。送煤的也不一定什么时候来。”

程时一转过身来，望着程靖霖，轻轻捻着自己的手指：“这一阵，你就得多跑跑了。我年纪大了，腿疼得厉害。药材咱们倒是还有点，不用太担心。这不是眼看要过年了吗？往年，都会有人来咱这买点东西，送送礼，走动走动……”

他没有继续说下去，眼神投向玻璃窗外空荡荡的南大街，寒风卷着尘埃在街面上掠过。天光已经大亮，但街面并无声息，偌大的通兰县好像一座空城。

炉子上的水壶发出嘶鸣，打破了药房里的沉默。程时一的女儿程晓梅从后门走进堂屋，她熟练地从柜台里取出两只碗，给程时一和程靖霖倒上开水，回到后间去水缸里添水。

程晓梅把水壶重新坐回到炉子上，说：“粮食咱还够半个月的。大概，能撑到过年吧，爹。”

程时一苦笑了一下，望向女儿，又望向被纸条糊住的玻璃窗。一阵风起，穿透窗缝。他问程晓梅：“闺女，老马家的药煎好了没有？”

程晓梅答应一声，重新回到后间。程时一踱步到柜台后：“霖子，跑一趟吧。”

“是。掌柜的。昨天我从南大街那边回来，觉着这街面比以前又冷清了。”程靖霖问道：“是不是外面风声又紧了？”

“让你去哪你就去哪。”程时一的声调没有什么变化，“你过去怎么跑，现在还怎么跑。外面冷，衣服掖好了，东西拿好了，快去快回。大冬天的，搁外边呆太久，就会冻着，一冻着了，那可就什么事都干不了啦。”



程晓梅端着一个装药的小砂锅从灶间出来，她将砂锅放进一个篮子，盖上棉垫，叮嘱程靖霖：“霖子，地滑。小心点，别撒了。”

程时一看了看那个小篮子，苦笑了一下：“天寒地冻的，药汤咱们可送不了多远。幸亏老马家就在借壁儿，不用换衣服，到了那儿也凉不了。”

程靖霖挽起篮子，从柜台后面绕出来，他听到炉膛子里炭火闷烧的声音，像在给他提醒，这里是一个坐标。

老医生走到柜台旁，拿起棉帽，在手里掂了掂，回头扣在程靖霖头上，给他系好帽带。程时一耐心地捋着带子，一边打结，一边说：“我老啦。跑腿的事，全靠你了。”

他给程靖霖戴好帽子，慢慢踱回柜台后面，补上两句：“马寡妇不定给你拿点什么……煤、粮食、钱，都顶一副药。但是这世道啊，有钱也买不到什么东西，有些东西钱买不来。”

程时一抬起眼睛，与程靖霖的目光交汇。他点了点头说：“不该看的别看，不该问的别问。走到哪，都得记得。去吧。”



程靖霖挑开厚重的门帘，推开药房正门。寒风如重拳般锤打在他的脸上。他回头看了看时一堂药房的牌匾，这是他每次出门的习惯，他自己也说不上为什么会这样做。

路边的雪与泥混成一团。他顺着土路旁边慢慢地走，挑着没那么脏的地方下脚。马家杂货铺和药房很近，就在借壁儿，几步路的事。
