送完药回来，天已经擦黑了。
程靖霖挑开门帘，屋里暖烘烘的。
程晓梅在灶间忙活，锅里咕嘟咕嘟响着。掌柜的正站在门旁，捻着下巴上的胡子。
程靖霖向老人行了礼：

程靖霖：掌柜的，我回来了。

程时一抬眼看了看他：

程时一：嗯。霖子，这几天可能会忙起来，我也不一定什么时候都在家。
程时一：老规矩，如果有哪些事情来不及交代，我会把它写在这块板子上。天还亮着，这活就能干。

程靖霖看向门口的看板。上面用粉笔粗粗地写着几行字。

【看板说明·美术形式：黑板，粉笔】这里是时一堂大药房的门口看板。看板上写着的这些事情会有时间、地点以及额外需求。

程时一：天色还早，霖子，挑一个去吧。回来吃饭。
程时一：这板子上的事儿，大部分都不麻烦，一个时辰就能回来。可是也会有一些，得多跑几次。
程时一：咱们药房，是给人抓药看病的地方。可县城里的事，不都在药柜上。有些事，得你去人家门上，才办得了。
程时一：快过年啦。这板子上的事，办不办、先办哪件、什么时候办——你说了算。办好了，人家记你的情；办砸了，耽误了，人家也记着。
程时一：这功夫，你要么在店里待着，等吃饭；要么趁天黑透之前，出去办一件。天快黑了。自己拿主意吧。

　程时一：事情办妥了就好。
　程时一：板上的事，办一件，少一件。明儿还会有新的事贴上来。
　程时一：日子就是这样。你今儿偷了闲，明儿就得紧着点；你今儿多跑了一趟，人家就多记你一分情。人情这玩意儿，在县城里比钱有用。
