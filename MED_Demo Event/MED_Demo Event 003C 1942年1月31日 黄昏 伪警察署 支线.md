# 1942年1月31日 黄昏 伪警察署 支线

时间：1942年1月31日 黄昏 

地点：伪警察署

人物：程靖霖/中野三郎（警尉，有历史原型，日本人）/警察 李加夫（中国人，无历史原型）/风寒犯人



文学性写作描述：



虽然只有一街之隔，但程靖霖还是不太愿意将目光投向远处那座被漆成黑色的建筑。那大概是这个县城里最为阴森的地方，很多东边的平民家庭夜里吓唬孩子的时候，总会说：“再闹，黑狗子就上门来抓你！”

县公署发“公告”，协和会讲“道理”，保甲所管“连坐”，警察署就复杂了。如果是平民百姓，平安无事地从里面走出来的几率并不大，这座衙门是带院的两进式改造房。前头朝街，门脸不大，里头吃人。

程靖霖沿着南大街慢慢走过去，时不时抬起头盯着小广场西南角的那幢建筑。刚才出来时，程时一特别叮嘱他：“警察署的差使，到了就回。多了别问，不让你看的也别看。”

如果走到路口再过街的话，就需要经过小广场。程靖霖想到那具吊在行刑架上的尸体凝固的眼白，把手往怀里揣紧了一点，低着头穿过南大街上的泥泞和车辙。他左顾右盼，但街上并没有什么人——过去，他偶尔也会被掌柜程时一派去西边送药，但去警察署，还是头一次。

风更加凌厉起来，卷着尘土打透了程靖霖的裤管。他加快脚步，很快到了警察署门口。两个正在抽烟的伪警察看到瘦高的身影靠近，其中一个厉声叫道：“站住！干什么的！”

另一个警察（警察B）认出了程靖霖，哈哈一笑说：“是老程家药房的伙计。里面用药，我刚让人去药房催了催老掌柜的。动作还挺快，这就送来了。”他向程靖霖一努嘴：“进去吧。”

程靖霖点头称是，从两个警察身边蹭进警察署的偏门。站在这幢黑乎乎的建筑前，他的心似乎也跟着沉了下去——被捏紧、揉搓和踩踏。

大厅里比外面有了点暖和的意思，坐在门口的一个警士懒洋洋地拦住程靖霖：“哪来的？找谁？”

还没等程靖霖回答，从警察署里面传来几句生硬的协和语：“伙计？药，我的。”随着话音，一连串脚步声顺着走廊传来，一个穿着警尉制服的日本人从黑暗中出现，走到程靖霖面前。他上下打量着年轻的伙计，摆手让旁边弹起来敬礼的警士坐下，微微笑了起来：

“你的，程家的，我的见过你的。药的带来？”

程靖霖低下头，从怀中掏出药包，双手递上。他微微抬起眼睛，眼神与那个日本人鹰隼一样的目光交汇，又赶紧把眼睛垂下。

日本警尉接过药包，掂了掂。他拍了拍程靖霖的肩膀，笑道：“你的，跟我来。”

程靖霖内心一惊。他本能地想拒绝，但心里如同电闪般划过了几个念头，最后还是低下头说：“是。”

日本警尉没再看他，转身往走廊深处走去。后面的警士推了程靖霖一把：“中野太君叫你跟他走，快点！”

走廊似乎长得看不到头。中野警尉打了铁掌的皮靴在水磨石地面上发出响亮的声音，每一步都像是一声判决。程靖霖跟随他走到一扇门前，中野回头看了看他：“你的，会治病？”

程靖霖点点头，但是想起掌柜程时一说的话，又赶紧摇摇头。中野看着他有些慌张的表情，又笑了起来：“你的，不要害怕。有人，要看一看。不是我。”

他推开门，程靖霖看到空荡荡的房间里摆着一张椅子，一个衣衫破烂的人被牢牢绑在上面。旁边的两个警察看到中野进来，都赶紧立正，手上的皮鞭和警棍垂在地上。

程靖霖的眼睛不敢抬起来，紧紧盯着审讯室的地面。他看到水泥地上经年累月留下来的一块块深黑色的污渍，上面又覆盖了新的暗红色的痕迹。

中野把程靖霖拉进房间，把他带到那个受刑者面前：“去，看看他的，发烧？”他一边说，一边把药包抛给一个警察：“李桑。”

程靖霖被推到受刑者面前，这个气息奄奄的男人衣衫破烂，上身的衣服被扯开，胸腹留着新鲜和陈旧的伤痕，干瘦的身躯上布满了皮鞭和木棒的印迹。他的一只眼睛已经青肿起来，脸上满是血渍。

程靖霖小心地把手覆盖在他的额头上，感觉到一股超过正常体温的炽热。他从怀里拿出手巾，擦掉受刑者嘴上的鲜血，捏着他的下颌，轻声说：“张嘴。”

受刑者的喉咙里吐出几个无法辨认的音节，似乎对于外界的一切都已经无动于衷，但还是张开了嘴。程靖霖看到他的牙齿已经残缺不全，牙床上的新创口还在漾着血丝。男人好像恢复了一点知觉，他的喉结滚动了几下，嘶哑的声音被挤出来：“水……水……”

程靖霖直起身来。刚才接过药包的警察走到他面前：“说，怎么样？”

程靖霖咽了一口唾沫，回应道：“风寒，烧得厉害。需要服药休息……”

警察狞笑起来：“休息？快过年了，老子都没歇班。”他转向中野警尉，说了几句日语：“彼は、その人は確かに病気だったと述べた。拷問を続けるべきでしょうか、それともどうしますか？”

中野警尉脸上依旧挂着微笑，回应道：“こいつは口が達者だ。死なせるわけにはいかない。”他将手伸进裤袋，掏出几张“老头票”，招手叫程靖霖过去，把钱递给他：“你的，走开。”

拿着药包的警察会意，跟上前去，把程靖霖推到室外，带上了门。程靖霖还没反应过来，一只铁钳似的手便掐住了他的胳膊，把日本人刚塞给他的钱夺了过去，他本能地叫道：“长官，这……”

“快滚！”警察吼道，“从哪来的回哪去！”他挥舞着拳头，威吓着年轻的伙计。

程靖霖不知道自己是怎么从警察署里走出来的。他回身看了看那幢黑漆漆的建筑，仿佛刚做了一场短暂的噩梦。
