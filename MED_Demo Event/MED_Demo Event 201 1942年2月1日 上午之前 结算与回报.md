# MED 文档 1942年2月1日 上午之前 · 时一堂大药房（结算与回报）

时间：1942年2月1日 上午之前

地点：时一堂大药房

人物：程靖霖/程时一/（敲门者按分支：李加夫或王吉来或张老大）

> **设定注（v1.12 落档核对）**：本日（2/1）程时一仍在家，未受 D13-D17 顺延影响（程时一被捕日＝D16，2/15 除夕）；"三线回报"与 202 领粮并行，无日期冲突。受刑者＝2/2 处决同一人（三天闭环，跨日钩子见 2/1 索引）。

以下为文学性描述：

---

天还没有亮，炉子里的炭火已经灭了，灰还是温的。

程靖霖从门板铺上坐起来，习惯性地先伸手摸了摸炉壁——凉的，但还没凉透。窗台上那盏灯正处于将灭未灭的边缘，火珠子如豆跳动。

他正要披衣起身，前门被人敲响了。

天还没亮，这个时候敲门，不是急病，就是有事。

程靖霖披上棉袄，走到门口，隔着门板问了一声："谁？"

门外的人闷声应道：“送东西的，开门！”

程靖霖拉开门闩，厚门帘掀起，一股冷风扑进来。

〔敲门者与回报——按昨日所择，三选一展开〕

---

**若昨日去了警署**（对应：`MED_Demo Event 003C 1942年1月31日 黄昏 伪警察署 支线.md`）：

门外站着的是李加夫。

他哈着白气，搓着手，一双布鞋在雪地里跺着——这双布鞋在东北的寒天里无所遮挡，他也只能这样从一个地方快步到另一个地方。他看见程靖霖，脸上挤出一个笑：

"小程子，起这么早？"他从怀里掏出一卷票子，递过来，"昨儿的事，弟兄们手快，误拿了你的药钱。太君发了话，叫给你送回来。一分不少。"

程靖霖没接，先看了看他的手。李加夫又往前递了递，压低声音："太君还说——时一堂的伙计，以后进出警署，报他的名字就行。这是太君给的脸面。"

程靖霖接过钱。票子还是冷的，带着雪气。他问了一句："那位犯人的病……"

李加夫摆摆手："还烧着，还没招。你操那心干嘛。"他说完缩了缩脖子，转身就走，布鞋在雪地里留下一串急促的脚印。

程靖霖看着那串脚印，把钱揣进怀里。

钱回来了，可他想起的还是那双蒙着血丝的眼睛。

**若昨日去了当铺**（对应：`MED_Demo Event 003A 1942年1月31日 黄昏 裕昌当铺支线.md`）：

门外站着的是王吉来。

他头戴瓜皮帽，手里提着一个红纸包，却是满脸的笑："小程先生，起得早！昨儿我说了，改天登门拜谢——这不，天没亮就来了，怕您出门。"

他进门，把红纸包放在柜台上："这是当铺的一点心意，不成敬意。"又摸出一卷老头票，"少爷特意嘱咐的——他那副药好使，今儿烧退了，就是还想在家养两天。少爷让我带句话：谢谢小程先生。"

程靖霖推辞不过，收下了。王吉来搓着手，又像是随口一提："大掌柜这两天跑上跑下的，也不知道忙些什么。您要是有事寻他，怕是要扑空。"

他走到门口，又回头补了一句："往后程家要周转，手头紧，言语一声。城里面，老王家的面子还在。"

门帘子放下，屋里那股客气劲儿也跟着散了。红纸包在柜台上，包得方方正正。

**若昨日去了大车店**（对应：`MED_Demo Event 003B 1942年1月31日 黄昏 大车店支线.md`）：

门外站着的是张老大。

他背着个褡裢，嘴里叼着烟袋，烟锅里的火星在风里一明一灭。看见程靖霖，他把烟袋在鞋底上磕了磕："老弟。"

"张把式要走了？"

"这兄弟烧了一夜，今儿好些了，我送他回乡。"张老大从怀里掏出一张叠好的皮子，塞进程靖霖手里，"山里打的，你拿回去给掌柜的。人参的事，两清了——我张老大说话算话，下回有事，多多帮忙。城里城外的，有信要传，说一声。"

他拱了拱手，转身走进晨雾里。

---

后堂传来一声咳嗽。

程靖霖关上门，把东西收好，转过身。程时一已经站在柜台后头了，惨白的晨光里，掌柜的脸隐在黑暗之中，看不清他脸上的表情。

他抬头看了程靖霖一眼，没问是谁来了，也没问送来什么，只把桌上一样东西推过来：

"领口粮去，赶早，别赶晚。"

程靖霖应了一声，接过粮本。

程时一又说：

"药房这边，我又翻出一份药。你领完口粮回来，还有一趟要跑——昨儿没送成的地方，今儿补上。别让那几家人等急了。"

（此去向下＝第二个送药任务，去向见《1942年2月1日全部可能事件索引》D2-03A 警署 / D2-03B 当铺 / D2-03C 大车店——对应上列三支线文件的未选项。）

他说完又咳嗽了两声，拿手背掩了掩嘴，像是要把那两声咳嗽也一起咽回去。

这间屋子看不见东边的地平线，但是窗外的天，渐渐亮起来了。
