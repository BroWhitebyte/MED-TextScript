# MED 文档 1942年2月1日 上午之前 · 大成粮店（领配给口粮）

人物：程靖霖/赵掌柜（东家本人·坐柜）/账房/伙计/[[保甲差役]]（配给监督）/排队领配给的百姓

以下为文学性描述：

---

天光还是灰的，北大道上已经排起了队。

大成粮店的两扇门板卸下一扇，门口横着一张长条案，案上放着大秤、账本、算盘、印泥，还有一摞洗得发白的旧票夹。磨面声从头顶传来——上边的大成火磨坊已经响了半夜，一股子面味混着煤烟味，落在排队人的鼻子里，反倒让人更饿了。

队伍从门口拖到街面上，谁也不说话，说话费热气。偶尔有人跺跺脚，鞋底在冻硬的地上蹭出一点声响，又被风卷走了。

程靖霖排在队伍中间，绿皮粮本揣在怀里，贴着胸口。他前面是个老头，领了粮还不肯走，把布袋的口解开，凑到眼前仔仔细细看那面的颜色。伙计不耐烦地敲了敲秤杆："看什么看！协和面就是这色儿，你还想要白面？"老头便弯着腰走了，嘴里念叨着什么，风一吹就散了。

轮到程靖霖了。

他把粮本递上去。账房翻开，蘸了墨，在簿子上记了一笔，抬眼看了看他："时一堂的？几口人？"

"三口。"

"三口，一人二十三斤，六十九斤。"账房头也不抬，"你家掌柜的怎么不来？"

"掌柜的腿脚不好，让我来。"

账房哼了一声，算是应了。伙计从里间搬出一只麻袋，又拿斗斛舀面。程靖霖看着他舀了满满一斗，心里刚松一口气，那伙计手腕一抖，斗沿上冒尖的面便滑下去半寸——又拿手背抹了一下。

"正好。"伙计把面倒进程靖霖的布袋里。

程靖霖接过。袋子比想象中轻。

他没有说话，用一根麻绳把袋子扎好，抱在怀里往外走。走出两步，又停了一下，回头看了一眼柜台上那排样粮柜——里面摆着的好面，颜色要白得多，也细得多。

"那是官面的。"账房像是看见了他的目光，慢悠悠地说了一句，"伙计，再给程子来一瓢。"

程靖霖没接话，打开袋子，让伙计往里面添了一瓢面，重新扎起袋子，走进灰蒙蒙的晨光里。

街上的梆子响了最后一声，更夫老白收工了。嘶哑的声音远远传过来，还是那句："天寒地冻，防火防盗！"

天，彻底亮了。

他抱着那袋协和面往回走，忽然想起去年秋天的事——交粮是在南大道那边的粮谷奉纳所，好粮一斗一斗倒进公家的斗里，说是《粮谷出荷》，是"王道乐土"的本分。交的是黄澄澄的谷子，领回来的是这灰扑扑的协和面。

他把背上的面口袋往上送了一下，心里清楚：接下来的一个月，三口人就指着这袋面活着了。
