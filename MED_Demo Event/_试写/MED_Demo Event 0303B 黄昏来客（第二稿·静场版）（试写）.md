## 白描

天擦黑了。

灶上的火封了一半。前柜里没点大灯，只有窗台上那盏油灯。药斗一排在暗里立着，一格一格的，像一面墙。

程靖霖在捆纸包。程时一坐在柜台后头那把椅子上——那把椅子是他坐了一辈子的，椅背磨得发亮。

今天他出去了一趟。回来以后就坐在那儿，一句话没说。

## 陈述

捆到第四个纸包的时候，程靖霖觉出不对。

不是听见的。是那种——**有人在看你**的感觉。他抬起头，往门外看了一眼。

街对面，戏楼底下那片背阴的地方，站着人。

看不清脸。只看见一个影子，不动。雪地上没有脚印通到那儿，说明站了有一会儿了，雪把他自己落平了。

程靖霖低下头，继续捆纸包。绳头绕了两圈，抽紧，打结。

他把第五个纸包码好，再抬头的时候，那个人已经在过街了。

## 陈述

门帘掀开，人进来了。

进来以后，他先站着。

他不看柜台，也不看程靖霖。他看药斗。从这头看到那头，一格一格地看过去，看得很慢，像在数。

数完了，他收回眼睛，往前走了两步。

前柜里有一张方凳，是给等抓药的人坐的。他没有坐。

他绕过方凳，走到柜台外头那张椅子跟前——**那是程时一平时坐的椅子**，坐堂看诊用的，椅背上搭着一条旧棉垫。

他坐了下去。

程靖霖手里的麻绳停在半截上。

他抬眼看程时一。

程时一站着。他没有说话，也没有请客人换个座儿。他站着，两只手垂在身侧。

那个客人坐在程时一的椅子上，把皮手筒子搁在膝盖上，往后靠了靠。椅背响了一声。

然后，他抬起右手，用指节在椅子扶手上敲了两下。

不轻不重。

程靖霖心里咯噔一下——**这是他掌柜的动作**。程时一想事情的时候，就是这么敲桌子的。他从小看到大。

## 陈述

程靖霖把纸包放下，去后头端茶。

水开得慢。他在灶前等了一会儿，听见前柜里一直没有声音。没有寒暄，没有问话，什么都没有。

茶端出来的时候，他看见了那位客人的眼睛。

那是从他掀帘子那一刻开始的。

他端着茶盘走过去，那人的眼睛跟着他走。他把茶盏搁在椅子旁边的小几上，那人的眼睛还在他脸上。

**不是打量。是看住了。**

茶盏搁下去，瓷底碰到木头，响了一声。那人没有伸手。

程靖霖的手还扶在茶盘沿上。他没有动。

前柜里静得能听见灶膛里的火。

他听见程时一咳了一声。

“霖子。”

程时一的声音很平。

“去后头。”

程靖霖应了一声，退了回去。帘子落下来的时候，他回头看了一眼——那位客人还在看他。帘子挡住了。

（结算：程时一第一次把那张脸从那个目光下面挪走——**他不知道为什么要挪**——回看锚：这一句"去后头"是掩护，他自己并不知道）
（结算：全场第一句人声，是程时一的——**客人从进门到此刻，一个字没说**）

## 陈述

（靖霖离场后——前柜只剩两个养父：）

帘子落下去。

前柜里两个人。一个站着，一个坐着。

坐着的那个人从皮手筒子里抽出一样东西，搁在几上，茶盏旁边。

一个很小的纸盒。寸许见方，纸壳磨毛了，四角起了边。盒面上贴着一片长条小标签，印着洋文，笔画硬。

他把盒子往前推了推。推到几子的边沿，推不动了。

程时一没有动。

坐着的人也不动。两个人就那么待着。炉子上水壶响起来，响了一阵，又平下去。

然后程时一走过去，拿起那只盒子，揣进袖子里。

他走回柜台后头，把椅子——那把客人刚坐过的椅子——端起来，放回了原来的位置。

客人这才站起来。

他走到门口，掀帘子。帘子掀到一半，他停住了。

他没有回头。

“你养了个好孩子。”

门帘落下去。脚步声往西边去了，不快。

（结算：药未入账——**全场没有一句话谈到药**——代价后置：D16 搜家时，账本上一个字都没有；搜出来的，是那个空瓶）

## 选择必有代价

（合流——靖霖出来时看见的：）

程靖霖从后头出来的时候，前柜里只剩程时一一个人。

他站在柜台后头，手里拿着那只小纸盒。

盒盖没有打开。

他把盒子举到灯下看了一会儿——不是看盒子，是看那片标签。看得很近。

然后他拉开上头那一排药斗，把盒子放进去，合上抽屉。

他回过身，看见账本摊在柜台上，翻在今天那一页。

他看了有几息。

然后把账本合上了。今天那页上，什么也没有添。

（结算：靖霖全程看见了——**从"没人提药"到"不记账"**——他记住了，当晚什么都没问）
（结算：药斗夹层＝`地点卡 v2.0` 的既有点位——"装子弹/纸条/不能见光之物，每天被手摸过却没人知道"）

## 结束转场

饭端上来的时候，天已经黑透了。

桌上三个碗。程时一坐下，拿起筷子，没有动。

程靖霖也没有动。他坐着，想说什么，嘴唇动了一下。

程时一掩着嘴咳了两声。

“吃饭。”

程靖霖把话咽了回去，低头扒饭。

屋里只有筷子碰碗。窗外，老白梆子的声音远远地过来了：天寒地冻，防火防盗——

（→ 转场：D3 深夜——老孙持枪闯入＝重大抉择）

## 备案·两稿对照（供作者取舍）

| 维度 | 第一稿 0303（有声） | **第二稿 0303B（静场）** |
|---|---|---|
| **台词量** | 约十二句（含"开了几年了""七年"） | **客人全场一句**（"你养了个好孩子"）；程时一两句 |
| **做工方式** | **话里的半句**——来源只给一半、体面与威胁同句 | **位置的错位**——他坐了程时一的椅子、敲了程时一的动作、把椅子放回去 |
| **最强的钉子** | "开了几年了""七年" → 1935线预付定金 | **指节敲扶手两下**（＝程时一的动作）＋**"你养了个好孩子"** |
| **黑川的形象** | 体面的、按规矩来的官员 | **不说话的、只做动作的、更冷的** |
| **靖霖知道多少** | 知道"来了个惹不起的人，掌柜的收了他东西" | 知道**同样多**，但**没有一句话替它作证**——更不安 |
| **风险** | 台词略多，接近"两个人在谈话" | **极简可能过头**——玩家可能没接收到"这是个大人物" |
| **补强手段** | 无需 | 靠**门外第二人不进门**（已保留）＋**椅子错位**（已写） |

## 备案·本场埋设与回收

| 埋设 | 位置 | 回收 |
|---|---|---|
| **那瓶军用磺胺**（药不入账、全场无人提及） | 几沿上一只小纸盒→袖中→上头药斗 | D4 用药（第一支）／后续／**D16 搜家＝空瓶** |
| **"你养了个好孩子"** | 门口、不回头 | **D17"你姓白"**——同一件事的两次说破；也是"真像……"的父亲版 |
| **指节敲扶手两下** | 客人刚坐下 | 程时一的标志性动作（001 捻手指／004 敲桌子）——**两个人是同一类人**；也是"他打听过这个人"的证据 |
| **坐了程时一的椅子→又放回去** | 全场 | 一个不请自来的人，**替主人把椅子归位**——他懂规矩，而他不需要守规矩 |
| **"去后头"** | 靖霖上茶时 | 程时一**无意识的掩护**——他自己不知道为什么要挪开那张脸 |
| **灯** | 窗台油灯（D1 亮／D2 灭） | D21 灯灭——**这一夜它是亮的** |
