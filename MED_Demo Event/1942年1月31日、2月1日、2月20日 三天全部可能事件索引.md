# 1942年1月31日 / 2月1日 / 2月20日 三天全部可能事件索引（v1）

> **本文件是什么**：把 **D1（1/31）·D2（2/1）·D21（2/20）** 三天，按《1942年2月1日全部可能事件索引》的体例（**每日三问 + 六段制分节表 + 分支树 + 跨日钩子**）逐日编成"全部可能事件"清单。体例参照 2/1 索引，**口径按 2026-09-09 会议终版六段制重排**（差异见 §〇.2）。
> **为什么是这三天**：D1＝DEMO 开端（教学日）／D2＝DEMO 转折日（强求出诊）／**D21＝第三周周终·"家没了"**（Ozymandias 位，本集标题《灯》）——三天在 29 天结构里分别承担**建置→推进→崩塌**，且互为远端钩子（D1 信物 → D2 包裹 → D21 灯灭）。
> **日期换算**：D1＝1/31，D2＝2/1，D3＝2/2，……**Dn＝1/31＋(n−1) 天**；故 D16＝2/15（除夕·入狱日）、D21＝2/20、D29＝2/28。DEMO＝1/30–2/2 四天（含 0000 序章＝1/30 黄昏）。

## 一、D1 · 1942年1月31日

> **本日三问**（want / obstacle / turn / cost / button——落于索引头部，各 event 头部引用本节）
> **⚠ 本日四答＝本文件首次成文（拟稿）**：经全域检索，**D1 原无任何"每日三问"记载**（`写作手册` §三·补 3 只把三问落在索引头部，而 D1 无索引件）；0101–0106 六件头部**均无**"本日三问"引用行。以下四答由本文件依据原文素材拟出，**待作者确认后方可回写各 event 头部**。
> 1. **want**：程靖霖想要**照着规矩跑完这一趟**——把药送到、把话带到、不给掌柜惹事（0101 程时一："**不该看的别看，不该问的别问。走到哪，都得记得。**"）。**obstacle**：煤只够三天、粮够半个月（0101）；"**我这里只有一份药，但是有三个地方要**"（0102）——资源不够分。
> 2. **turn（关系重定义）**：从"跑腿的伙计"变成"**要替掌柜做取舍的人**"——"一份药、三处要"的第一次取舍（0102）；**人情账自此起算**（"你选哪家都对，就是卖个人情"）；黄昏 0104 由程时一明说放权："**从今儿起，这板子上的事，办不办、先办哪件、什么时候办——你说了算。**"
> 3. **cost**：三选一各有代价——警署＝药钱被劫＋受刑者的眼睛（003C）；当铺＝双倍回报，但吃下王家的"人情"与账（0103A）；大车店＝人参当小押，接住张老大的一句承诺（0103B）。**账本行＝人参（D1 埋设·H71 去向留白）**。0104 代价句："**人情这东西，比钱沉。**……你欠了人家的，早晚得还。"
> 4. **button**：**信物（辽13式步枪子弹）交到玩家手上**——**定格物证型**〔落位见 §一.七〕；**末句**："**那是一颗步枪子弹。**"

> **本日定位（D1）**：DEMO 第一天·**教学日**（新手教程＝"叙事的合理性的部分"，整合表序号 4-10）。核心事件：**第一次送药（马家）**、**三选一（警署／当铺／大车店）**、**看板教程**、**叶子戏**、**信物归还（资产）**。
> **本日结构（26.9.8 三轮汇总）**：`清晨教学(001) → 上午去马家(002) → 下午三选一(003A/B——警署摘出) → 黄昏看板教程(004) → 夜晚叶子戏打牌(005·马老二凑局) → 午夜无事件（睡得很香）`
> **本集标题**：**《纸绳》**（29 天标题系统，D1）。
> **冷开场类型**：固定教学日——**豁免类型轮换**（戏剧冲突审计 Q22：固件日 D13/D16/D21/D27/D29 豁免；D1 教学同理）。
