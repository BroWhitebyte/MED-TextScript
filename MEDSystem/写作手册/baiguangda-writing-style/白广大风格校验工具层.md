# 白广大风格写作 · 校验工具层

> **定位**：`白广大写作风格skill.md` 是"怎么写"的规范；本文件是"写完怎么验"的工具层——规则表、评分表、语域选择器，配套可执行脚本 `scripts/style_lint.js`（位于本目录下）。
> **依据**：全部阈值为 444 篇书面语料（101.5 万字）、47 段访谈口语（1.95 万字）、1 篇口述文（0.39 万字）的实测统计值（见第四节与 `corpus/corpus_compare.txt`）。
> **用法**：初稿 → 跑 linter → 对照评分表打分 → 按负样本库修订 → 复跑。

---

## 一、校验规则表

### A 级 · 硬错误（出现即必须修改）

| # | 检查项 | 判定方式 | 语料依据 |
|---|---|---|---|
| A1 | 中文行文混用 ASCII 直引号 | 正文出现 `"` （代码块、URL、纯英文引语除外） | 书面语料一律使用弯引号 `“”`；真实事故：一篇稿出现 44 个直引号 |
| A2 | 元叙述句 | 命中 `先说`/`再说`/`先聊`/`再聊`/`最后说说`/`先说好` | 全语料无此句式；小标题自带信息，无需导游 |
| A3 | "不是……而是……"模板 | 正则 `不是[^。；！？\n]{0,24}而是` | 全语料转折靠 但是 842 / 不过 427 / 其实 309 次 |
| A4 | AI 腔黑名单句式 | 命中：综上所述、总的来说、总而言之、值得注意的是、不难发现、`随着…的发展`、`在当今…的时代`、`首先…其次…最后`、众所周知、值得我们深思、`在…的背景下`、这不仅…更是 | "综上所述""总的来说"等在全语料出现 **0 次** |
| A5 | 假出处格式 | `——某书，某年` 但无法指出章节/作者/可核查来源 | 第十二节史实核查协议：格式越像真的越要核查 |

### B 级 · 警告（建议修改）

| # | 检查项 | 阈值 | 语料依据 |
|---|---|---|---|
| B1 | 签名表达超量 | "坦率地说" ≤1；"不解释。" ≤1；"醍醐味" ≤1；"味儿" ≤2；"图一乐" ≤1 | 全语料：坦率地说 13 次、醍醐味 6 次、图一乐 1 次 |
| B2 | 括号吐槽超量 | `（笑）（误）（？）（无贬义）（指本人）（大雾）（捂脸）` 合计 ≤2 | 仅 14 篇使用，各标记个位数次 |
| B3 | 句长落差不足 | 句长标准差 < 12，或短句（≤10 字）占比 < 2% | 书面句长中位 44、p90 93、≤10 字占 4.4% |
| B4 | 引用出处缺失 | 全文 `——` 出处格式 0 处（2000 字以上稿件应 ≥2 处） | 书面 `——` 每千字 1.44 次；`——《` 52 次/33 篇 |
| B5 | 数字密度不足 | 年份（`\d{4}年`）< 3 处，或全文无具体数量 | 275/444 篇含年份，全书 1,135 处；百分比 202 处 |
| B6 | 破折号/括号失衡 | `——` < 1/千字，或 `（）` > 3/千字 | 书面：—— 1.44/千字、（）1.73/千字 |
| B7 | 段落长度均匀 | 全文段落均在 100—200 字、无 < 60 字短段 | 段落中位 229 字、p25 95 字（长短交错） |

### C 级 · 提示（信息性）

| # | 检查项 | 说明 |
|---|---|---|
| C1 | 口语句式密度 | `其实+就是+然后` 每千字 >2 → 书面文偏口语（见第三节语域选择器） |
| C2 | 结尾方式识别 | 自动归类：设问/升华/祝福/预告/自嘲/诗化，提示是否符合六式之一 |
| C3 | 标题特征 | 检查是否含冒号、问号、数字、书名号、竖线、【】前缀之一（九公式） |
| C4 | 密度体检 | 输出全文字数、段落数、句数、均句长、引用数、数字数，供与语料基准对照 |

## 二、A/B 评分表（满分 100）

| 维度 | 权重 | 评分标准（0—满分） |
|---|---|---|
| 标题钩子 | 10 | 9—10 含信息+钩子（九公式之一）；5—8 有信息无钩子；0—4 平淡或夸张失实 |
| 开头路线图 | 10 | 9—10 陈述式导语/时间锚点，一段内给出背景与命题；0—8 抒情腔、比喻堆砌、无路线图 |
| 证据密度 | 20 | 按每千字：年份 ≥1、专名 ≥3、可核查出处 ≥1 → 满分；缺一项扣 5 |
| 引用规范 | 10 | 出处格式 `——来源，年份` 且可点击核查 → 满分；装饰性引用或假出处 → 0 |
| 语域控制 | 15 | 三档语域（书面/口述/访谈）选择正确、雅俗摆动幅度恰当 → 满分；通篇单一语域扣 8 |
| 结构与节奏 | 15 | 小标题口语带钩子、段落长短交错、句长有落差 → 满分；均匀三段式 → 扣 8 |
| 幽默与签名 | 10 | 1—2 处定点爆破、有靶子、括号点到位 → 满分；贴标签式堆砌或全程无 → 扣 5 |
| 结尾 | 10 | 六式之一且拒绝总结癖 → 满分；"总的来说"式总结或对读者煽情 → 0 |
| AI 腔清零 | 硬扣 | 每命中 1 条 A 级错误 −10 分（可扣至负分，负分视为不合格） |

**判定线**：≥85 可发布；70—84 需按 B 级警告修订；<70 退回重写。

## 三、语域选择器（三档，按稿件形态选择）

同一作者在三类载体上的语料实测差异（每千字出现次数）：

| 指标 | 书面文章（基准） | 口述/自述文 | 电台口播/访谈稿 |
|---|---|---|---|
| 句均长（字） | 52 | 58 | 47 |
| 短句（≤10 字）占比 | 4.4% | 6.2% | 6.1% |
| 其实 | 0.30 | 0.52 | **2.00** |
| 就是 | 0.99 | 1.30 | **2.41** |
| 然后 | 0.15 | 0.00 | **0.87** |
| 这个 / 那个 | 1.42 / 0.15 | 2.33 / 0.52 | 2.61 / 0.56 |
| 东西 | 0.22 | 0.00 | **1.18** |
| 我 / 我们 | 6.03 / 2.75 | 5.96 / 1.04 | 7.83 / 5.12 |
| 问号 | 1.23 | 0.78 | **3.58** |
| 然而 / 不仅 | 0.18 / 0.27 | 0.00 / 0.78 | **0 / 0** |
| 破折号 | 1.44 | 1.56 | 0.87 |
| 括号 | 1.73 | 0.00 | 2.61 |

**选择建议**：
- **书面考据/评测/新闻** → 按基准列写作；口语标记克制（其实 ≤0.5/千字）。
- **口述/自述（第一人称经历文）** → 句长可拉长到 55—60，"不仅"类连接词可用，但破折号与引语偏多；人称密度回落（口述经编辑整理）。
- **电台口播稿/访谈答话** → 口语标记放开（其实 2、就是 2.4、然后 0.9），正式连接词清零（然而/不仅不要出现），疑问句密度约为书面 3 倍（自问自答多），括号插入语增多。

**跨档禁忌**：把口播稿的口语密度（其实 2.0）搬进书面长文，或把书面文的连接词（然而 0.18）搬进口播稿，都会立刻失真。

## 四、可执行校验

```sh
node "02_白广大写作风格/scripts/style_lint.js" <稿件.md>
```

输出：A 级错误逐条定位（含行号与上下文）、B 级警告计数、C 级体检数据、总分预估与修改建议。

配套文件：
- `白广大风格负样本库.md` —— 十大错误模式的错例/错因/改写示范；
- `scripts/style_lint.js` —— 规则实现（正则与阈值即上表）；
- `scripts/build_corpus.js`、`scripts/corpus_stats.js` —— 语料提取与统计脚本；
- `corpus/corpus_compare.txt` —— 三档语域统计原始输出；
- `corpus/corpus_interview.txt` —— 47 段访谈口语语料（1.95 万字）；
- `corpus/corpus_oral.txt` —— 口述文语料。
