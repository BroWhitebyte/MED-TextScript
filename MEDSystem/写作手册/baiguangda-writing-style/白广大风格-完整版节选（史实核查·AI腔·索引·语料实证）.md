## 十二、史实核查协议（考据文的硬纪律）

白广大的考据文之所以可信，是因为细节经得起核查：年份精确到日（“1949年5月20日……颁布了……戒字第壹号令（[原文](https://www.gcores.com/articles/22672)）”）、数字精确到个位（“军事法庭受理的政治案件29407件（[原文](https://www.gcores.com/articles/22672)）”）、引文必注出处（“——《蒋介石日记》，1949年1月22日（[原文](https://www.gcores.com/articles/22672)）”）。模仿其风格，必须同步继承其核查纪律——否则就是“有老白的腔调，没有老白的信用”。

### 1. 数字三查
- **时间**：年份、日期、时刻必须核实（“7月9日上午11点35分，他站在栈桥上（[原文](https://www.gcores.com/articles/19657)）”）；写“今天”“近日”时，确认所指日期真实存在；
- **数量**：人数、金额、销量、百分比精确到个位（“13人死亡，5510人受伤（[原文](https://www.gcores.com/articles/95744)）”“赔偿金总额约1.57亿（156,693,720）日元（[原文](https://www.gcores.com/articles/114786)）”“总体识字率约21.1%（[原文](https://www.gcores.com/articles/151948)）”）；
- **专名**：人名、地名、机构名、作品名用全称，外文附原名（俄文 Григорий Ефимович Распутин、日文 不謹慎ゲーム、Axiom 的希腊语词源）。
- 规则：写不出精确数字时，用“据估计/约”而非“大量/众多”；**任何精确数字都必须有来源**，无来源的数字宁可不写。

### 2. 引文三查
- **查原文**：引文必须逐字核对原文，注明版本/篇章（引《创世纪》标注 “CUV - Simplified ch.”（[原文](https://www.gcores.com/articles/173533)），引《礼记》标注篇名）；
- **查出处**：“——来源，作者/机构，年份”必须真实存在——**严禁编造该格式的假出处**（这是 AI 幻觉的高发区：格式越像真的，越要核查）；
- **查语境**：不断章取义；外文引用附中文翻译，译文质量自己负责；引文后必接自己的评价或分析，不堆砌引文。

### 3. 事实与传闻分级

| 级别 | 处理方式 | 白广大示范 |
|---|---|---|
| 实锤（官方公告/判决书/一手史料） | 直接陈述 | “终审判决Koei Tecmo需向Capcom支付赔偿金总额约1.57亿（156,693,720）日元（[原文](https://www.gcores.com/articles/114786)）” |
| 媒体报道 | 注明来源 | “*内容编译自Polygon、Kotaku等相关报导（[原文](https://www.gcores.com/articles/96846)）” |
| 传闻/爆料 | 明确标注 | “据传”“Reddit上的舅舅党开始爆料”“无责任爆料” |

用量提示：传闻类标注在全语料中相当克制——总计约 26 次/444 篇（“据悉”9、“传闻”7、“据称”4、“据传”3、“无责任”2、“舅舅党”1），主要出现在新闻与爆料语境；长文考据里几乎不用，需要不确定表述时用“或许/可能/据说”代替。
| 推测/解读 | 明确标注 | “个人推测”“无根据过度解读”（其标题《黑神话·悟空》2022年PV剧情无根据过度解读（[原文](https://www.gcores.com/articles/155395)）即示范） |

规则：**事实不掺观点，观点不伪装成事实。**

### 4. 多源互证
- 重大事实至少两个独立来源；历史考据优先一手史料（法令、日记、档案、判决书），次选权威学术著作，再次才用百科与媒体；
- 来源冲突时如实呈现分歧，不强行取整（如亚塞诺瓦茨集中营遇害人数，他写“受害者数目的基础共识至少是8-10万人左右（[原文](https://www.gcores.com/articles/149464)）”）；
- 引用的二手转述，注明转述链（“根据他的描述”“据多家日本媒体报导”）。

### 5. 发表后纠错
- 发现错误必须公开更正：他的[《关于对〈科乐美出售寂静岭域名〉不实资讯的致歉声明》](https://www.gcores.com/articles/117920)与[《我向所有关心机核的朋友们道歉》](https://www.gcores.com/articles/125591)是示范；
- 更正格式：【更新】/【更正】+ 时间戳，保留原文与更正说明（“## 8月23日更新（[原文](https://www.gcores.com/articles/101159)）”结构）。

### 6. 可核查性约束
- 本 skill 的全部示例引文均已附原文链接（https://www.gcores.com/articles/ID），撰写时直接点击核查；
- **新写入的每一条引用、数字、日期，都应保证能被读者顺藤摸瓜地验证**——这是“老白式考据”的底线；无法验证的内容，要么删掉，要么降级为“据传/个人推测”并明确标注。

## 十三、与 AI 写作风格的差异：深挖与规避 AI 腔

### 1. 表层之下的深层特征（按可模仿度递减排列）

1. **证据链写作**：引用承担证据功能——从游戏里的“生界/影界”一路考据到《雅威典》词源、axioma 的希腊语流变（[原文](https://www.gcores.com/articles/173533)），每个断言都有文献落点；AI 的引用是为了显得博学，白广大的引用是为了让人核查。
2. **立场是身份承诺**：对《辐射》又爱又恨（[原文](https://www.gcores.com/articles/17417)）、对独立开发者有明确同情、对“不谨慎游戏”有明确道德判断（[原文](https://www.gcores.com/articles/95744)），十年不变；判断错了会公开致歉，这套判断、犯错、纠错连成的闭环是人格信任的基石。
3. **时间锚定**：“1986年夏天（[原文](https://www.gcores.com/articles/18959)）”“7月9日上午11点35分（[原文](https://www.gcores.com/articles/19657)）”“就在刚才（北京时间2019年1月11日）（[原文](https://www.gcores.com/articles/105370)）”——他是“正在发生的文化史”的同时代人，新闻与考据的杂交体。
4. **个人生命史是内在时间轴**：5 岁的 Atari 2600、35 岁的《你为什么玩游戏？》（[原文](https://www.gcores.com/articles/18959)）、女儿出生后的“育儿”系列（[原文](https://www.gcores.com/articles/129487)）、“中年肥宅”自嘲（[原文](https://www.gcores.com/articles/107422)）——知识用人生经验做中介。
5. **语域主动摆动**：在“他娘的”与“有鉴于此”之间大幅切换，立论用雅言建权威，吐槽用口语破权威——一个声音里的两个声部。
6. **旁逸斜出**：“顺便说一下，今天还是没有看到导演，据说他家的公猫在怀孕之后意外流产了。让我们深深地祝福它吧！（[原文](https://www.gcores.com/articles/96052)）”——无信息量的毛边就是人味。
7. **情绪有真实指向**：愤怒、哀伤、狂喜都有具体对象（悼单田芳“呜呼，白眉已随秋风去，世间再无三侠剑！”（[原文](https://www.gcores.com/articles/101977)）、悼金庸（[原文](https://www.gcores.com/articles/103358)）、为 12 岁去世的玩家 Wes Pak 写“好样的，谢谢你们”（[原文](https://www.gcores.com/articles/102348)）、骂 B 社“小公司啦”（[原文](https://www.gcores.com/articles/17417)）），情绪落在具体的人与事上，修辞渲染到不了这个位置。
8. **结尾拒绝模板**：六式结尾无一“总结全文”，偏爱把问题抛回读者或留一句余韵（见第六节）。
9. **读者是具体社群**：回应站内事件、点名感谢提供消息的网友（“感谢本站网友chenzj的大力支持”（[原文](https://www.gcores.com/articles/97127)））、悼念站内作者——有来有往，有欠有还。
10. **句子有身体感**：“育碧赢了。”（[原文](https://www.gcores.com/articles/97106)）四字独立成段 vs 百字排比长句，长短落差就是节奏。

### 2. 通用 AI 腔的特征（写作时主动规避）

- **平均化**：句长、段长、情绪都向均值回归——没有“育碧赢了。”这种四字炸弹；
- **平滑化**：输出“干净”，没有毛边、没有括号吐槽、没有自曝其短；
- **安全化**：立场端水，不敢得罪任何一方（白广大敢写“B社是否将成为最大输家？”（[原文](https://www.gcores.com/articles/17417)））；
- **模板化**：开头总起→中间分点→结尾升华的三明治结构顽固；
- **无时间性**：不知道“今天”是什么，除非提示词注入；
- **无身体性**：没有童年、没有工位上的荒诞日常；
- **引用装饰化**：引用是为了“显得有文化”，且常是幻觉出处；
- **幽默怯懦**：笑点永远安全（谐音梗、自嘲括号），没有靶子和价值观；
- **同质化**：DeepSeek、Kimi、ChatGPT 输出之间的区分度，远低于白广大与任何编辑的区分度——下一词预测天然向“最平庸的共识”收敛，而风格（style）的本质是“偏离共识的稳定方向”。

**AI 高频句式黑名单（出现即改写）**：

- **硬性禁用一：元叙述式提示语**——不用 `先说历史` `再说玩法` `先聊X，后聊Y` `最后说说……` 这类替读者安排阅读顺序的提示语。小标题本身就是路标，正文直接开写，读者自己会跟上；出现 `先说` `再说` `先说好` `先聊` `再聊` `最后说说` 即改写。

- **硬性禁用二：对举框架**——不用 `这不是……，而是……` `XX 不是 A，而是 B` `X，而非 Y` 这类模板。它引入一个读者没问过的对立项，读者要先理解被否掉的那半句才能理解你要说的那半句。要表达转折，用“然而/但是/不过”直接说，或者拆成两句平铺。白广大的转折从来不靠这个模板。

- 其余黑名单（出现即改写）：`综上所述` `总的来说` `总而言之` `值得注意的是` `不难发现` `随着……的发展` `在当今……的时代` `这不仅是一个……的问题` `一方面……另一方面……（无立场的端水）` `首先/其次/最后（机械分点）` `值得我们深思` `在……的背景下` `众所周知`。

### 3. 词频限量（可测量版本）

第 2 小节的黑名单只说了“哪些词不能用”。写成稿时真正拖慢阅读的，是那些不在黑名单里、但被用得太密的词。本节把密度设成上限，按每千字折算。

| 项 | 上限 | 说明 |
|---|---|---|
| 对举框架（不是……而是……、并非……而是……、A，而非 B） | **0 次** | 与硬性禁用二同一条 |
| `不是`、`而是`（单独出现） | 每千字 0.4 次 | 部分否定是正常表达，所以不设零；但同一段里不得重复 |
| `更` 加形容词（更值得、更重要、更直接） | 每千字 0.5 次 | 比较级堆叠。`越来越`、`更好/更快` 这类平行对比不计 |
| `一` 加量词（一个、一种、一次、一条、一句） | 每千字 2 次 | 同一段落内不得重复；连续两句不得都以它起头 |
| 装饰性破折号复合词（判断—犯错—纠错） | 0 次 | 解释性破折号正常使用，不受限 |

计数豁免：数字里的“一”（2026 年、1.69 小时）、专名（《一人之下》）、引文原话。

上限的标定依据来自第十五节的语料统计。白广大 444 篇文章约 101 万字符，“咱们”全语料只出现 14 次，括号吐槽总共只有 14 篇用过；签名类表达的实际密度是全篇一两处。按这个量级反推，一个 2,000 字里出现 30 次“一”加量词的稿子，那些“一”在承担填充功能。

**替换方法**

| 原写法 | 改法 | 依据 |
|---|---|---|
| 一个助手最贵的动作 | 助手最贵的动作 | 汉字名词自带不定指，多数场合直接删 |
| 做过一次复核 | 做过复核 | 同上 |
| 一条值得记住的细节 | 值得单独说的细节 | 同上 |
| 一种常见的误解 | 这类误解 | 需要不定指时，换具体量词 |
| 更直接的数字 | 这组数字值得单看 | 把比较关系说成事实 |
| 更麻烦的是 | 麻烦的地方在于 | 同上 |
| 这是一个更狠的提醒 | 提醒相当狠 | 删掉“一个”与“更”，句子意思不变 |

**自检**

成稿跑一遍脚本，把统计结果附在交付物里：

```
powershell -File scripts/check_banned_wording.ps1 -Path <文件> -Start <首行> -End <末行>
```

脚本按每千字折算上限，超限时打印命中位置并以退出码 1 结束。两条已知限制。脚本的豁免只覆盖反引号包裹的规则定义与 Markdown 表格行；正文里的中文引号不豁免，因为它同时承担正常引用功能，把它算作豁免会让检查器漏掉真正的违规。所以本节的黑名单与限量表统一用反引号书写。另有一条环境事实：脚本文件必须存为带 BOM 的 UTF-8，Windows PowerShell 5.1 按 GBK 读取无 BOM 的 `.ps1` 会把中文正则解坏，报 `Unterminated [] set`。

### 4. 对照速查（白广大 vs 通用 AI 腔）

| 维度 | 白广大 | 通用 AI 腔 |
|---|---|---|
| 立场 | 敢下判决，十年不变 | 端水，追问即漂移 |
| 证据 | 可核查的出处链（——来源，年份） | 装饰性引用，常有幻觉出处 |
| 时间 | 强锚定（“就在刚才（北京时间2019年1月11日）”）（[原文](https://www.gcores.com/articles/105370)） | 无时态综述 |
| 身体 | 真实童年/女儿/工位/中年危机 | 无，只能伪造 |
| 语域 | 雅俗大幅摆动，有意图 | 平滑中间地带 |
| 信息 | 疏密有致，旁逸斜出 | 密度均匀，100% 相关 |
| 情绪 | 真实起伏，指向具体对象 | 平稳、安全 |
| 结尾 | 六式，拒绝总结癖 | “总的来说”三明治 |
| 幽默 | 定点爆破，有靶子有价值观 | 安全均匀，不敢冒犯 |
| 社群 | 与具体的人对话、道歉、还人情 | 对抽象“读者朋友们”广播 |
| 纠错 | 公开致歉（[117920](https://www.gcores.com/articles/117920)/[125591](https://www.gcores.com/articles/125591)） | 公式化道歉或沉默 |
| 可辨识度 | 一眼可辨 | 三家互相难分 |

### 5. 结论：可模仿与不可模仿

- **可模仿（形式层）**：标题公式、导语结构、小标题风格、过渡词库、括号吐槽、引用格式、结尾套路、数字密度纪律——严格指令下可做到七八成。
- **不可模仿（本质层）**：
  - 证据的真实性——AI 会编造“——《蒋介石日记》，1949年1月22日”格式的假出处，唯一的解法是写作流程上强制查证（见第十二节）；
  - 立场的一致性——AI 的立场是每段临时生成的，解法是写作前先写“立场声明”（本文明确站队 X，不打算平衡）；
  - 时间与身体的在场——AI 没有“1986年夏天”，解法是使用者提供真实的个人素材，AI 负责组织；
  - 旁逸的品味——AI 知道“该放一个括号吐槽”，但不知道“什么值得吐槽”，这是品味问题，无法用规则穷尽。
- **使用建议**：把本 skill 当作“白广大的影子”而非“白广大本人”。立场、经历、查证由使用者提供，AI 负责按老白的语法组织。写完对照第十二节做事实核查，再对照本节的 AI 腔黑名单做清理，最后过一遍第十一节自查清单。
