# 写作手册

本目录收三类东西：**检查规范**、**写作规范（可激活的技能）**、**落卡规范**。

## 一 检查规范

| 文件 | 内容 |
|---|---|
| `画布检查规范_结构篇.md` | 豁免与既定设计——结构／版式／选项类检查的口径，是**检查器的唯一依据** |
| `画布检查规范_考证篇.md` | 史料考证类检查的口径：证据等级、时点纪律、输出体例、检索范围纪律 |
| `画布考证核验_操作.md` | 「审查」与「索引」两条轨道的 prompt 逻辑与调用惯例（正文）＋一句话生成索引（附录） |
| `SPEC_RECIPE.md` | 画布落卡规范：spec → `ncanvas_from_spec.ps1` → 覆盖率检查 → 三审计器 |
| `med-canvas-verify_SKILL.md` | 考证技能的 `SKILL.md` 备份；技能本体在工作区 `.dsh\skills\`，引擎与数据见 `tools\med-canvas-verify\` |

## 二 写作技能（可激活）

以下两个目录是 DSH 技能包，**复制到工作区的 `.dsh\skills\` 即可被加载**：

| 目录 | 用途 |
|---|---|
| `tonglan-narrative-style/` | 通兰叙事法：怎么写（白描、物证、事件件语法）。含 13 份 references，其中《附录A 通兰世界速查》《附录B MED术语与体例速查》是设定速查 |
| `baiguangda-writing-style/` | 机核系考据文风（游戏文化考据、评测、行业观察），与本库叙事写作并行使用 |

## 三 口径优先级

**项目文档 > 写作技能 > 考证工具的历史口径提示**。三者冲突时按此裁定，并在对应文件里改口径，不要各留一份。

## 四 与工具的关系

- 检查器（`tools\`）读《画布检查规范_结构篇》的口径与 `tools\med-canvas-verify\lexicon.tsv` 的时点／用词判据；
- 索引产物落在 `MED_考证索引\`，审查意见（`EventNNN_审查意见.md`）同目录；
- 时点纪律目前仍分散在四处（本目录、词表、`_handoff\接续说明.md`、索引文档），收敛方案见该工作区的《待裁定-时点纪律收敛.md》。
