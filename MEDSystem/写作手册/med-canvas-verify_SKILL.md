# MED 画布考证核验（med-canvas-verify）

> 一句话：**只读画布 · 时点为轴 · 三道闸门 · 本地库优先（联网兜底）· 出处到页 · 确定性输出**
> 本技能是项目第四类体检（前三类：结构闭环 `audit_flow`／框体重叠 `check_overlaps`／选项代价 `audit_choice_cost`）。
> 口径唯一真相仍是 `_tools\audit_decisions.md`；本技能不另立豁免规则。

## 〇 目录与角色

| 文件 | 角色 |
|---|---|
| `med_verify.js` | 引擎（Node，无依赖） |
| `lexicon.tsv` | **查什么**：词表（主词／别名／消歧／证据等级／时点闸门／用词裁定） |
| `citations.seed` | 出处源文件（人写，`^` 列分隔见文件头注释） |
| `citations.jsonl` | 编译产物：出处台账（工具生成，勿手改） |
| `rules.json` | 判据与配置（时点、闸门级别、配额、输出目录、主题分组、元层豁免） |
| `画布考证规范.md` | 规范全文（级别定义、时点纪律、输出体例、检索范围纪律） |
| `审查与索引_prompt逻辑与调用惯例.md` | **操作读本**：审查（四类体检＋审查意见体例）与索引（口令／判定顺序／命令／产物）的 prompt 逻辑与调用惯例 |
| `.cache/<事件名>.search.json` | 检索缓存（同输入重跑零成本） |

## 一 五条铁律

1. **只读画布**——任何模式都不写 `.ncanvas`；输出只落 `MED_考证索引\` 与 `.cache\`。
2. **先闸门后检索**——`lint` 不依赖语料／不需检索库，任何情况下都能跑；`index` 才查库。
3. **出处必须到页**——`著作 — p{PDF页}（书页 {印刷页}）— 文章标题`；两个页码都给（实测差 10–14 页）。
4. **dry-run 默认**——`index`／`batch` 不加 `--write` 只打印；`lint` 有 error 时退出码 1。
5. **本地库优先，联网兜底**——考证依据只认本地库书证（整页 `✓`／片段 `·`）。本地 0 命中或命中全为异代异地语境、而该词会进正文时，才走 `web_search` → `web_fetch`；结果标 `〔网络来源·未入库〕`＋URL＋访问日期，**不回填 `citations.seed`**，也不得替 X 类闸门开豁免。同一问题换源 3 次无果即报「查不到」。细则见 `审查与索引_prompt逻辑与调用惯例.md` §2.3。

## 一·补 一句话触发的标准动作（2026-09-30 新增）

用户说「**生成 101 的考据索引**」「**给 202B 出一份索引**」「**对 306 跑体检**」「**把今天的汇总一下**」时，按此执行：

1. 画布有新增/改名时先 `node ".dsh\skills\med-canvas-verify\scan_events.js" --write`（重建代号登记表）；
2. `node $S list` —— 确认代号在册；
3. `node $S lint --event <代号> --all` —— 先看闸门（秒级、离线、不需检索库）；
4. `node $S index --event <代号> --write` —— 出索引，落 `MED_考证索引\<代号>_索引.md`；
5. 多件：`node $S batch --only 101,102 --write`；汇总：`node $S index-events --write` ＋ `node $S history`。

**代号解析**：`--event` 收代号（`101`／`103A`／`202B`，也认画布内部旧号 `204A`）或显式路径。
**时点来源**：显式 `--period` ＞ 登记表该件日期 ＞ `rules.json` 默认——**一般不必手写时点**。
**耗时预期**：≥3 字的词走 FTS5 trigram（毫秒级）；2 字词（「煤」「当铺」等）只能整表 LIKE，约 3–5 秒/词，故单件约 15–40 秒。
**完整操作与三层汇总**见同目录 `如何生成索引.md`。

用户说「**审一下 104**」「**104 有什么问题**」时，走**审查轨道**（不止看闸门）：结构／重叠／代价／史料四类体检 → 出 `MED_考证索引\EventNNN_审查意见.md`，体例（七节＋尾注）、A/B/C/D 分级与只读纪律见 `审查与索引_prompt逻辑与调用惯例.md` §四。

**节点数与分支数**随审查一并读：`tools\audit_flow.js`（节点／连线／Entry／End／可达）＋ `_tools\audit_choice_cost.js`（选择点／每选项独占支／汇合点），判据（分叉必有代价、分支配得上件型、多 End 须有意）见同文档 §4.2；索引头部记「N 节点／M 连线」，改稿后用它比对新旧版本。

**文字量与时长是硬性参数**：每份审查结论与索引都要带总文字量／陈述文字量／对话文字量／选择肢数量／选择肢长度／完成时长估算六项，用 `node "_tools\ncanvas_metrics.js" <代号>`（全库 `--all`）出数，口径与速度常数见同文档 §4.3。

## 二 标准流程

```powershell
$S = ".dsh\skills\med-canvas-verify\med_verify.js"          # 引擎（唯一真相）
# 亦可从项目惯例位置调用（薄启动器，转发到同一引擎）：
#   node _tools\med_verify.js <同样的参数>
$E = "06_MED_TextScript\MED-TextScript\MEDNarrative\Flows\【主线】序章\新序章.ncanvas"

node $S lint  --event $E --all        # ① 离线闸门：时点／用词／缺口（先跑这个）
node $S terms --event $E              # ② 看本件命中哪些词（决定要不要扩词表）
node $S index --event $E              # ③ 检索+生成（打印，不落盘）
node $S index --event $E --write      # ④ 确认后落盘
```

换时点（第二天/第三天件）：`--period 1942-03..1942-04`。
换输出位置：`--out <路径>`。

## 三 闸门怎么读

| 级别 | 含义 | 处置 |
|---|---|---|
| **error** | X 类词出现在其存在时间之前（如 1942-01 写「组合」） | **必改**（或改成先兆写法） |
| **warn** | 用词裁定（药房/堂倌/皮手筒/协和面）或口径冲突（出荷督励本部） | 按 note 改写或加注 |
| **info** | C 类缺口词（金镏子/小广场/大氅）／专名重复计数 | 保留可，首次出现宜加注 |

报告末行 `覆盖：检查 N 词／命中 M 词／未命中的禁用词 …` 用来判断**这次体检的广度**——若关键禁用词长期"未命中"，说明词表没覆盖到，应扩词而不是庆幸。

**产出索引固定五节**：① 闸门结果 → ② 时点红线（穷举本时点不可用/需注意的词，**未命中也会列出**，避免"没踩就以为能用"）→ ③ 主题索引（正文）→ ④ 泛词体检 → ⑤ 检索台账。

## 四 扩词表（最常用的维护动作）

`lexicon.tsv` 一行一词，`^` 分隔 10 列（详见文件头注释）。追加一行即可参与下一轮：

```
L-9.1 ^ 洋火 ^ 民生 ^ 火柴 ^ 配给 ^ realia ^ A ^ from:1941-01 ^ 【用词裁定】东北口语"洋火"，"火柴"为官称 ^
```

- 别名多个用 `|`；消歧词**只能是单值**且不得与主词/别名重复（`lexicon` 命令会报不合规）。
- 泛词必给消歧词——`index` 会列出命中 ≥300 本的词提醒你补。
- 需要出处时，在 `citations.seed` 追加一行（9 列，见文件头），再 `node $S build-citations`。

## 五 与写作技能的分工

- **本技能**：这个名物/制度/称谓在 1942 年前后东北是否成立、出处是哪本书哪一页。
- `tonglan-narrative-style`：怎么写（白描、物证、事件件语法）。
- 冲突时：项目文档 > 写作技能 > 本技能的历史口径提示。

## 六 环境坑（血泪版，勿踩）

1. **不要经 PowerShell 处理中文文本**：PS 5.1 读 UTF-8 无 BOM 文件会按 ANSI 解，`Out-File` 会插 BOM。工具全程 Node 读写 UTF-8 no-BOM。
2. **异体字归一必须单向**：`帐→账` 这类若写成对称交换，正文与检索词会互换而互不相等（本项目真踩过，导致禁用词漏报）。
3. **列分隔符不要用 `|`**：别名内部也用 `|`，会串列；本技能一律 `^`。
4. **`node:sqlite` 是实验特性**：只在 8080 服务不可用时回退使用；日常走 HTTP API。
5. **改 Obsidian 里的画布后**，重跑 `lint` 前先在 Obsidian `Ctrl+R`（Reload app without saving），否则读到旧文件。

## 七 回归自测（改工具后必跑）

```powershell
# 负样本：含「组合／通账配给／堂倌／药房／搜荷督励」，应报 1 error + 6 warn，退出码 1
node $S lint --event "_handoff\_lint_selftest.ncanvas" --all
# 真件：应报 0 error（3 warn + 4 info），退出码 0
node $S lint --event $E --all
# 端到端验收（对照已发布索引的六条 A 类证据）
node "_handoff\_accept.js"
```

排障用 `--debug`（逐词打印命中节点与闸门是否触发）、`--refresh`（忽略缓存重查）。

## 八 已知边界（诚实声明）

- 检索优先走 8080 服务，服务未起时回退索引库直连（路径以 `rules.json.lib.db` 为准，2026-10-01 已由 `I:` 迁至 `D:\抗联整理_OCR成果`）。**检索库不可达时只有 `lint` 可用**——这是设计使然。
- 台账 `verified=snippet` 的条目是"仅检索片段"，引用定稿前需按 `著作—页数` 回取整页。
- 出处短名由库内全名截取，个别长副题书名可能截断；需要全名时看 `citations.jsonl`。
- 「出荷督励本部」的时点口径库内两说冲突，工具按 warn 报出而不替你做判断。
