# MED 画布考证规范（画布检查规范 · 考证篇）

> **定位**：本文是 `audit_flow.js`（结构闭环）、`check_overlaps.js`（框体重叠）、`audit_choice_cost.js`（选项代价）之外的**第四类体检——史料考证**的口径说明。
> **口径唯一真相**：豁免与既定设计仍以 `_tools\audit_decisions.md` 为准，本文不另立一套；两者冲突时以 `audit_decisions.md` 为准。
> **实现**：`.dsh\skills\med-canvas-verify\med_verify.js`（命令 `lint`／`index`／`search`／`terms`／`lexicon`／`build-citations`）。
> **本文件与工具的边界**：工具**只读画布**，绝不写 `.ncanvas`；只输出索引/报告文件。

---

## 一 三层数据（本插件全部可复用性所在）

| 层 | 文件 | 作用 | 谁改 |
|---|---|---|---|
| 查什么 | `lexicon.tsv` | 词表：主词／别名／消歧词／证据等级／时点闸门／用词裁定 | 人（追加行即可） |
| 有什么出处 | `citations.seed` → `citations.jsonl` | 出处台账：著作·pdf页·书页·文章标题·摘句·取证强度 | 人写 seed，工具编译 |
| 怎么判 | `rules.json` | 时点、闸门级别、配额、输出目录、主题分组、元层豁免 | 人 |

**扩一个事件只需**：在 `lexicon.tsv` 追加该事件特有的词 → 需要出处时在 `citations.seed` 追加行 → `node med_verify.js build-citations` → `index --write`。

## 二 证据等级（class）

| 级 | 含义 | 用法 |
|---|---|---|
| **A** | 同代同地直接对应（1942 年 1–2 月、东北／滨江省一带） | 可直接作为写作依据 |
| **B** | 同类实物／制度旁证（异地、或略早略晚） | 可写，但**不得据此作强断言／数字化断言** |
| **C** | 库中缺口（全库无书证） | 保留须加注或改词；工具报 `gapTerm`（info） |
| **X** | 闸门词（时点禁用或用语禁用） | 只检查不检索；期限内出现报 **error** |

## 三 时点纪律（timeGuard）

- 写法：`from:YYYY-MM`。正文出现该词且当前 `period` 早于该月 → **X 类报 error，其余报 warn**。
- 已登记闸门（截至 2026-09-30）：

| 词 | 闸门 | 依据 |
|---|---|---|
| 组合（行业） | `from:1942-07` | 鹤岗文史资料 第8辑 p88 |
| 通账配给制（劈柴/煤炭/食盐等） | `from:1943` | 李淑娟 p156；苏崇民 p410（三色通账 1943-07） |
| 出荷督励本部 | `from:1942-10` | **口径冲突**：旧口径 1942-11 才有 vs 伪满官员供述 1942-10 已在运作 → 报 warn，安全写法「粮谷搜荷督励本部」 |
| 橡子面 | `from:1941-12` | 太平洋战争爆发后大规模顶替；1942-01 宜写"开始出现" |
| 汉医许可／出诊 | `from:1941-01` | 辽宁文史资料 第26辑 p173 |
| 堂倌（用语） | 无日期，X | 东北口语一律「跑堂」 |

**事件件时点怎么给**：`--period 1942-01..1942-02`。默认取 `rules.json.period`（序章件）。第二天/第三天件请显式传参，**不要改默认值**。

## 四 用词裁定（deprecatedTerm）

词表 `note` 含 `【用词裁定】` / `【禁用】` / `【建议改词】` 时，正文命中即报 warn，提示改写；`【缺口】` 归入 `gapTerm`。

## 五 输出与顺序（确定性）

- 默认输出目录：`06_MED_TextScript\MED-TextScript\MED_考证索引\`，文件名 `<事件名>_索引.md`。
- 固定五节：① 闸门结果 → ② 时点红线（**穷举**本时点不可用/需注意的词，未命中亦列出）→ ③ 主题索引 → ④ 泛词体检 → ⑤ 检索台账。
- 排序固定：主题分组（`rules.json.sections` 顺序）→ 词表 id → 出处出现顺序。**同输入必得同输出**（检索结果缓存在 `.cache/<事件名>.search.json`，实测字节一致）。
- 出处书写：`著作 — p{PDF页}（书页 {印刷页}）— 文章标题`；`〔〕` = 章节/卷次名，`《》` = 书名或法规名。
- **双页码必写**：PDF 顺序页与原书印刷页实测差 10–14 页，只写一个会引错页。
- 标记：`✓` 已取整页核对／`·` 仅片段／`〔未取页〕` 仅命中。

## 六 检索范围纪律（防漏报／防刷屏）

1. **异体字单向归一**：`帐/账`、`著/着` 等映射到同一代表字后再比（曾用对称交换，导致两侧互换而互不相等 → 漏报）。
2. **泛词必须消歧**：`disambig` 列给出同页 AND 词；`index` 会自动列出命中 ≥300 本的词，提示补消歧。
3. **短词回退**：≤2 字词 FTS5 可能分词失败，工具自动回退 `LIKE`。
4. **非游戏文本不参与**：以 `【】` 开头的内部卡（`【结算】【转场】【提示】` 等）不进入闸门与关键词统计。
5. **元层豁免**：`rules.json.exempt.metaLayer` 命中时（如 `106`）闸门全部跳过。
6. **配额**：`rules.json.caps`（默认 120 查询／40 取页）；超限即停并报账，不自动重试。

## 七 命令

```powershell
$S = ".dsh\skills\med-canvas-verify\med_verify.js"      # 引擎（唯一真相；_tools\med_verify.js 为同源薄启动器）
$E = "06_MED_TextScript\MED-TextScript\MEDNarrative\Flows\【主线】序章\新序章.ncanvas"

node $S lexicon                                   # 词表／台账自检
node $S terms   --event $E                        # 看本件会查哪些词
node $S lint    --event $E --all                  # 离线闸门（不需语料）
node $S index   --event $E                        # 检索+生成（dry-run，打印）
node $S index   --event $E --write                # 落盘到 MED_考证索引
node $S lint    --event $E --period 1942-03..1942-04   # 换时点
node $S build-citations                           # citations.seed → citations.jsonl
```

审计用：`lint` 有 error 时退出码 1（可进 CI）；`index` 默认 dry-run，只有 `--write` 才写文件。

## 八 与既有体检的关系

```powershell
node "$repo\tools\audit_flow.js"            <画布.ncanvas>   # 1 结构闭环
node "_tools\check_overlaps.js"             <画布.ncanvas>   # 2 框体重叠
node "_tools\audit_choice_cost.js"          <画布.ncanvas>   # 3 选项代价
node ".dsh\skills\med-canvas-verify\med_verify.js" lint --event <画布.ncanvas>   # 4 史料考证
```

前三条查"通不通、挤不挤、值不值"；第四条查"**这个时代有没有这东西、这词能不能说**"。四条互不重叠。
