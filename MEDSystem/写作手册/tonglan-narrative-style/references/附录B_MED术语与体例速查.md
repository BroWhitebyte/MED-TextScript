## 一、体例规范（写作时逐项照填）

### 1.1 文件名

```
MED_Demo Event {编号}-{性质}-{任务名}-{地点子项}-（{时段或窗口}）（选一项）（可复用/无复用）（状态）.md
```

| 字段 | 取值 |
|---|---|
| 编号 | `0000`＝1/30｜`01xx`＝1/31｜`02xx`＝2/1｜`03xx`＝2/2｜`04xx`＝2/3（同任务双子项用 0103A/B） |
| 性质 | `固定`／`主线`／`支线`／`自由` |
| 时段 | 六段制：清晨／上午／下午／黄昏／夜晚／午夜；窗口写 `（上午-下午-黄昏）`；**任务不落午夜** |
| 标记 | `（选一项）`＝窗口内选一项执行 |
| 复用 | `（可复用）`＝跨天通用件｜`（无复用）`／`（无复用-教学）` |
| 状态 | `（试写）`／`（资产）`／`（定稿）`；零状态＝待定稿 |

### 1.2 头部（列表式，统一）

```
# MED Event {编号} {任务名}

- 时间

（{性质}/白名单·{窗口说明}）
{日期}
{时段或窗口}

- 地点

{区域} {地点名}

- 人物

{人名} {身份}

> **本日三问**：见《{日期}全部可能事件索引》头部
> **结构注 / 设定注**：……
```

⚠️ 现存两种写法并存：`时间：…`（内联，7 份存档件）与 `- 时间`（列表，22 份）。**新建件一律列表式**。

### 1.3 动作指向与结算

```
## 选项名（结算：短标签）        ← 一级；动词短语或台词式
### 子选项名（结算：X）          ← 二级
（结算：钱→资源→道具→关系/人情→信息/线索→伏笔登记）
（→ 转场：{编号} {任务名}——{日期}·{时段}·{情景}）
（此件结束后跨日——清晨结算＋{次日固定件}）
```

**五条硬规则**：真实选项必有结算（含默认支）｜条件支成对｜结算字段顺序固定｜选项名禁情绪词｜标记不进叙事句。

### 1.4 条件语法

| 类型 | 写法 |
|---|---|
| 道具 | `## 如身上有道具 酒` → `### 拿出 道具 酒` ／ `### 不拿出 道具 酒` |
| 前情 | `## 如果之前拿出 道具 酒 （抗联+1）`／`**若昨日去了警署**` |
| 数值 | `### 如果是6颗（结算入账）` |
| 结算映射 | `## 若给的是紫雪丹：（钱和关键道具）` |
| 检定 | 选项即检定（关系／属性／背包），已知是否通过 |

## 六、体例检查速查（写完后跑）

```powershell
node scripts/validate_structure.js "<单个事件件.md>"   # 单件结构（头部/时段/选项结算/条件/转场）
node scripts/check_style.js "<单个事件件.md>" --kind=event   # 单件文风（红线硬项+密度提示）
node scripts/lint_med_events.js        # 全语料十项规范审计
node scripts/analyze_med_events.js     # 全语料结构、人物、重复句、术语
node scripts/stats_personal.js         # 跨语料文风红线（含对照基线）
```

**2026-09 单件回归结果**：结构合规 **17/30** 件；文风无硬违规 **22/30** 件。
文风硬违规集中在：修饰密度 >40/千字（7 件，其中 003C 48／203A 46 为存档旧稿）、比喻套语 >2（3 件）、对白占比越界（2 件）。
结构硬问题集中在：叶选项块内无结算（教学件 0101/0102/0103A/B 等 13 件）。

**结构写法三代并存（就地择用，同件内不混用）**：① `## ` 标题式（默认推荐）② **粗体标签**式（0201 等定稿）③ 行内引号式（0102，唯一一例，新写不用）。
**结算写法两代并存**：显式 `（结算：…）` 26 处 ／ 隐式（写在选项标签括号内）24 处。
