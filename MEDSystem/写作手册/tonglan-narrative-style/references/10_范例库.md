# 通兰叙事法·原文范例库

用途：写通兰文本时对照既有原文，校准开场、句式、结尾与标记写法。每条引文均摘自本仓库既有文件，出处行号已逐条用 read 工具核对，未核到的一律不收。

---

## 一、空间开场（以地点／方位开头的首句）

- 引文：「通兰县城有四座门。先有门还是先有墙呢？这说不好。」
  出处：`通兰民间故事集 序章 县城.md:25`
  为什么是范例：先立一个可数的地标，再用一句自问把「谁先谁后」变成悬念，空间开场立刻带出历史的悬置感。
- 引文：「官舍区在县公署后身，一条街之隔，却是另一片天地。」
  出处：`MED_Demo Event 0303-主线-官舍区送药-（下午）（选一项）（无复用）.md:34`
  为什么是范例：方位打头，末句用「另一片天地」把物理距离转成阶级距离，一句话完成空间与权力两层定位。
- 引文：「聚春馆在县城西南的巷子深处，门脸比药房高，也比药房旧。」
  出处：`MED_Demo Event 0304-支线-聚春馆送药-（黄昏）（选一项）（无复用）.md:27`
  为什么是范例：位置＋两个「比」构成的对照，开场即给场所的性格定位。
- 引文：「天光还是灰的，北大道上已经排起了队。」
  出处：`MED_Demo Event 0201-固定-领口粮-（清晨）（选一项）（无复用）（定稿）.md:124`
  为什么是范例：天光句垫底、地标句落点，时间与空间各半句，开场不写人先写场面。

## 二、动作开场（从人物动作切入的首句）

- 引文：「程靖霖从门板铺上坐起来，习惯性地先伸手摸了摸炉壁——凉的，但还没凉透。」
  出处：`MED_Demo Event 0201-固定-领口粮-（清晨）（选一项）（无复用）（定稿）.md:40`
  为什么是范例：起床＋摸炉壁一个连贯动作，末尾「凉的，但还没凉透」把体感写成信息，动作自带环境交代。
- 引文：「程靖霖夹着肩膀，顺着南大街一路慢慢向药房走去。」
  出处：`MED_Demo Event 0000-固定-序幕（黄昏）（无复用）.md:24`
  为什么是范例：「夹着肩膀」是姿态不是情绪，一句话交代冷、赶路和身份。
- 引文：「他走到平码脚行的院门跟前，伸出戴着厚手套的右手，嘭嘭嘭地敲了几下门。」
  出处：`MED_Demo Event 0204B-支线-脚行送药-（上午-下午-黄昏）（选一项）（无复用）（定稿）.md:36`
  为什么是范例：动作落到拟声词收尾，画面有声音，下一段便可直接接门内反应。
- 引文：「中野警尉先进来，身后跟着翻译，再后头是警察，屋里一下被寒气填满了。」
  出处：`MED_Demo Event 0205-主线-登门-（黄昏）（选一项）（无复用）.md:31`
  为什么是范例：以进场次序写压迫感，「寒气填满」把人数差换成体感。

## 三、定义句（「X 是 Y」格言体）

- 引文：「墙是通兰县最老实的东西。」
  出处：`通兰民间故事集 序章 县城.md:7`
  为什么是范例：把无生命的墙说成「老实」，定义句兼做人格化，全文第一个句子就定了比喻基调。
- 引文：「东大道是县城的孙子。」
  出处：`通兰民间故事集 序章 县城.md:83`
  为什么是范例：用亲属称谓做等级隐喻，短到不能再短，情绪和排名一起给足。
- 引文：「通兰县城是一具尸体，四种语言、四种规矩、四种恐惧拼起来的尸体。」
  出处：`通兰民间故事集 序章 县城.md:151`
  为什么是范例：先下判断，再重复中心词「尸体」并补出四个并列定语，格言体扩展到总纲。
- 引文：「“人情这东西，比钱沉。”」
  出处：`MED_Demo Event 0104-固定-看板教程-（上午-下午-黄昏）（选一项）（可复用）.md:119`
  为什么是范例：五字定义句放进对白，人物用一句俗理结束训话，不说教也能立规矩。

## 四、对比排比（「官在这边，民在那边」式）

- 引文：「官在这边，民在那边。公署在这边，粮店在那边。学校在这边，磨坊在那边。协和会在这边，当铺在那边。」
  出处：`通兰民间故事集 序章 县城.md:61`
  为什么是范例：四组同构短句只换名词，排比到第四组自然收住，节奏本身就在说「两边」。
- 引文：「越危险的地方，话越轻；越有权的人，说得越慢；越没路的人，反倒越敢骂。」
  出处：`通兰民间故事集 序章 县城.md:133`
  为什么是范例：「越…越…」三连递进，第三句加「反倒」破格，排比不呆板。
- 引文：「西北能决定谁算"人"，西南能决定谁还"有路"。东北和东南承担代价，通常是人命。」
  出处：`通兰民间故事集 序章 县城.md:155`
  为什么是范例：方位对举分成两组，前一组对仗、后一组破格收尾，把四区结构压成两句话。
- 引文：「越往西走，街面越规整，门脸越高，灯越亮。」
  出处：`MED_Demo Event 0204A-支线-同和居送药-（上午-下午-黄昏）（选一项）（无复用）（定稿）.md:27`
  为什么是范例：一个「越」带三个并列分句，走在路上就把贫富梯度铺完。

## 五、转折递进（「雪会覆盖痕迹，也会暴露痕迹」式）

- 引文：「雪会覆盖痕迹，也会暴露痕迹：谁夜里经过、谁拖过重物、谁跌倒、谁被抬着走，全都能在雪地里留下答案。」
  出处：`通兰民间故事集 序章 县城.md:93`
  为什么是范例：同一主语两个相反谓语并列，冒号后用四个选项证明后半句，转折不靠转折词。
- 引文：「但谁都知道，在这通兰县城里，平安只是暂时的，无事只是还没被看见的。」
  出处：`通兰民间故事集 序章 县城.md:161`
  为什么是范例：先接更夫的「平安无事」，再用「只是…只是…」两级收回，肯定句被改成条件句。
- 引文：「白天，邮差从这里出发，把信送到县城的每一个角落。夜里，这里变成消息交换的地方，信封里装的可能是信，也可能是别的东西。」
  出处：`通兰民间故事集 序章 县城.md:297`
  为什么是范例：昼／夜对举之后，末句用「可能是…也可能是…」把日常物件变成两义物。
- 引文：「“这县城不大，可也不小。有些人，一辈子兴许只见一面——可那一面，就够记一辈子了。”」
  出处：`MED_Demo Event 0305-主线-黑川夜访-（夜晚）（选一项）（无复用）.md:76`
  为什么是范例：两句各含一次自我否定，把普通的告别话推成伏笔。

## 六、物件清单句（顿号密集的物名罗列）

- 引文：「土墙、青砖、木梁、夯土院墙、木板门、黑瓦、草顶、糊窗纸、补丁似的油毡和破毡帘子。」
  出处：`通兰民间故事集 序章 县城.md:9`
  为什么是范例：九个名词一路顿号到底，只在最后一项加修饰语，清单靠密度不靠形容词。
- 引文：「冬天里，县城的味道尤其刺鼻：煤烟味、豆饼味、牲口膻味、冻菜味、酱油味、劣烟草味、人身上的寒气、衙门屋里的墨和湿木头味。」
  出处：`通兰民间故事集 序章 县城.md:101`
  为什么是范例：同一后缀「味」重复八次，倒数第二项突然换成体感「人身上的寒气」，清单在末段换质地。
- 引文：「柜台上的东西不多：粗纸一摞，火柴几盒，两块胰子并排码着，针头线脑装了半笸箩。墙角立着个小坛子——煤油。笸箩边上压着一包旱烟叶子、一罐饴糖，罐口蒙着纸，压得严实。」
  出处：`MED_Demo Event 0203-自由-下午自由窗-（下午）（选一项）（无复用）.md:105`
  为什么是范例：罗列中夹进量和位置，清单读起来像盘点，不像并列。
- 引文：「匣子里垫着旧布，东西一样一样摆着：最底下叠着件半旧的棉袍，上头搁一把缺了齿的木梳；铜手炉挨着木梳，炉底有点瘪；再边上是一卷旧书，书皮卷了角；最上头，是一枚磨得发亮的铜顶针。」
  出处：`MED_Demo Event 0203-自由-下午自由窗-（下午）（选一项）（无复用）.md:131`
  为什么是范例：用「最底下／上头／再边上／最上头」串出空间次序，每件都带一处残缺，物件因此有来历。

## 七、结尾样本

### 收在物象

- 引文：「药钱在怀里，焐热了。」
  出处：`MED_Demo Event 0304-支线-聚春馆送药-（黄昏）（选一项）（无复用）.md:79`
  为什么是范例：不写主角想法，只写钱被体温焐热，情绪全在物上。
- 引文：「桌上还有三碗饭，只剩两个人在堂屋里。」
  出处：`MED_Demo Event 0205-主线-登门-（黄昏）（选一项）（无复用）.md:125`
  为什么是范例：数碗筷不数人，缺席由饭量的余数说出来。
- 引文：「那盏油灯不知何时已经灭了。」
  出处：`MED_Demo Event 0301-固定-行刑-（清晨）（无复用）（定稿）.md:67`
  为什么是范例：以一件小物的熄灭收段，不预告后文却已埋下紧张。
- 引文：「黑色的棉门帘子撩起又放下，这一天便也如同这沉重的门帘一样，落到了地上。」
  出处：`MED_Demo Event 0103B-主线-第二次送药-大车店-（上午-下午-黄昏）（选一项）（无复用）.md:88`
  为什么是范例：物象结尾再加一句明喻，把一天的终结绑在帘子的起落上。
- 引文：「城墙根下的曹二泥还在敲敲打打。他的锤声很轻，被风传得很远。」
  出处：`通兰民间故事集 序章 县城.md:163`
  为什么是范例：首段出现的人与声在结尾原样回来，用同一物象做闭环。

### 收在动作

- 引文：「程时一关上门，回来坐下，端起碗，接着吃。」
  出处：`MED_Demo Event 0206-主线-夜归-（夜晚）（选一项）（无复用）.md:103`
  为什么是范例：四拍连续动作，没有一句解释，把「不追问」演成行为。
- 引文：「他不愿再多想，用快要冻僵的手指系好帽带，双手揣回袖筒，继续向药房的方向走去。」
  出处：`MED_Demo Event 0000-固定-序幕（黄昏）（无复用）.md:98`
  为什么是范例：以离场动作收束整幕，把悬念留给下一段而非本段。
- 引文：「他回头看了看时一堂药房的牌匾，这是他每次出门的习惯，他自己也说不上为什么会这样做。」
  出处：`MED_Demo Event 0101-固定-训练日-（清晨）（无复用-教学）.md:84`
  为什么是范例：动作＋「说不上为什么」，用一个习惯动作示范留白。
- 引文：「“饿了。”程靖霖心里想着，加快了脚步。」
  出处：`MED_Demo Event 0204B-支线-脚行送药-（上午-下午-黄昏）（选一项）（无复用）（定稿）.md:278`
  为什么是范例：心里的两个字当台词用，接一个动作收束，把紧张段落降回日常。
- 引文：「程靖霖没有起来看。那句话，他记下了，没有问第二遍。他闭上眼睛。」
  出处：`MED_Demo Event 0207-固定-午夜响动-（午夜）（无复用）.md:87`
  为什么是范例：三句都是消极动作，以「不做什么」收尾，克制成优势。

### 收在制度性判断

- 引文：「通兰县保甲事务所，就是在这种背景下设出来的基层控制机关。」
  出处：`通兰民间故事集 序章 县城.md:221`
  为什么是范例：段落以机构定性和设立背景收束，说明性文字排在场景之后。
- 引文：「这类地方在空间上讲究一件事：前面看见秩序，后面方便做脏事。」
  出处：`通兰民间故事集 序章 县城.md:185`
  为什么是范例：把建筑格局总结成一条通则，判断句里带锋利的口吻。
- 引文：「所谓"火磨"，是靠锅炉、柴油机或煤机带动，不再全靠牲口和人力。改成火磨以后，出粉快，能压过周边小磨，附近零散磨坊要么替它揽活，要么被它挤垮。」
  出处：`通兰民间故事集 序章 县城.md:257`
  为什么是范例：先释名、再写技术、最后落到同行下场，制度性判断自带因果链。
- 引文：「他把背上的面口袋往上送了一下，心里清楚：接下来的一个月，三口人就指着这袋面活着了。」
  出处：`MED_Demo Event 0201-固定-领口粮-（清晨）（选一项）（无复用）（定稿）.md:160`
  为什么是范例：配给制度被换算成「一个月三口人」这句生活账，制度落回个体。
- 引文：「（——收束·端 02：时一堂守住了明面的干净——那包草药被推到桌角，收没收，成了一笔没落下的账——城外的线，还悬在暗处）」
  出处：`MED_Demo Event 0306-固定-选边-（午夜）（无复用）.md:110`
  为什么是范例：事件件的收束行，用括号把结局翻译成立场与账目，供写手对齐尺度。

### 收在短对白

### 留白

- 引文：「明天，才是一切的开始。」
  出处：`MED_Demo Event 0000-固定-序幕（黄昏）（无复用）.md:104`
  为什么是范例：把已发生的事一句带过，把重量推到未写出的下一章；前一行「这一天，就这样过去了。」（同文件 :102）作对照，两句合起来是完整的收束对。
- 引文：「他走到门口，看板上那张写着"平码脚行"的纸条，在风里卷着边。他伸手按了一下——纸角按平了，手一松，又卷起来。他就不按了。」
  出处：`MED_Demo Event 0203-自由-下午自由窗-（下午）（选一项）（无复用）.md:154`
  为什么是范例：三次尝试压平再放弃，用动作写「办不到的事不办了」，全文不点破。
- 引文：「程靖霖看着他的背影，把想问的话咽了回去。」
  出处：`MED_Demo Event 0206-主线-夜归-（夜晚）（选一项）（无复用）.md:105`
  为什么是范例：把冲突写成未发生的对话，留白落在人物的克制上。
- 引文：「下午的阳光斜斜地照进来，屋里安安静静。没有来客，没有事。程靖霖把裁好的药纸又码了一遍——上午才码过。码完，再没有别的活儿了。」
  出处：`MED_Demo Event 0203-自由-下午自由窗-（下午）（选一项）（无复用）.md:80`
  为什么是范例：用重复劳动写时间空转，段落没有事件却交代了「窗口期」。
- 引文：「办了的，板上那张纸条揭下来，折进怀里；没办的，还钉在板上。风一吹，纸角卷起来，又落回去。」
  出处：`MED_Demo Event 0104-固定-看板教程-（上午-下午-黄昏）（选一项）（可复用）.md:111`
  为什么是范例：把「选择必有代价」写成看板上的物理状态，代价可视化而不评判。

## 八、对白样本

### 极短对白（4–8 字）

- 引文：「“霖子，你看那板子。”」
  出处：`MED_Demo Event 0104-固定-看板教程-（上午-下午-黄昏）（选一项）（可复用）.md:43`
  为什么是范例：七字指令，不用「你去看看」这类过渡语，人物关系（长辈指派）已在称呼里。
- 引文：「"药钱，收着。"」
