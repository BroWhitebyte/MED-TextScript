# 04 结构模板

> 本文件给**可直接套用的骨架**。结构与时序的最终依据是项目文档：`MEDSystem/时间系统.md`（六段制）、`写作手册_每日单元写作指南.md`（六段卡）、`设计文档_29天单元结构大纲.md`。冲突时以项目文档为准。

---

## 一、标题与命名

### 1.1 小说章节
- 意象名词优先（"一、墙"是偶得，**不强制**单字）。
- 可用「主标题：副标题」，但**不用问号标题**（与白广大式标题形成区分）。
- 章节名不拘一格，每篇另拟（已确认）。

### 1.2 事件件文件名（VN 规范）

```
MED_Demo Event {编号}-{性质}-{任务名}-{地点子项}-（{时段或窗口}）（选一项）（可复用/无复用）（状态）.md
```

- 编号＝日期组＋日内序：`0000`＝1/30｜`01xx`＝1/31｜`02xx`＝2/1｜`03xx`＝2/2｜`04xx`＝2/3（同任务双子项用字母位 0103A/B）
- 性质：`固定`（写死事件/教程/晨务）｜`主线`｜`支线`｜`自由`
- 时段＝**任务白名单**（任务不落午夜）；窗口写作 `（上午-下午-黄昏）`
- 状态后缀：`（试写）`／`（资产）`／`（定稿）`

### 1.3 头部元信息（列表式，全文件统一）

```
# MED Event {编号} {任务名}

- 时间

（{性质}/白名单·{窗口说明}）
{日期}
{时段或窗口}

- 地点

{区域} {地点名}

- 人物

{人名} {身份}          ← 每行一位

> **本日三问**：见《{日期}全部可能事件索引》头部
> **结构注 / 设定注**：……（可多条）
```

## 二、开头模板

| 模板 | 写法 | 适合 |
|---|---|---|
| 空间定位 | 「{方位/地点}{状态}。{人物}{动作}。」 | 通用首选 |
| 动作切入 | 「{人物}{正在做的动作}。」 | 事件件首选 |
| 结算回响 | 「{人物}{从昨日的某件事里醒来/走出来}」 | 清晨段 |
| 极短句定音 | 「天快黑了。」「夜已经深了。」 | 节拍转变处 |

**禁**：议论、交代、史料、对白开场。

## 三、分节与节奏

### 3.1 章节体
- 二级标题分节，一节一个论点/空间；节名用名词短语。
- 节内：句群铺陈（段长中位 60–90 字）。
- 可用 `---` 做视觉断点（序章用连续空行与分隔线切大块）。

### 3.2 事件件体：六段卡（每段一张卡，不许跳段）

| 段 | 名称 | 写什么 |
|---|---|---|
| 1 | 清晨 | **结算弹窗**（昨日消耗＋获得一并告知）＋固定晨务（1–2 个动作） |
| 2 | 上午 | **冷开场**（四类型选一）＋第一幕：钩子 → 本日 want/obstacle → 目标句 |
| 3 | 下午 | 第二幕：行动/检定 → 第一次小失败 → **转折点**（什么被重新定义）＋自由行动窗 |
| 4 | 黄昏 | 第三幕前半：**核心冲突/重大选择位** ＋ B 线角色 ＋ 信息差交换 |
| 5 | 夜晚 | 第三幕后半：日常主戏收束（归来／晚饭／来访／打牌）＋代价线索 |
| 6 | 午夜 | **写死固定事件位**（白名单：任务不落午夜）＋按钮 ＋次日结算预告 |

**冷开场四类型**：① 昨日后果引爆 ② 闪前/梦魇 ③ 新面孔/物证 ④ 环境/状态。
**按钮类型**：定格物证型｜人物回头型｜声响/火光型｜名单/文字型｜灯/光母题型｜日历/天气型。

## 四、动作指向模板（事件件）

```
## 选项名（结算：短标签）          ← 一级选择；选项名用动词短语或台词

{白描正文，2–6 段}

（结算：钱→资源→道具→关系/人情→信息/线索→伏笔登记）
（→ 转场：{编号} {任务名}——{日期}·{时段}·{情景}）

### 子选项名（结算：X）            ← 二级选择

## 如身上有道具 {道具名}           ← 条件分支（必须成对）

### 拿出 道具 {道具名}（结算：X）
### 不拿出 道具 {道具名}（结算：Y）

## 若{前情条件}：（结算项）
### 如果是{数值}（结算入账）        ← 数值条件
```

**五条硬规则**：
1. 真实选项**必须**有结算（含"不问/不拿/待着"这类默认支）。
2. 条件支**必须成对**（拿出／不拿出）。
3. 结算字段顺序固定：**钱 → 资源 → 道具 → 关系/人情 → 信息/线索 → 伏笔**。
4. 选项名用**动词短语**（首选）或**台词式**（例外）；**禁情绪判断词**；同一件内不混用。
5. 结算/条件/转场**不得混进叙事句**，一律独立成行或作标题。

## 五、结尾模板

| 类型 | 写法 |
|---|---|
| 收在物象 | 一个物件最后的状态（灯灭了／门帘落下） |
| 收在动作 | 一个未完成的动作（把口袋往上送了一下） |
| 收在制度性判断 | 一句不带情绪的规律句 |
| 收在短对白 | 一句家常话 |
| 留白 | 极短句把时间合上（"这一天，就这么过去了。"） |

事件件尾**必接一行转场**；午夜段必写**次日结算预告**（哪怕一句）。

## 六、代价与伏笔（引用项目规则）

- **账本／代价延迟偿还**：本日之"赢"必须标价；最多延迟 14 天收账；收账时比埋设时更重。
- **伏笔**：埋设 ≤14 天回收；每条有唯一负责人与回收日；**不得未登记新增、不得提前回收**。
- **信息差**：每集至少建立或兑现一处（三层：角色层／玩家推理层／系统层）。
- **风物钩子**：每天从背景库取一件当天用（冻住的锁、曹二锤声、保甲的簿子、路倒、梆子声），交稿登记防重。
