# 07 工作流

> 本文件规定**从素材到成稿的十环节**，以及每个环节 AI 能做什么、绝不能做什么。

---

## 一、十环节

| # | 环节 | 动作 | 产出 |
|---|---|---|---|
| 1 | 搜集 | 多语抓取、归档、去重 | 原始材料池 + 抓取日志 |
| 2 | 立卷 | 建索引、标来源、区分【档】【推】 | 卷宗（含来源索引） |
| 3 | 判断 | 结构四问 → 定主要矛盾 → 找检验点 | 一段判断（可由一个数字推翻） |
| 4 | 点子 | 立核心内容的点子（画面／机制／一句话） | 一句话 |
| 5 | 反向展开 | 由点子倒推世界、人物、制度、时间线 | 人物表、地点表、事件链 |
| 6 | 结构 | 章节表／六段卡／场景卡／分支树 | 骨架文档 |
| 7 | 落笔 | 写正文（行动开场、白描、事件句点） | 初稿 |
| 8 | 挂标记 | 动作指向、结算、条件、转场 | 可解析文本 |
| 9 | 校验 | 跑三个脚本 + 过交稿清单 | 审计报告 |
| 10 | 归档 | 更新真值文件、术语表、伏笔表、账本 | 登记完成 |

---

## 二、AI 分工（权限表）

| 环节 | AI 可做 | AI 禁止 |
|---|---|---|
| 1–2 | 全权：抓取、归档、去重、建索引、标来源 | 编造出处；把【推】写成【档】 |
| 3 | 给选项、列矛盾、算数据、找反例 | 替作者做价值判断；决定主题 |
| 4 | 提出候选点子、检查是否重复 | 替你定点子 |
| 5 | 推演后果、列人物与地点需求、查冲突 | 自行新增未登记设定 |
| 6 | 生成六段卡／分支树／结算字段清单 | 自行改变事件编号与性质 |
| 7 | 写正文初稿 | 布景开场、抒情、心理直给、加总结段、加比喻 |
| 8 | 挂标记、穷尽条件支、查漏结算 | 发明新标记语法 |
| 9 | 跑脚本、出缺陷清单、定位到行 | 放行 error 级问题 |
| 10 | 生成登记条目、检查是否已存在 | 自行修改伏笔回收日 |

## 三、四个脚本的用法

```powershell
# ① 结构校验（单件；新稿并入项目之前先跑）
node scripts/validate_structure.js "<事件件.md>"
#   → 头部三字段／时段一致／选项必有结算／条件支成对／转场／导演层指引

# ② 文风体检（单篇；红线硬项 + 密度提示）
node scripts/check_style.js "<稿子.md>" --kind=novel     # 小说/章节体
node scripts/check_style.js "<事件件.md>" --kind=event   # 游戏事件件

# ③ 语料级规范审计（十项，输出缺陷清单到行）
node scripts/lint_med_events.js
#   → 06_MED_TextScript\MED_Demo Event 文本规范审计报告.md

# ④ 语料级文风与结构统计（跨语料对照，含对照基线）
node scripts/stats_personal.js      # → 14_个人创作\通兰叙事法_语料统计.md
node scripts/analyze_med_events.js  # → 06_MED_TextScript\MED_Demo Event 语料分析报告.md
```

**判定分级**：硬项（开场／结尾／AI 腔／比喻／修饰 >40／视角污染／体裁错位）必须过；密度项（段长、句长、术语、修饰下界、对白偏离）只作提示——单篇波动大，语料级判定看 ④。
**写完必跑**：① + ②（单篇）；并入项目时再跑 ③。

## 四、单次写作的固定流程（可直接照做）

```
0 读导演层      Hidden_Meaning/{编号} 分支索引（分支结构＋设定统一）
1 答每日三问    want／obstacle／turn／cost——答不出 turn 或 cost 的天不写
2 填六段卡      清晨(结算)→上午(钩子)→下午(转折/自由窗)→黄昏(核心冲突)→夜晚(日常收束)→午夜(写死+按钮)
3 建文件与头部  文件名 → 头部元信息（列表式）→ 本日三问引用行
4 写正文        行动开场；秩序代替情绪；短句直落；一段一句一动作
5 挂动作指向    五种类型按需；条件支穷尽；选项名用动词短语或台词
6 挂结算        钱→资源→道具→关系→信息→伏笔；"什么都不做"也要结算
7 挂转场        段内 / 跨日 / 结尾次日预告
8 跑校验        上述两个脚本
9 过交稿清单    §五
```

## 五、交稿自查清单

**内容**
- [ ] 每日三问四答齐全；有 turn 与 cost
- [ ] 六段齐全（清晨开、午夜收）
- [ ] 今天至少建立或兑现一处信息差
- [ ] 代价已记入账本行；14 天前旧账已核对
- [ ] 伏笔：无未登记新增、无提前回收
- [ ] 镜像人物在场

**文本**
- [ ] 开场是空间或动作；结尾具象；无点题旁白
- [ ] 真实选项都有结算；条件支成对
- [ ] 选项名无情绪判断词
- [ ] 结算／条件／转场未混入叙事句
- [ ] 无 AI 腔（0–2 处/万字）、无比喻套语、无现代词
- [ ] 修饰 25–35/千字、副词 ≤4/千字

**世界**
- [ ] 地点／规矩与序章八章一致；无未登记新增
- [ ] 话术符合身份（公署／警署／保甲／药房／穷人）
- [ ] 感官正确（区、季、夜的状态）
- [ ] 当天用了一件风物钩子并已登记防重

**残忍桥段（若有）**
- [ ] 五问自查通过；配额未超；后有生活块
