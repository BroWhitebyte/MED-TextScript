# 03 语言指纹

> 本文件是**可核对的清单**，不是形容词。所有数值来自 `09_语料统计.md` 的实测。

---

## 一、句法

| 项 | 规则 |
|---|---|
| 句长 | **长短相间，短句收束**；中位 18–19 字；短句用于定音（"墙是通兰县最老实的东西。"） |
| 段落 | 章节体：一段一意、句群铺陈（中位 73 字）；事件件体：短段快切（中位 34 字） |
| 单句成段 | 事件件 44%、章节体 24%——**允许**，但只用于节拍点 |
| 修饰 | 几乎全靠名词与动词；形容词能删一半就删一半 |
| 主谓宾 | 清楚直落；一段一句一动作 |

**四类认可句式**：

1. **定义句**（X 是 Y）——"北大道是县城的脊梁。""东大道是县城的孙子。"
2. **对比排比**——"官在这边，民在那边。公署在这边，粮店在那边。学校在这边，磨坊在那边。"
3. **转折递进**——"雪会覆盖痕迹，也会暴露痕迹。"
4. **条件句**——"只要住在城里，一个月多少得走几趟。"

**不采用**：三连否式排比（"不把话说满，不把人叫破，不把事认死"）作为**公式**——它在序章的"话"节里成立，但不作为通用模板。

## 二、标点

| 标点 | 用法 | 实测密度（通兰／白基线，每千字） |
|---|---|---|
| 顿号 | **清单式物名罗列**（"土墙、青砖、木梁、夯土院墙、木板门、黑瓦……"） | **42.9** ／ 5.6（7.7 倍）——是结构特征，不是修辞 |
| 破折号 —— | 补充与转折 | 事件件 5.8 ／ 基线 1.4 |
| 省略号 …… | 留白 | 事件件 1.8 ／ 基线 0.3 |
| 引号 | **术语分层装置**（官称／民间称）；事件件中主要承载对白 | 通兰 16.7 ／ 基线 9.2 |

| 连用标点（？！／??／!!!） | **极克制**，实测 0 | 0 |

**排版规范**：一律用**全角弯引号**“”。⚠️ 通兰序章现为 ASCII 直引号（158 处）混 8 处全角——按待议项 6，skill 统一要求全角，旧稿改写时顺手纠正。

## 三、词汇与比喻

**比喻取材域**（实测密度对比，每千字）：

| 域 | 通兰 | 白基线 | 倍数 |
|---|---|---|---|
| 建筑空间（墙／门／街／院／炕） | **35.2** | 2.2 | 16× |
| 物候天气（雪／冻／煤烟／风） | **18.9** | 2.1 | 9× |
| 生计账目（药／粮／账／钱／秤） | 16.3 | 2.7 | 6× |
| 身体病痛（冻疮／手／脸／血） | 9.9 | 2.3 | 4.3× |
| 牲畜交通（马／爬犁／车／铁路） | 7.9 | 0.9 | 8.8× |
| 权力暴力（枪／查／押／保甲） | 6.7 | 1.2 | 5.6× |

**规则**：比喻只从**物质世界**取（劳动、身体、器物、天气、气味）。
**禁止**：复杂比喻与明喻套语——"仿佛""像是""犹如""像一场……"**一律不用**（本项目写作手册明令）。

**气味与温度是主要感官**：煤烟、豆饼、牲口膻、冻菜、酱油、劣烟草、寒气的具体写法见 `附录A`。

## 四、术语分层（本风格最强的签名）

同一物在不同阶层口中给不同的名——**这是"物证叙事"最经济的做法**。

| 物 | 官称 | 民间称 |
|---|---|---|
| 城墙 | 城防线／警戒带 | 两层墙／硬墙／里外墙 |
| 粮 | 《粮谷出荷》／配给 | 领口粮／协和面 |
| 钱 | 中银券 | 老头票 |
| 病 | （处方）调养方 | 抓方／送方 |
| 死 | 处决 | 那事儿／昨儿那事 |

实测密度：≤8 字引号术语 **7.4/千字**（章节体）／4.8（事件件）／3.3（对照基线）。

## 五、时代用语（必须准确，不得错置）

**可用**：康德（纪年）、满洲国／伪满、县公署、警察署、警尉／警士、保甲／保甲长／差役、协和会／协和语／通译、关东军、粮谷出荷、奉纳所、配给、协和面、良民、街公所、火磨、烧锅、脚行、大车店、当铺、掌柜、伙计、屯。

**绝对禁止**：现代管理词与心理词（内卷、情绪价值、边界感、原生家庭、KPI）、网络流行语、外国借词（除协和语语境）、后世才有的器物与制度。

**时间写法**：纪年用汉字（康德九年），数量用阿拉伯数字（三口、每人 23 斤），年份可写 1942 年；**时间用时辰**（寅时、酉时）在人物口中，系统层用六段制（清晨／上午／下午／黄昏／夜晚／午夜）。
**粮食定量已定案**：每人 23 斤→三口 69 斤→到家 90 斤＝30 天量（1 斤/人/天）；缺口 21 斤/月。写数字前先查 `附录A` §五 与术语表。

## 六、禁用词与禁用写法表

| 类别 | 禁用 | 实例（错误 → 正确） |
|---|---|---|
| AI 腔 | 总而言之／综上所述／值得注意的是／不仅仅是……更是……／在这个……的时代／首先其次最后 | ❌"总而言之，这一天很难熬" → ✅ 删掉 |
| 直接心理 | 他心想／他觉得／他感到／内心十分 | ❌"程靖霖感到不安" → ✅"程靖霖把方子折好，塞回内兜，按了按。" |
| 抒情形容 | 凄美／苍凉／深深地／默默地 | ❌"雪凄美地落下" → ✅"雪落下来，把脚印慢慢盖住。" |
| 说明式旁白 | 这体现了……／象征着……／意味着…… | ❌"药房的灯象征着希望" → ✅ 只写灯亮着 |
| 空转词 | 进行／方面／情况／相关／一定的 | 全删 |
| 现代词 | 情绪价值／边界感／内卷／档期／复盘 | 全删（时代错置） |
| 廉价比喻 | 仿佛／像是／犹如／如同一场 | 全删 |

## 七、可复现的语言习惯（少量使用）

- **极短句定音**：「天快黑了。」「夜已经深了。」
- **物件收尾**：「他把布包重新包好，掂了掂。」
- **重复句式做结构**：「从药房的正门出去，拐上南大街」在两个分支件里重复出现——**这是分支复用，不是失误**。
- **对话功能性**：「例行而已。」四字定人。
- ⚠️ **不要发明口癖**：本语料中未出现稳定的作者口癖（无"老白""咱们""图一乐"式签名），不要凭空添加。
