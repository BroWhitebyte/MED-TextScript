# 05 人物与对白

> 人物手段排序与对白分档来自语料实测；话术分层与 voice 纪律引自项目 `写作手册`。

---

## 一、人物塑造手段（按实测使用频次排序）

| 优先级 | 手段 | 实例 |
|---|---|---|
| 1 | **职业与生计** | 补墙匠曹二泥、火磨、脚行把头老韩、当铺二柜王吉来 |
| 2 | **身体特征与病痛** | 脸瘦、鼻梁高、眼袋发乌（金井军曹）；冻疮、咳嗽（程时一） |
| 3 | **随身物件** | 一根没点燃的纸烟；狐皮大氅与金镏子（王裕昌）；袖口的药末 |
| 4 | 说话方式 | 「例行而已。」——四字定人 |
| 5 | 与官／日伪的关系位置 | 身份即命运（保甲差役、通译、受刑者） |

**不做**：心理侧写、性格标签（"他是个善良的人"）、内心独白。
**命名**：无一定之规，按叙事需求灵活（**已确认：不设固定命名公式**）。
**功能性人物**：职位代称可作人物名（账房／伙计、保甲差役、宪兵队军官、通译、老鸨、围观人群）——他们**只承担结构功能，不给背景故事**。

## 二、对白分档（按体裁）

| 体裁 | 占比 | 形态 | 功能 |
|---|---|---|---|
| 章节体 | **3.9%**（近零） | 极少直引，多为称谓与话术暗示 | 全景冷叙述 |
| 事件件体 | **30.2%** | 916 条/30 件，条均 20 字，最长 100 字 | **信息主干**：交代任务、账目、人物关系 |

**事件件的对白纪律**：
- 中等长度承担信息，不承担抒情。
- 「双关日常话」——药名、时辰、回头再拿、今晚别断火，这类话能当正话，也能藏别的意思。
- **禁解释性台词**（人物替作者解释设定）。
- 一人一开口即定其阶层与位置（见 §三 话术分层）。

**对白归属的实测参考**（MED DEMO）：主角 31.8%、次主角 13.3%、女主 5.9%，未指明 37.4%——**近四成对白不点名说话人**，靠语序与身份暗示，这是本风格的写法。

## 三、话术分层表（写对话前先对表）

| 对象 | 规矩 |
|---|---|
| 公署 | "奉公""协力""安靖地方"；对绅商"请坐""好商量"；对穷人"规矩""照章""先候着" |
| 警署 | 简单粗暴，短句压迫（"赶紧""信不信我扒了你的皮"） |
| 保甲所 | 先问"你归谁管"；连坐话术："一户不清，一保不宁" |
| 药房前柜 | 客套里带提防：对穷人讲价直，对熟客留面，对伪满守规矩，对日本人**说话少、快、准、别抬头** |
| 药房里屋 | 话更短：先看人，再说病，再谈药，最后才谈别的 |
| 穷人 | 三句话不离钱、粮、病、路子和谁又没了 |
| 总则 | **不把话说满，不把人叫破，不把事认死**；越危险的话越轻；"人知道越少，活得越长" |

---

## 四、主角 voice 纪律

- **先听后答**；对伪满与强权：句子短、少带情绪；对熟人：不把话说满。
- 手上有药茧、袖口有药末；怕冷；站在灯下。
- 不说漂亮话、不做总结陈词、不喊口号。

## 五、镜像人物（每次主角做选择，画面里最好站着一个对照）

| 镜像对 | 对照内容 |
|---|---|
| 主角 / 孪生兄弟 | 同一张脸，两个阵营（终极镜像） |
| 老掌柜 / 日本警尉 | 两个"父亲"：一个沉默十年，一个为家放行 |
| 女主 / 杂货铺寡妇 | 等消息的女人 |
| 坚持者 / 投降者 | 同一个问题的两个答案 |

> 对照**不用旁白点出**，靠并置与物证（袖口整洁的那一个 vs 有药末的那一个）。

## 六、身份冒用与辨别（若涉及双线身份）

| 人物 | 辨识能力 |
|---|---|
| 老掌柜 | 一眼即穿（亲手养大＋认得生父的脸） |
| 女主 | 几分钟穿帮（先看脚再看手、折纸角、药斗位置） |
| 当铺掌柜 | 一眼即穿（他见过两张脸） |
| 日军军曹 | 辨不出脸、**辨得出行迹**（记脸＋鞋底磨损＋出入规律） |
| 日本警尉 | 早已起疑，但**不声张、不促成**——记下了，什么也不做 |
| 街坊／车马店掌柜 | 短时可骗过（黑市错认的土壤） |

**纪律**：不同框（认出即合体即结局）；每次冒用写清冒用者**失去什么**（名字／信任／自由）——冒用不是免费道具。

---

## 七、写对白时的三问

1. 这句话**只有**这个人能说吗？（换个人说是否还成立——成立就是没写好）
2. 他**为什么现在**说？（有事才开口，不寒暄填充）
3. 这句话能不能**只靠物名与时辰**说出来？（能 → 别加形容词）
