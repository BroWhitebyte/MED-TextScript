# 通兰叙事法

> 一句话内核：**点子先行 · 白描为基 · 术语分层 · 物证叙事 · 空间为纲**
> 本技能负责"怎么写"；写成什么形状（文件名、头部、选项、结算、条件、转场）由
> `06_MED_TextScript/视觉小说文本规则描述（动作指向·资源限制）.md` 定义；结构与时序以项目 `写作手册`／`MEDSystem` 为准（冲突时项目文档优先）。

## 一、八条铁律

1. **行动开场，不布景开场**——景从人的动作里长出来。实测：30 份事件件中 **17 份以空间开、11 份含动作、0 份以对白开场**。
2. **零度叙述**——全篇 0 句抒情；情感靠物证、账目、路程、时辰、病痛自证，叙述者不宣布。
3. **白描短句，修饰极少**——修饰指标（的＋副词＋地）**25–35/千字**，副词 **≤4/千字**。通兰序章实测 31.8，白广大基线 48.3。
4. **秩序代替情绪**——写"谁先动筷子""谁站在暗处""谁把参推回来"，不写"大家都很沉重"。
5. **术语分层**——同一物给两种名：官称（城防线／警戒带）↔ 民间称（两层墙／硬墙）。实测术语密度 7.4/千字，为对照基线 224%。
6. **收在事件句点**——结尾止于物象／动作／制度性判断／短对白／留白；点题交给按钮与标题系统。
7. **结算写账，不写感想**——`（结算：人情+（马寡妇）——饴糖×2 道具）`；含"什么都不做"的默认支。
8. **标记不进句子**——结算、条件、转场一律走括号行或标题行，正文句子里不得出现系统词。

## 一·补 遇设定冲突怎么办（2026-09-10 定）

**就地按叙事逻辑决断，不挂"待裁定"清单，不等审批。**

- **能就地定的就地定**——两种叫法、两处格位、口径不一，按当篇的叙事逻辑择一，写完继续。
- **决断写回一处**——`Hidden_Meaning/{编号} 分支索引.md` 的"设定统一"节，或 `术语表.md`（名词口径）。写回是为了下次不重复打架。
- **同件内不得两种写法并存**——决断的作用域至少覆盖当前事件件。
- **不得为绕开冲突而删设定**——世界不许因此变薄。
- **真值文件硬冲突**：以**序章八章正文**为准（写作手册已定优先级）。
- 详见 `references/06_世界观一致性.md` §八。

## 二、写作工序（七步）

```
① 点子      先立核心内容的点子（一个画面/一个机制/一句对白）
② 反向展开  由点子倒推：需要什么样的世界、人物、制度、时间线
③ 体裁定调  小说章节体 ／ 游戏事件件体 ／ 设定卡体 ／ 评析体
④ 文风配平  文风必须与内容需求匹配：需要白描，则全篇白描，
            且白描的"水平与品质"在篇内必须一致（不许前紧后松）
⑤ 落具体    把结论翻译成具体的人、物、动作、账目、路程、时辰
⑥ 校一致    与卷宗、地点卡、时间线、术语表对齐
⑦ 过禁令    过 §四 红线 + §五 自检清单
```

**④ 是本技能独有的工序**：不是"统一腔调"，而是**品质配平**。验收办法：写完跑一次统计，落档即配平（见 `references/09_语料统计.md`）。

## 三、视角双模（按体裁分派）

| 体裁 | 视角 | 说明 |
|---|---|---|
| 章节体（小说／地方志体） | **准地方志式全知** | 知道全城，**不表态、不读心**；"墙是通兰县最老实的东西" |
| 事件件体（游戏文本） | **人物贴身限制** | 贴主角走，只写他看到的听到的；正文实测"他"11.2/千字、"我"4.4/千字 |
| 两模共同 | 一律**不写内心独白** | 心理只能由动作、体感、物件转译 |

## 四、红线表（写完必查）

> **判定性质（重要）**：**上界多为硬约束**（越界即错：体裁错位／白描失效），**下界只是提示**（更少修饰＝更白描，短篇与对白密集篇天然偏低）。
> 硬约束：对白占比、第一人称、副词上限、修饰**硬上限 40**／千字、开场、结尾、AI 腔、比喻套语。
> 软提示：段长、句长、术语密度、修饰下界。

| 指标 | 小说章节档 | 事件件档 | 判定 |
|---|---|---|---|
| 修饰（的＋副词＋地）/千字 | 25–33 | 25–35 | >40 判失败；低于下界仅提示"偏干" |
| 副词/千字 | ≤1.5 | ≤4 | 硬上限 |
| 段长中位 | 60–90 字 | 25–40 字 | 提示 |
| 句长中位 | 15–25 字 | 15–25 字 | 提示 |
| 对白占比 | ≤5% | 20–35% | **硬**（对调＝体裁错位） |
| 术语（引号内非对白 ≤8 字）/千字 | ≥6 | ≥4 | 提示（篇内波动大，宜按语料整体看） |
| 第一人称/千字 | ≤0.3 | ≤5 | **硬**（章节体出现"我"＝视角污染） |
| AI 腔词 | **0** | ≤2/万字 | **硬**（判据为"构成式"：不仅仅是…更是…／在这个…的时代；自然中文不误判） |
| 比喻套语（仿佛／像是＋名词／像一场） | ≤2 | ≤2 | **硬**；"像是＋动作"属贴身视角推测，不计 |
| 开场 | 空间或动作 | 空间或动作 | **硬**（禁对白／议论／史料；判据取开场单位前 60 字） |
| 结尾 | 具象 | 具象 | **硬**（抒情或总结 → 删） |

**验收工具**（写完直接跑，退出码 1＝有越界项）：

```powershell
node scripts/check_style.js "<你的稿子.md>" --kind=novel    # 小说/章节体
node scripts/check_style.js "<事件件.md>"  --kind=event    # 游戏事件件
```

复跑语料级统计：`node scripts/stats_personal.js`（文风红线）／`node scripts/lint_med_events.js`（事件件规范十项）。

## 五、自检清单（12 条，逐条过）

1. 点子先行了吗？反向展开有没有反过来改写点子？
2. 文风与内容需求**配平**了吗？白描品质在篇内一致吗（有没有前紧后松）？
3. 开场是空间或动作吗？有没有议论、交代、摆史料？
4. 结尾止于物象／动作／判断／短对白／留白吗？有没有抒情或总结？
5. 形容词能否再删一半？每一个都要过这一问。
6. 情感是由物证给出的，还是叙述者宣布的？
7. 有没有直接心理描写与内心独白？
8. 【档】【推】【虚】三级标注有没有混用（研究材料与文学作品的闸门）？
9. 术语分层体现了吗（同一物的官称与民间称法）？
10. 时代用语有没有错置（康德九年／1942、出粮、奉纳、协和会、保甲）？
11. 视角与体裁匹配吗（章节体＝地方志全知／事件件＝贴身限制）？
12. 与卷宗、地点卡、时间线、术语表有没有冲突？
