# 行动系统

# 设计目的

1. 事件入口，叙事的舞台

2. 支撑「有风险的决策」，投入资源、获得结果和影响

# 系统设计

## 地图

详见[地图系统](https://my.feishu.cn/docx/P9vfdufreoU6KJxhletckDGenhh?from=from_copylink)

1. 所有行动地点都在地图上

2. 如果地点没有事件可供进行，则无法选择

3. 地图上的地点划分**区域**

4. 如果角色在城内区域，深夜行动结束后会自动回到**时一堂大药房**（主角家）

    - 回家不额外消耗体力

5. **新增：**行动结束后不一定在原先地点，通过对话配置

    - 例：行动在大车店发生，对话中主角移动了，那么最后主角在药房而非大车店

## 体力

1. 体力值为自然数

2. 在地图上前往任何地方都需要消耗体力

    - 同区域内移动消耗1格体力

    - 其他情况（如移动到不同区域）消耗更多体力

3. 玩家体力存在上限

4. 新的一天时，恢复一定量的体力

## 行动条件

1. 任何行动都消耗**时间段**[时间系统](https://my.feishu.cn/docx/O4jqdU6ttoxIuhxF901cWLVVnBe?from=from_copylink)

2. 任何行动都消耗**体力**[行动系统](https://my.feishu.cn/docx/XBgCd6DHKoSuppxzoRHcqsWwn5f#share-NpofdCAurokiGyxThkqch8EhnAe)

3. 部分行动限制时间\&时间段

    - 例如，「1942年2月1日」「深夜」无法前往「裕昌当铺」进行「典当物品」的行动

4. 部分行动需要检查势力\&NPC关系[NPC\&势力系统](https://my.feishu.cn/docx/H8dRd0yTToOU1oxef25cnPicnsQ#share-ZNNqdjh9Zos2EIxU9AOczemMnTg)

    - 例如，如果得知NPC的**里势力**，则会开启新的行动

5. 部分行动需要消耗资源\&道具[资源\&道具系统](https://my.feishu.cn/docx/FDpidXsW1oKRIIxXJn6cjz34nve?from=from_copylink)

6. 部分行动需要检查属性\&特殊状态[属性\&特殊状态系统](https://my.feishu.cn/docx/LatRdjIi6ooQlxx9xqUcUvF5nNg?from=from_copylink)

## 行动信息

1. 任何行动都会显示行动信息文本

2. 任何行动都会已知一部分人物

    - 例如，某次「典当物品」行动知道「王裕昌」在，但是去了才发现伪满也派了人

## 返回结果

对话事件中的检定和结算，直接在对话框内即时反馈
