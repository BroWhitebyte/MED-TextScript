# 属性\&特殊状态系统

# 设计目的

1. 支撑成长循环，让玩家直观感受到角色成长

2. 支撑叙事，配合**特殊状态**，提供更多检定手段

# 系统设计

玩家控制角色带有**属性**，可能获得/消除**特殊状态**

## 属性

### 身手\&眼力

属性分为身手\&眼力两种

1. 属性的初始值由系统设定，为自然数

2. 属性都存在上限，随着游戏进行逐渐成长

    - 例如，对话、道具等都能让属性成长

3. 身手倾向于**动作**，如追逐、闪避、潜行、脱身等

4. 眼力倾向于**额外线索发现**，如话里有话，意识危险存在，发现线索，感受人情世故等

## 特殊状态

1. 通过行动、对话可以获得/消除特殊状态

2. 部分特殊状态达到条件后，也可以随时间消除

    - 例如，连续吃下食物2天后，「饥饿」消除

3. 特殊状态的效果很多样

    1. 影响行动：例如「寒冷」导致无法前往其他区域

    2. 影响检定：例如「饥饿」导致属性下降

4. 同一状态存在等级，等级为正整数

    - 例如，1级「发冷」、2级「寒冷」、3级「冻僵」、4级「失温」

    - 每级效果可以不同，等级只是表述
