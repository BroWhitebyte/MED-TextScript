# NPC\&势力系统

# 设计目的

1. 支撑NPC与玩家的叙事，提供符合立场和关系的事件

2. 支撑行动选择，需要权衡多方关系、谨慎选择当前行动

# 系统设计

势力与人物关系默认**互不影响**，唯一例外是表里身份（见「表里身份」第 8 条）

## 势力关系

主要势力：**官面、街面、江湖、城外**

1. 每位NPC都有所属**表势力**

2. 每个势力都有对应**声望**，选择会影响声望

    - 例如A事件选择，导致官面声望上升，而江湖声望下降

3. 势力关系同样参与检定，影响对话内容

### 势力声望（人头计票派生值）

势力声望不单独计数，由该势力9\~12个具名NPC的声望人头派生

1. 人头判定：NPC声望 ≥4 记为「朋友」，≤−4 记为「对头」，中间为「认识」

2. 净人头 = 朋友数 − 对头数，映射五档：倚重 ≥4 ／ 友善 2\~3 ／ 中立 0\~1 ／ 冷淡 −1\~−2 ／ 敌视 ≤−3（经蒙特卡洛校准，见系统拆解报告附录C）

3. 面板只显示档位名与「替你说话的人」数量，不显示个人数字

4. 派生值随NPC声望的每日漂移自动回落，不单独维护

5. 负外部性：与某阵营NPC交往+1时，敌对阵营随机一人−1（社区记忆到「传闻级」才生效）

6. 挚友（NPC声望 ≥6）可出面担保，抵消一次对头带来的降档

7. NPC死亡/被捕联动2\~3个关联者声望，人头数随之变化

8. 到达极端档位触发专属负面事件（高位反噬：例如官面「倚重」会被警署要求指认他人）

9. 势力级大事件可直接修正净人头 ±1\~2，全程控制在个位数次数

### 恐惧

1. 全局单轴（暂定0\~100），由日军身份相关的行动与事件推动

2. 只能上升或极缓下降，无法通过讨好消除

3. 恐惧不进入UI，不显示数字，也不提供稳定映射：同一现象允许多种解释（他没打招呼是怕了、是忙、还是听说了什么，玩家无从确认），不得据此倒推数值

4. 到达阈值时推动官方压力的特殊状态等级（见属性\&特殊状态系统）

## NPC关系

单个NPC与玩家的关系

1. NPC关系通过检定影响对话内容

2. 每位NPC都与玩家存在关系，选择会影响关系

    - 与事件相同，选择可能导致多个人关系上升/下降

### NPC声望

NPC声望是int值（暂定\-10\~10），正/负值对应关系好/坏，初始值为0

1. 不显示数字与档位，只通过对话措辞与称谓体现

2. 同样每天结算时向0漂移

3. 锚定：到达「朋友」（≥4）或「对头」（≤−4）后不再漂移（跨过一次重大事件的关系，不会自然回淡）

## 身份

1. 每位NPC都有所属身份，受到势力限制

    - **官面**（日军 / 伪满 / 警署 / 县公署）

    - **街面**（商户 / 诊所 / 车马店 / 邻里 / 工匠）

    - **江湖**（黑市 / 打手 / 赌档 / 线人 / 脚行）

    - **城外**（猎户 / 走山人 / 抗联交通 / 外路人）

2. 身份用于玩家认识NPC，便于理解关系

### 表里身份

1. 部分NPC可能存在**里势力**，通过行动/对话开启

2. NPC的里势力和表势力不同

3. 如果NPC存在里势力，则他的**里身份**在里势力范围内

4. NPC被得知里势力时，仍可能不知道里身份

    - 里身份同样，通过行动/对话开启

5. 如果NPC有表里身份，那么他有两个独立的NPC声望

6. 新增待发现状态：玩家知道NPC有秘密身份，但不知道具体身份的情形

7. 里势力的声望全程隐藏，连档位名也不显示

8. 表里身份是势力与NPC关系的**唯一耦合点**：里势力被揭穿时，表声望相关的事件链被迫改写（普通NPC与势力保持解耦）
