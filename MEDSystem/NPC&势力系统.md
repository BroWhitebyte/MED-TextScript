# NPC\&势力系统

# 设计目的

1. 支撑NPC与玩家的叙事，提供符合立场和关系的事件

2. 支撑行动选择，需要权衡多方关系、谨慎选择当前行动

# 系统设计

势力与人物关系**互不影响**

## 势力关系

主要势力：**官面、街面、江湖、城外**

1. 每位NPC都有所属**表势力**

2. 每个势力都有对应**声望**，选择会影响声望

    - 例如A事件选择，导致官面声望上升，而江湖声望下降

3. 势力关系同样参与检定，影响对话内容

### 势力声望

势力声望是int值（暂定\-10\~10），正/负值对应关系好/坏，初始值为0

## NPC关系

单个NPC与玩家的关系

1. NPC关系通过检定影响对话内容

2. 每位NPC都与玩家存在关系，选择会影响关系

    - 与事件相同，选择可能导致多个人关系上升/下降

### NPC声望

NPC声望是int值（暂定\-10\~10），正/负值对应关系好/坏，初始值为0

## 身份

1. 每位NPC都有所属身份，受到势力限制

    - **官面**（日军 / 伪满 / 警署 / 县公署）

    - **街面**（商户 / 诊所 / 车马店 / 邻里 / 工匠）

    - **江湖**（黑市 / 打手 / 赌档 / 线人 / 脚行）

    - **城外**（猎户 / 走山人 / 抗联交通 / 外路人）

2. 身份用于玩家认识NPC，便于理解关系

### 表里身份

1. 部分NPC可能存在**里势力**，通过行动/对话开启

2. NPC的里势力和表势力不同

3. 如果NPC存在里势力，则他的**里身份**在里势力范围内

4. NPC被得知里势力时，仍可能不知道里身份

    - 里身份同样，通过行动/对话开启

5. 如果NPC有表里身份，那么他有两个独立的NPC声望

6. 新增待发现状态：玩家知道NPC有秘密身份，但不知道具体身份的情形
