## 首轮裁定（2026-08-25）

1. **试写定位＝完整初稿·设定克制**：完整可读的初稿（供对照改定）——新设定/新细节克制（有依据才加——见裁定 4）。
2. **前提确认＝资源关联预查**：试写前（或试写稿内）**提前询问"哪些已有资源/道具/伏笔/人物可与即将发生的事件产生关系"**——并在试写稿中提出；同时核对分支共通与衔接对象的关联——尽量合理。
3. **选择必有代价＝铁律**："选择一定有代价，无论什么形式——当剧情产生选择分支时，每一个选择都必须是有意义的，否则它就不应该是一个选择。"（用户原话——2026-08-25）
4. **新设定可加但须有依据**：可以加入新设定——**必须基于现有文本特征以及 Rule 文件夹内的相关内容**（从既有文本/规则延伸——非凭空编造）。
5. **映射不限镜像**：不一定非得镜像对称——**有力的、能形成映射的、能让玩家/读者产生印象的方式都可以**（成对/呼应/对照/回声——"映射句"替代"镜像句"概念）。
6. **五条偏好待逐条确认**（§八 39-43——拆分为独立问题）。

## 第二轮裁定（2026-08-25·五条偏好）

7. **偏好① 来客驱动＝重要但非唯一**："来客是重要的事件驱动，但事件驱动的线索不能只有来客一种模式。"——事件驱动模式多元化（来客/环境/物件/街面动静/传闻/天气……）——来客是主要模式之一，不是唯一。
8. **偏好② 选择必有代价＝铁律确认**：代价形式不限（资源/人情/信息/关系/情绪——任何形式）。
9. **偏好③ 事必留声（街坊目睹升格为叙事机制）**："人的行动是一定会被看见的——无论做了什么样的事，在城里都会有风声（看见或听说）——这些都会变成发现事件真相的线索，或驱动玩家去找寻故事、挖掘故事的动力。"——**行动必被看见、风声必起**——风声＝线索＋探索动力（不只是"大事不留死角"）。
10. **偏好④ 骨架映射＝自然结果·不强行对称**：同日同时同地同时的人发生的事本来就差不多——映射是自然结果（同前提同来客）；只有核心选择的决策导致事态巨变（分支差异=选择的后果）；**不强行镜像/对称——有自由发挥空间——但不能与当时状态出离太远**。
11. **偏好⑤ 细节即人物史＝可加有依据**：新设定藏在动作/细节里（伤疤/钱箱钥匙/烤手镜像）——试写可加——须有依据（从现有文本特征/Rule 延伸）。

## 第三轮裁定（2026-08-25·删改模式）

12. **删改原因＝编造感＋动作空洞**（用户原话）："第一，它有明显的编造感，并且没有依据，在此之前和在此之后都没有提及。然后它的重复实际上是没有意义的——**动作可以没有意义，但是行为逻辑一定有意义**。我理解你想表达的意图是心神不安的状态，但是这种描写极易落入空洞。"——**行为逻辑纪律**：动作/细节允许表层无意义——但必须有行为逻辑支撑（206A 保留的"端碗没喝→水凉→换热水"＝行为链有意义；"错漏三连"＝空洞重复）；"心神不安"类心理状态不许用重复动作演示。
13. **选择＝社会性举措**（用户原话）："这种应对实际上是人的社会性举措，为社会身份带来的影响。玩家在这个游戏里的社会关系，是需要通过自己的行动去形成的。"——**选择的分量＝社会关系的形成机制**：揭发/忍/人情不只是当下应对——是玩家的社会身份在行动中被定义（选择绑定旧账关系＋塑造未来关系）。
14. **街坊活气＝可加但循原则**：马大脚外号/斗嘴/市侩口语可加——但遵循前述原则（有依据／行为逻辑有意义／不空洞）。

## 试写前六问（每次试写命令前的固定提问——2026-08-25 定）

> 用户指令：**每次命令开始试写之前都要提问**——六问如下（用户六问＋发挥填充）。
> 执行方式：每次试写前用本六问提问（ask 或清单）——答毕再落导演层、再写正文。

1. **接续**：这个场景接续哪个场景？（相邻 event 的收尾句点——句点接句点；分支归属：共通／分支专属——前提确认）
2. **人物**：这个场景里的人物会有谁？（在场／缺席／来客——谁来谁不来——来客的话冲谁去）
3. **冲突**：你希望达到怎样的叙事冲突？（抉择／暗语／日常张力／信息差——turn＝什么被重新定义）
4. **篇幅与细节**：篇幅与主要细节和选择的分支？（行数／道具风物／选择数量与维度——与相邻 event 的映射关系）
5. **资源**：选择分支和哪些资源有关系？（金钱／药材／人情／信息／关系／情绪——"选择必有代价"铁律的落点）
6. **导向**：场景结束是否导向分支？（结果分支／共通汇流／下一块衔接——按钮与次日）

## 试写原则定稿（v0.3·裁定汇总）

**定位**：试写＝完整初稿·设定克制（供对照改定）。
**试写前三查**：①前提确认（共通/分支专属/衔接对象）＋**资源关联预查**（哪些已有资源/道具/伏笔/人物可与本事件产生关系——试写稿内提出）②相邻 event 收尾衔接（句点接句点）③术语表（口径/称谓）。
**写作五律**：
1. 选择必有代价（任何形式——资源/人情/信息/关系/情绪）——无意义的选择不成立；选择＝社会关系的形成机制。
2. 新设定可加——必须基于现有文本特征与 Rule 内容（前后可呼应）。
3. 行为逻辑一定有意义——动作可表层无意义，心理状态不许用重复动作演示（防空洞）。
4. 映射不限镜像——有力的映射/呼应/对照/回声皆可；分支骨架映射是自然结果（同前提同来客）——不强行对称——但不能与当时状态出离太远。
5. 事必留声——行动必被看见、风声必起（看见或听说）——风声＝真相线索＋驱动玩家探索的动力。
**事件驱动模式**：来客是重要驱动——但非唯一（环境/物件/街面动静/传闻/天气皆可）。
**落档流程**：试写→定稿→对比分析（结构/逐处/新设定/待确认）→回写导演层→登记（角色卡/术语表/留钩子/复用规则/写作登记）。
