# 写作手册（入口）

> **本文件是写作的唯一入口，≤100 行。** 详细内容在下列文件，按需点开；不要一次全读。
> 优先级：设计文档 v2.2 > 26.9.8 会议裁定 > 29 天表 > 本手册。

## 一、三条铁律

1. **天＝集**：每天一个自足单元，单看成立，为前一天留结算、为后一天留扣子。
2. **历史做氛围，虚构做因果**：史实走传闻/电文/号外，不在剧情层面与虚构互相解释。
3. **冲突按优先级链裁决**，裁决结果记进 `docs/定案.md`。

## 二、六段制（2026-09-09 会议终版）

| 段 | 功能 | 时长参考 |
|---|---|---|
| 清晨 | 结算（昨日消耗＋获得，一次性）＋固定晨务/事件位 | 1–2 分钟 |
| 上午 | 任务与自由行动窗 | 2.5 分钟 |
| 下午 | 任务与自由行动窗 | 3 分钟 |
| 黄昏 | 任务与自由行动窗；核心冲突可选位 | 2.5 分钟 |
| 夜晚 | 日常主戏收束（打牌/归家/来访） | 2 分钟 |
| 午夜 | 写死固定事件位（白名单任务不落午夜） | — |

时长以系统侧预算定案为准；上文为既有基线。

## 三、动笔前：每日三问（写在脚本头部）

1. 今天想要什么？障碍是什么？（want / obstacle）
2. 今天哪个局面被重新定义？（turn，优先关系重定义）
3. 谁为哪个选择付了代价？（cost beat，记在账本）

答不出 turn 或代价的天，不写。

## 四、写作路径

```
med brief <代号>   → 拿到这一天的日期/农历、段位、定案、清单、词表提示
写正文（按 段模板）
med check          → 登记/索引对账（可选 --lint 跑闸门）
```

## 六、禁用与红线

- 禁用词与时点红线以 `lexicon.tsv` 的 `timeGuard` 列为准；`lint` 报 error 必改，warn 按 note 处理。
- 内部卡（`【结算】`等）不进游戏文本，导出端负责剔除。
- 数值不写死在正文选项里；带圆括号数值注解的选项视为写手提示（见 `canon/rules.tsv` R-01）。
